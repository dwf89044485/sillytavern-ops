  type: principle
  source_chapter: 1.入门（一、性格对冲思路）
  source_quote: |
    "在创建角色确定思路时，你需要明确这个角色的三大要素来定下角色深度。驱动角色的主性格，产生变化的副性格，发生化学反应的对冲性格。（注意，最少三个而不是最多三个）如此，你的角色达成了最基础的去标签化。"

- id: p18

  source_chapter: 1.入门（二、为什么选择手写而不是ai扩写）

- id: p19

- id: p22

  type: rule

  source_quote: |

- id: p23

  type: maxim
  source_chapter: 10.大总结-02调色盘篇
  source_quote: |
    "标签是单色的，而人是混色的。一个底色'不甘心'就已经包含了自卑和坚韧两种东西的共存，AI读到'不甘心'就知道这个人既知道自己处境差，又在默默反抗。"

    NSFW 部分不列"性癖/敏感部位/高潮表现"清单（教 AI 做什么→演成性爱机器），写行为背后的动机（控制安全感、分离焦虑、渴求确认）。
    把性和人格连起来：依赖的人在床上也依赖，害怕被抛弃的人在床上也害怕。

- id: p26
  title: 三面性判断标准：找不出两种以上压力性质截然不同的场景就不需要
  type: rule
  source_chapter: 2.三面性（三、什么角色需要三面性）

- id: p27
  title: 先有调色盘，再有三面性
  type: principle
  source_chapter: 2.三面性（四、三面性和调色盘的关系）
  source_quote: |
    "先说结论：先有调色盘，再有三面性。没有调色盘的三面性是空壳。调色盘回答的问题是：这个人是什么做的？三面性回答的问题是：同样这些材料，在不同房间里怎么组合？"
  summary: |
    调色盘是材料（砖头钢筋玻璃），三面性是同一批材料在不同房间的混合比例（学校面/舞台面/恋人面）。
    写作顺序：先写完调色盘，再看这些颜色在不同场景怎么混合出三面性。没有调色盘的三面性是空壳。

- id: p28
  title: 每张面必须写满五个部件
  type: checklist
  source_chapter: 2.三面性（五、给每张面装上五个部件）
  source_quote: |
    "每一张面不是一个标签，是一个完整的行为系统。五个部件：1.触发条件：什么情况下这张面启动？2.能量状态：消耗多少精力？3.语料：在这张面里她怎么说话？4.身体行为模式：她的身体怎么动？5.功能：这张面在保护什么？"
  summary: |
    每张面五部件：触发条件（何时启动）、能量状态（消耗高低/稳定性）、语料（具体台词示例）、身体行为模式（身体怎么动）、功能（保护什么/解决什么）。
    缺一个 AI 对该面的理解就出现漏洞。五部件是"运行模式"不是"心理分析"。

- id: p29

    有三面性的角色，具体台词从调色盘移到各面语料区（同一个人不同面说话完全不同，混在一起 AI 分不清何时用哪套）。

- id: p30
  title: 三面性只写"怎么运作"，不写"为什么"

- id: p31

- id: p32
  title: 三面性写完后自查六问
  type: checklist
  source_chapter: 2.三面性（十一、实操检查清单）
  source_quote: |

- id: p33
  title: 台词人设是特化方案，不与调色盘混用
  type: rule
  source_chapter: 3.台词先行（二、调色盘和台词人设的关系）
  source_quote: |

  summary: |
    模型台词正常→用调色盘；模型"端着"、角色说话像 AI→换台词人设；不确定→先试调色盘。
    一个角色要么调色盘要么台词人设，别把衍生和台词塞一起，AI 会困惑。

- id: p34
  title: 第三人称解释不替角色下结论，用存疑打断 AI
  type: principle
  source_chapter: 3.台词先行（四/五、第三人称解释与存疑）
  source_quote: |
    "第三人称解释的功能是给AI一个'怎么理解这句话'的参考，但同时通过存疑阻止AI把这个理解锁死。……存疑就是：不给结论。打断AI的惯性思考。在该说清楚的地方不说清楚。方式要打散。"
  summary: |
    台词人设=台词+旁观者观察式解释，解释不钻角色脑子、不下定论（"是否真的讨厌，存疑"）。
    存疑=在该说清楚的地方不说清楚，给两种可能性/只描述现象/什么都不说，逼 AI 每句重新判断，防止角色被锁死。

- id: p35
  title: 台词不分类，混在一起写
  type: rule
  source_chapter: 3.台词先行（六、怎么写台词人设）
  source_quote: |
    "不要分类。……一旦你分了类，你就在告诉AI'她在这种场景下应该这样说话'。这和写标签有什么区别？……台词就是台词。混在一起写。让AI自己从四百句话里提取模式。"
  summary: |

- id: p36
  title: 台词量要够，否则 AI 回落到资料库

  source_chapter: 3.台词先行（六/七、量和上下文窗口）
  source_quote: |

  summary: |

- id: p37
  title: 混色只写动作，不解释情绪
  type: principle
  source_chapter: 4.混色（四、第四步）
  source_quote: |
    "混色不能解释。一旦你解释'她笑着哭是因为同时感到快乐和悲伤'，AI就会把这当成一个标签去执行。……画面永远只写'她做了什么'，不写'她为什么这样做'。"
  summary: |

- id: p38

  type: rule
  source_chapter: 4.混色（四、第三步）
  source_quote: |

- id: p39
  title: 混色是点睛之笔，不是底色
  type: rule
  source_chapter: 4.混色（五、错误二）
  source_quote: |
    "混色的画面是点睛之笔，不是底色。大部分时间角色的情绪是相对单一的，混色出现在特定的瞬间。如果到处都是混色，那就没有混色了，因为没有反差。"
  summary: |

- id: p40
  title: 禁止用"不是…而是…"和转折词做混色
  type: rule
  source_chapter: 4.混色（五、错误一/四）
  source_quote: |

- id: p41
  title: 核心人格层七件套 + 自查清单

  source_quote: |

  summary: |

- id: p42

- id: p45
  title: 日常不要频繁触发核心恐惧

- id: p46
  title: 二次解释直接叙述想要的样子，不写"不是…"
  type: principle
  source_chapter: 10.大总结-06二次解释篇
  source_quote: |
    "写法上有一个核心原则：直接叙述你想要的样子。不要先列举错误然后否定它。直接说'她是这样的'。……AI读到'不是冷漠'，它脑子里第一个蹦出来的词就是冷漠。你越说不是什么，AI越会往那个方向想。"
  summary: |

    禁止"不是…"句式——AI 越听"不是冷漠"越往冷漠想。每条做两件事：说清特质在你角色身上什么样 + 拦住 AI 最常犯的错。

- id: p47
  title: 二次解释放在人设最后，且不是越多越好
  type: rule
  source_chapter: 10.大总结-06二次解释篇（五/七）
  source_quote: |

  summary: |
    二次解释放所有人设内容最后（基础信息→调色盘→三面性→混色→核心人格层→二次解释），AI 最后读到的记忆残留最强。
    按需详细写：特质易被误读、有反直觉组合、初始关系特殊、不想要某模板时才多写；直观特质可省。

- id: p48

- id: p49
  title: 意象要短、不解释自己、能承载关系、放最后
  type: rule
  source_chapter: 10.大总结-07意象篇（四、原则二三四 / 六）
  source_quote: |
    "原则三：意象要短。意象不是小作文。几段话就够了。原则四：意象不解释自己。……好的意象不只描述角色自己，还能把她和{{user}}的关系动态放进去。……放在人设的最后面。AI读到的最后一样东西，记忆残留最强。"
  summary: |
    意象四原则：短（几段话，力量在浓缩）、不解释自己（写完放那里让它发光）、能承载关系动态（风铃和风/开窗的人）、放在人设最后收尾。
    它是 AI 的"总调性锚"，让后续正文质感往意象方向靠。

  title: 开场白固定文风并尽量完全手写

- id: p52
  title: 用户信息是校准 AI 对用户行为的理解
  type: principle
  source_chapter: 9.用户信息（一/六）
  source_quote: |
    "用户信息不是给AI演的。用户信息是给AI读的。……用户信息的本质是提示词，不是人设。它不是在塑造一个角色，而是在校准AI对用户行为的理解。"
  summary: |

- id: p53
  title: 抢话党用户信息写简化版角色卡：特化+禁止+边界
  type: principle
  source_chapter: 9.用户信息（四、抢话党）
  source_quote: |
    "抢话党的用户信息，本质上就是在写一张简化版角色卡。……核心原则：只写特化部分，不写常态部分。同时写禁止部分。……边界：当剧情进入关键点或危急关头，允许产生新的性格衍生。"
  summary: |
    抢话党（AI 演你）用户信息=简化角色卡：基础信息+外貌只写特化部分+性格调色盘+禁止部分+边界。
    禁止部分拦 AI 反复提特征；边界允许关键时刻产生新衍生（否则 AI 永远在安全区打转）。
  tags: [principle, user-info, talkative-player]

- id: p54
  title: 不抢话党用户信息写行为翻译手册，不写调色盘
  type: principle
  source_chapter: 9.用户信息（五、不抢话党）
  source_quote: |
    "不抢话党的用户信息，核心是：用户行为分析。……你不是在描述自己，你是在给AI一份行为翻译手册。……不抢话党不写调色盘。AI读到调色盘，会拿你的标签去预判你的行为。"
  summary: |
    不抢话党（AI 只演角色并读懂你）用户信息=行为翻译手册：从肢体接触含义、语气措辞真实含义、情绪表达方式、与特定角色互动模式四维度拆解"我做这个动作时是什么意思"。
    不能写调色盘——AI 会拿标签预判行为，你偶尔热情一次反而觉得不对劲。
  tags: [principle, user-info, quiet-player]

- id: p55
  title: 特征后面必须跟禁止说明；不要写"我不是什么"
  type: rule
  source_chapter: 9.用户信息（八、错误三/四）
  source_quote: |
    "你写了'白发'，AI就会在每段描写里都提你的白发。特征后面必须跟禁止说明。……不要告诉AI你不是什么。告诉它你是什么。'{{user}}不是冷漠的人'——AI读到'不是冷漠'，脑子里第一个蹦出来的词就是冷漠。"
  summary: |
    用户信息写特征必须附禁止说明（"白色短发（禁止频繁描写，仅初次见面可插入）"），否则 AI 每段都提。
    禁止"我不是什么"句式，直接写"我是什么"：正面叙述，因为 AI 听到"不是冷漠"会往冷漠想。
  tags: [rule, user-info, forbidden, positive]

- id: p56
  title: 用户信息 token 控制在角色卡四分之一以下
  type: rule
  source_chapter: 9.用户信息（八、错误五）
  source_quote: |
    "用户信息不是主角。角色才是主角。用户信息的token量应该控制在角色卡的四分之一以下。写多了，AI的注意力会被你的用户信息抢走，反而影响角色的表现。"
  summary: |
    用户信息 token 量控制在角色卡的四分之一以下。角色才是主角。
    写多了 AI 注意力被用户信息抢走，影响角色表现；核心行为翻译写清楚就够。
  tags: [rule, user-info, token-limit]

- id: p57
  title: 写卡第一步先定核心驱动力、用户动力、长期性

- id: p58
  title: 定死一个不可动摇的内核
  type: principle
  source_chapter: 6.纯文字卡实战（三、定死不可动摇的东西）
  source_quote: |
    "每个角色身上都有一个'绝对的东西'，一个不管发生什么都不会改变的内核。你要在一开始就把它定死，后面所有的设计都围着它转。……如果你不在一开始定死这个东西，写到后面就会摇摆。AI也会摇摆。"
  summary: |
    每个角色定死一个绝对不变的内核（如姜糖的"偏爱没有输过"），后面所有画面/衍生/面/进化规则都围着它转。
    不定死，你会写出"她差点咬下去"这种摇摆内容，因为自己都没想清楚爱有多绝对。
  tags: [principle, card-design, invariant]

- id: p60
  title: 你写的每个字都在替 AI 选联想词
  type: maxim

- id: p61
  title: 小传是录像带：只写五官能感受到的
  type: principle
  source_chapter: 11.入门平替（第三章 小传）
  source_quote: |
    "小传里只写：她做了什么、她说了什么、她的表情变化、她的身体动作、环境里发生了什么。不写'她觉得'。不写'她心想'。不写'因为'。不写'其实'。……写完检查：删掉所有'她觉得''因为''其实''内心'这些词。"

- id: p62
  title: 情绪阈值表写"触发、过程、怎么结束"
  type: principle
  source_chapter: 11.入门平替（第五章 喜怒哀乐衰）
  source_quote: |
    "每种情绪写三样东西：1.什么触发（从正常状态→进入这种情绪）2.过程（情绪的变化轨迹，不是一个静止画面）3.怎么结束（从这种情绪→回到哪种状态）。"
  summary: |
    情绪表不写情绪的样子（"开心时会微笑"是数据库默认），写情绪的阈值：什么触发、过程轨迹、怎么结束、落到哪。
    写的是条条线：这条线以上进入该情绪、以下出来。情绪之间会串，用矛盾动作让 AI 自己理解。
  tags: [principle, emotion-threshold, entry-level]
