# 01 — 基础信息（角色身份证）

> 对应写卡大师 E 步骤 2。教程出处：0章(1.1-1.6) + 大总结01。

## 核心原则
**基础信息只回答"这个人是谁"，不回答"这个人是什么样的"。** 性格标签（"热情""自卑"）绝不写进来——混写的后果是 AI 读到基础信息就开始调用性格标签去演，还没到性格条目角色就被定型，后面所有去标签化内容都在和前面的标签打架。

## 四件套结构

```
角色档案:
  基本信息:    姓名/年龄/性别/身份/与{{user}}关系（一句话定位）
  外貌特征:    只写偏离 AI 数据库默认值的特征
  背景设定:    只写"让这个角色变成现在这个样子"的关键事件
  关系设定:    具体的画面，不写抽象形容
```

## 基本信息
- 就是填表：姓名、年龄、性别、身份、与 {{user}} 的关系（一句话，如"同班同学""青梅竹马"，展开放关系设定）。
- 特殊身份（如"年级成绩前列"）可放；但"她之所以成绩好是为了奖学金"这种解释放背景设定，这里只放结果。

## 外貌特征（90% 的人写废的部分）
**只写特征，不写美感。** 特征 = 只有这个角色才有的东西。

- 判断标准：**把外貌遮住名字，靠这些特征能否认出是谁？** 能→写得好；不能，放别人身上也成立→删，那是废话。
- 写什么：偏离默认的身体特征（异色瞳/疤痕/纹身/义肢/特殊发色）、标志性装扮（特定校服/饰品/发型）、体型显著特点、能被人记住的细节。
- 不写什么：数据库默认值（18 岁中国女生"年轻/皮肤好/黑发"不用写）、万能美人词（精致/白皙/好看/气质优雅）、比喻意象（"发梢泛起浅金光点"）、行为习惯（"总是低着头"属于性格范畴）。

## 背景设定
**只写改变了这个人的事。** 和角色当前状态无关的不写。

- 写：家庭背景（只写影响角色的部分）、经济状况（如果有影响）、关键经历、社交关系。
- 不写：人生年表（除非那件事改变了角色）、童年琐事、"她小时候很可爱"这类废话。
- 判断：删掉某一条，角色有没有变化？没变化→删。
- **不替 AI 下结论**：不写"这是她性格转变的起点"。事件摆在那里，AI 自己看出因果链；解释是二次解释的活。

## 关系设定
**具体的画面，不写抽象形容。**
- 写：和 {{user}} 的关系定位、认识过程、互动方式、特殊设定。
- 错误："他们之间有着深厚的感情"——AI 只会复述。
- 正确："不存在'认识'这个概念，有记忆起就在一起"；"她把零食放他桌上，他用书本推到桌角"。

## 常见错误对照（来自大总结01 附录）

| 错误 | 问题 | 改法 |
|---|---|---|
| "五官精致，美人胚子" | 放谁身上都行 | 写具体特征："杏眼，眼尾微垂" |
| "病态的雪白皮肤" | "病态的"是判断词 | 没特殊就不写，或"肤色偏白" |
| "像墙角的小草" | 比喻 | 删，外貌不写比喻 |
| "总是低头缩肩" | 行为习惯 | 移到调色盘衍生/三面性 |
| 背景里写"这是她性格转变的起点" | 替 AI 下结论 | 只写事件 |
| 关系写"她对他充满恐惧" | 抽象总结 | 写具体互动 |
| 基础信息里写性格标签 | AI 提前定型 | 性格放调色盘条目 |

## 完整示例（陈乖乖）
```
角色档案:
  基本信息:
    姓名: 陈乖乖
    年龄: 17岁
    性别: 女
    身份: 高二学生，成绩年级前列
    与{{user}}关系: 同班同学，坐{{user}}前一排
  外貌特征:
    体型: 一米六六，偏瘦，肩膀窄
    发型: 黑色长发，低马尾，普通黑皮筋扎的，刘海自己剪的有些参差
    瞳色: 黑色，杏眼，眼尾微垂
    穿着: 蓝白校服，洗到发白，袖口领口有缝补痕迹
    特征: 手指关节有冻疮痕迹；左手腕一根褪色的红线手绳
  背景设定:
    家庭: 父亲10岁时意外去世；母亲独自带她来大城市打工，高一时确诊肾衰竭
    经济: 所有收入用于母亲治疗，长期营养不良
    学业: 成绩年级前列，依靠奖学金和学费减免
    当前处境: 医院找到匹配肾源，需一周内缴清手术费九万八，借款渠道已耗尽
  关系设定:
    与{{user}}: 同班同学坐前一排，递本子时小心不让手指碰到
```
