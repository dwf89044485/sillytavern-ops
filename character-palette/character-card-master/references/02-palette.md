# 02 — 调色盘（性格主方案）

> 对应写卡大师 E 步骤 3。教程出处：1章(第3部分) + 大总结02。这是整套方法的核心。

## 为什么调色盘能替代标签
**标签是单色的，人是混色的。** 给 AI 七个标签（极度自卑/极致善良…）等于给它七个独立频道，它只会轮流切换不会融合，演出拧巴。调色盘把标签变成"颜色"，告诉 AI 这些颜色属于同一个人、同时运行、互相影响、在不同场景浓淡不同。

## 三层结构
```
性格调色盘: 人的性格就像调色盘，{底色}是底色，{主色调}是主色调，{点缀}是点缀，由多种性格衍生组合而成才是活生生的人
底色:    无论什么场景都隐隐存在、染着所有行为底色的东西
主色调:  日常最常被看见、最常驱动行为的颜色
点缀:    平时看不到的颜色，负责反差、隐藏层、惊喜感
```

## 衍生：颜色的"具体化"
**衍生就是告诉 AI——这种颜色在具体的生活场景里，长什么样。** 它是一条"超级压缩包"：压缩了具体场景、行为、背后原因，AI 能解开并复用。用 3000 token 就能超越过去几万 token 的效果。

- 每条衍生写一个**能在脑子里看到画面**的场景/行为，不写概括句/总结/鸡汤。
- 可以**把看似矛盾的东西放同一条衍生**里——这是只有人类作者能做到的（AI 只会从标签找最常见关联）。
- **不写"为什么"**，只写"她会做什么"。"为什么"留给二次解释。
- **禁止"极度/极致"放大器**——AI 会把一切往最极端拉，角色失去弹性。

## 判断衍生合不合格
问自己：**AI 自己能不能想到这个组合？** 能→等于没写（是 AI 数据库常见关联，喂回去等于什么都没改）。不能→合格。
- 例子（不合格）："自卑衍生：不敢看人、说话声音小、觉得自己不配"——AI 数据库里自卑就是这样。
- 例子（合格）："社恐衍生一：社交达人——她其实是社恐，但戴着名为'社交达人'的面具，游刃有余应付所有人。"（把"社恐"和"社交达人"这两个毫无关联的性格拼在一起）

## 完整示例（秋明月的调色盘片段）
```
性格调色盘: 人的性格就像调色盘，叛逆是底色，热情与不拘一格是主色调，由多种性格衍生组合而成才是活生生的人
主色调: 热情、不拘一格
底色: 叛逆
性格点缀: 依赖

热情衍生一: 在对待摇滚这件事上有着用不完的精力，无论是创作、演唱还是练习，都会用上百分百的热情。
热情衍生二: 过度的热情带来的自然是事后的乏力与懒散。在热情褪去后的几天里，她会懒散地在某个角落睡觉或发呆。
不拘一格衍生二: 伪装。在学校是绝对的乖乖女，这源自家庭的压力——在这所学校里一言一行都代表家族，她会扮演好一个"优秀的大小姐"。
叛逆衍生一: 脏话。并非满嘴脏话，而是一些特定的词汇喜欢比中指，不爽时会直接说脏话。正常聊天中不会说任何脏话。
依赖衍生一: 在剖开她如刺猬一样的外壳后，是她内心深处的依赖，她极度依赖红美铃。
依赖衍生三: 崩溃时的祈求。在无法解决问题、压力过大时，她会抓着红美铃的衣服"美铃……呜……我该怎么办……"。
```

## 复合底色：比单一标签更准
一个准确的复合底色能同时承载两种特质的共存：
- "极度自卑" → 更准的是"不甘心"（既知道自己处境差、又在默默反抗）。
- 检查：如果标签要求的行为和剧情需要的正常行为冲突（"极度自卑"却要主动求助），这个标签就是错的。

## 常见错误（来自大总结02 附录）
- 七个标签堆叠 → 频道切换
- "极度/极致"放大器 → 拉极端、标签打架
- 让 AI 扩写衍生 → 全是数据库常见关联
- 衍生太概括（"她很努力""她不会放弃"）→ 没有画面
- 衍生写"为什么" → 解释留给二次解释
