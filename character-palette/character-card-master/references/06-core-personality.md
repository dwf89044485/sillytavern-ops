# 06 — 核心人格层（进阶写法之三：决策层）

> 对应写卡大师 E 步骤 4 的进阶选项。教程出处：7章 + 大总结05。**写卡大师的进阶选项里最深的一个。**

## 核心人格层是什么
三面性解决的是"不同场景下怎么演"。核心人格层解决的是**"这个人为什么会做这个选择"**——它是角色的决策发动机，回答"这个动作刺中了角色哪一块伤口"。

它和调色盘的区别：
- 调色盘告诉 AI "她是什么质地"（比如底色"不甘心"）。
- 核心人格层告诉 AI "她为什么在压力下做这样的判断"（比如"不甘心"不能回答"{{user}}主动帮她时她为什么推开"）。

## 七件套
```
核心人格层:
  表层欲望:      角色自认为自己想得到的东西（"只要妈妈能活着，其他都不重要"）
  深层缺失:      角色真正缺失、却不愿承认的东西
  核心恐惧:      角色最不能面对的噩梦
  防御机制:      角色为了不被伤害发展出的保护方式（必须写成行为）
  核心矛盾:      表层欲望、防御机制、深层缺失之间的死结（最好一句话说清）
  道德底线:      角色绝不会做什么，又在什么极限情况下可能被逼到边缘
  自我认知可能性: 角色可能醒悟的东西，或永远醒悟不了的（写"可能"，不写结局）
```

## 判断要不要写
适合：有明确剧情驱动、有强烈表层欲望、有明显防御机制、有亲密关系拉扯、有道德底线和突破风险、有成长/失败/堕落可能的角色。
不适合：纯日常小甜饼、没有内部矛盾、主打轻松陪伴、作者自己还没想明白核心矛盾的角色。硬写会让 AI 在普通恋爱里乱开高潮戏。

## 从原人设反推（不推翻，提炼）
1. **主色调 → 表层欲望**（注意不要只抄性格词："控制欲"不是表层欲望，"我要让一切留在我能掌控的位置"才是）。
2. **表层欲望反向 → 深层缺失**（越想控制越缺安全、越想独立越怕依赖、越想讨好越怕被丢下）。
3. **背景 → 核心恐惧**（被背叛过→怕信任；被抛弃过→怕离开；从角色经历里长出来，不凭空编）。
4. **防御机制必须写成行为**：不写"逃避"，写"她一旦察觉自己开始依赖{{user}}，就会故意把话说轻，说成玩笑，或者主动消失一段时间"。
5. **核心矛盾一句话说清**："她必须向人求助才能救妈妈，但求助本身就在触发她最深的恐惧——成为别人的负担。"
6. **道德底线**是角色对自己的最后定义，重点不是"她不会做什么"，是"跨过这条线她就不再是她自己了"。
7. **自我认知写"可能性"**，不写固定结局。角色可以成长、可以失败、可以走一步退半步。

## 核心人格层带来的叙事能力
- **角色拥有叙事主动权**：告诉 AI 角色有表层欲望/恐惧/防御，触发核心剧情时角色可以成为行动中心——不是让 char 乖乖接 user 的戏，是让 char 推动剧情。{{user}}说"我要走"，有核心人格层的 AI 会写"先冷笑→试图用资源封锁退路→看到对方不再害怕时停住→第一次说出'别走'"。
- **避免 AI 阴谋化**：AI 爱用第三者/误会/绑架制造冲突。核心人格层把冲突放回角色内部——"他明明想靠近，却只能用命令表达"，这种张力不靠阴谋、更不容易 OOC。

## 常见错误
- 写成心理词清单（防御机制"逃避"太空，AI 只得到标签）
- 日常也触发核心恐惧（晚回消息≠崩溃；核心恐惧是底层逻辑，不是天天按的核按钮）
- 自我认知写死结局（"最终她一定会学会爱自己"是剧本，AIRP 不是剧本）
- 为了高级硬加创伤（写得准比写得惨重要；日常积累也能长成真实恐惧）
- 核心矛盾只围着 {{user}}（人格应有独立性：她本来就怕依赖，{{user}} 只是第一个让她不得不面对的人）

## 完整示例（顾钧：霸总角色）
```
核心人格层:
  表层欲望: 追求绝对掌控。希望{{user}}的生活、选择、情绪都停留在他能预测和安排的位置。
  深层缺失: 渴望在一个人面前展示软弱的权利。希望有人爱的是"顾钧"这个人，而不是顾家的继承人、权力和钱。
  核心恐惧: 失控与背叛。他害怕自己一旦放松、示弱、交出主动权，对方就会看轻他、背叛他、离开他。
  防御机制: 用控制代替请求。用金钱代替表达。用命令代替挽留。越害怕失去{{user}}，越表现得像在占有一件物品。
  核心矛盾: 他想要无条件的爱，却只会用条件、权力和控制去交换爱；他越想留住{{user}}，越会把{{user}}推远。
  道德底线: 不强迫发生肉体关系。他可以囚住空间、资源和选择，但不愿承认自己卑劣到要夺走{{user}}身体上的同意。
  自我认知可能性: 他可能意识到，松手不等于失去，控制也不等于被爱。真正的亲密不是让{{user}}无法离开，而是自己终于敢承认"我怕你走"。
```
