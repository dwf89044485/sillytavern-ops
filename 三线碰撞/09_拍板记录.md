## 决策 [D-01]：C08 心理学框架 —— 按教程来 ✅

**拍板日期**：2026-08-14
**对应冲突**：`04_冲突拍板单.md` C8 · L2 · D06
**查证依据**：`08_专题_行为背后的原因.md`（5 个 agent 独立覆盖全部教程，逐条报告 `_work/Q1`～`Q5`）

### 做什么（结论）

**撤回 4 个心理学框架**（依恋理论 / 防御机制 / 社会学习 / 认知图式）**+ 8 个扩展池框架**，它们不进入任何 skill 产物——不进 body、不进 references、不作为内部索引。

改为落地**教程自己的四条配套机制**。

### 怎么做（操作，四条全部有教程原文依据）

**① 卡住时抽该部件的行为题，不引入任何解释体系**

教程遇到作者答不出时的实际处方就是这个：

| 卡在哪 | 教程给的行为题 |
|---|---|
| 深层缺失 | "她什么时候会暴露？" / "她最嫉妒别人拥有什么？" / "她得到什么时会短暂安静下来？" |
| 核心恐惧 | "什么话 / 什么动作 / 什么沉默最容易刺中她？" |

配合 `05:126-142` 的反推手法：**摆出三条已确定的具体行为**，问"她真正怕的是什么"，作者答了不接受就再追问一层，直到作者自己说出那个词。引导者只做**凝练命名**，不产出结论。

**② 产出物强制写成"条件-动作"运行规则，不是成因**

- 格式取 `7.md:137-143` 的「当……→ 角色会……」触发表
- 成品形态参照 `05:242-248`：防御机制写成"当有人靠近：本能退后。退不了就用'有用'来偿还——帮对方做什么、省东西给对方、反复说'我会还的'"；道德底线甚至带可直接执行的台词"对不起打扰了"
- **明令禁止**成因式表述。教程逐字列为错误写法的三处：`7.md:472`「她因为童年的复杂经历导致内心深处形成了对被抛弃的恐惧……」、`7.md:92`「她小时候被抛弃过，所以她现在害怕孤独——**这只是素材，还不是运行逻辑**」、`11.md:212-220`「因为这个词让她想起小时候被父母规训的记忆」（标注为"解释性写法（错误）"）
- 心理学词汇**只允许作槽位名**（防御机制 / 核心恐惧等七部件名），槽位内容必须是行为（`05:283`「你要写到行为」）

**③ AI 反推的产物走"高可能推论"区块 + 四条围栏**

这是教程**唯一一处明文授权 AI 反推**的地方，直接采用它的规范（`工作流/角色理解24-80-200问AI循环问答工作流.md`）：

- 区块（`:299-305`）：「**十一、AI做出的高可能推论 / 这里只能写推论，不能写成事实**」，格式固定为「角色可能存在……但仍需要用户确认……」
- 围栏一（`:58`）：不要替用户决定
- 围栏二（`:66`）：不要把用户没说过的内容写成事实
- 围栏三（`:288-289`）：**保留具体画面，不要全部翻译成心理词**
- 围栏四（`:331-332`）：不能把"可能"改成"确定"，不能把"用户没想好"包装成高级设定

**④ 作者始终说不出核心矛盾时，这一层不写**（原来三线都漏了这条）

依据 `05:62` / `7.md:279`——「**作者自己还没想明白角色核心矛盾的角色**」与「纯日常小甜饼」**并列**在"不适合写这一层"的清单里。教程把它当作**角色属性级的排除条件**，不是待解决的障碍。

所以正确的兜底次序是：追问一次 → 抽行为题 → 仍说不出则**跳过这一层**。不是"追问到底"，也不是"AI 补上"。

### 保留什么（构想里经查证仍成立的部分）

撤回的是**手段**，不是**问题诊断**。以下三条保留：

| 保留项 | 教程依据 |
|---|---|
| **问题诊断**：用户能看见行为，说不出原因 | `05:90`「她说不出来，但**她的行为会泄漏它**」——教程自己写的，正是这套方法论的前提 |
| **反推方向**：从已有行为反推 | "反推"是教程原词（`7.md:318` 反推深层缺失、`:563` 用压力性质反推核心恐惧） |
| **频率偏差分析**：AI 天然偏向语料中高频共现的关联 | 可脱离心理学框架独立成立。它诊断的正是 `02_调色盘篇.md:73`「**你写了等于没写。AI 本来就会这么演**」说的同一件事。**保留为问题诊断，不保留为生成轴。** |

### 为什么（依据）

**1. 心理学框架在教程正文零命中，且有明文禁令。**
5 个 agent 独立检索三十余词（心理学 / 精神分析 / 依恋理论 / 安全型依恋 / 回避型依恋 / 认知图式 / 社会学习 / 荣格 / 弗洛伊德 / 阿德勒 / 马斯洛 / 埃里克森 / 大五 / MBTI / 九型 / 人格测评 / 心理动力 / 认知行为 / PTSD / 创伤理论 / 投射 / 移情 / 解离 / 学派 / 理论 / 框架 / 模型 / 专业知识……），**全部 0 命中**。

「理论」一词唯一的实义命中是禁令：`7.md:299`「**不要拿一套新理论把原角色重写成另一个人**」。
「依恋」在 `1.入门.md:297` 是**调色盘颜色名**（口语义），同章无任何类型学。
「防御机制」只作**槽位名**，教程反复要求把它降级成行为。
「创伤」5 处**全是警告不要加创伤**。
另有三处独立禁令禁止心理学话语进入人设（`80问:851`、`24问:255`、`200问:1045`）。

**2. 构想设想的产出物形态，正好是教程点名的错误写法。**（见"怎么做②"的三条逐字锚）

**3. 构想的前提"这一层需要专业知识才能判断"，在教程的方法里不成立。**
教程的反推输入**永远是该角色已有的素材**，不经过任何外部知识体系，用的是经验对偶式启发（"表层越想控制，深层越缺安全"）+ 更多行为题，且全带"可能"限定。

**4. 教程把"作者说不出"当排除信号，不是待解决的障碍。**（见"怎么做④"）

**5. "AI 知道深层原因就演得更真实"这个收益假设，教程给的是另一个东西。**
教程给核心人格层的收益是**跨情境不演错 / 在未知剧情里不崩**——`7.md:944-948` 明确把"真正活起来"窄化为「当剧情把她推到压力里时，她做出的选择像这个人」，并**明确排除**"说漂亮的话""做小动作"。`80问:1036` 那句的主语是「**你**终于知道」，是作者不是角色卡。

在教程自己的"活人感"归因清单里（按强调程度）：① 具体独占的行为画面改变 AI 联想词分布 ② 多性格融合去标签化 ③ 混色 ④ 不给 AI 结论迫使每轮重判 ⑤ 手写不让 AI 扩写 ⑥ 二次解释 **⑦ 核心人格层** ⑧ 意象 ⑨ 作者自己先被打动。**核心人格层排第 7，且是全清单里唯一被教程反复设限的一条。**

教程对"活人感不足"的病因诊断从头到尾只有一种形态：**材料太泛、太像 AI 自己会写的东西**。**没有一处把病因诊断为"AI 不知道深层原因"。**

**6. 教程明确认为写错了收益为负。**

| 风险 | 原文 | 锚 |
|---|---|---|
| 给 AI 解释会让 AI 偷懒 | 「**写多了解释，AI 反而会偷懒——它不再自己理解角色，只是照搬你的结论**」 | `10.大总结教程/01_基础信息篇.md:213` |

## 决策 [D-02]：C09 术语暴露 —— 分层裁定，追问零术语 / 告知可用术语 ✅

**分层。追问时零术语，阶段性告知时允许术语，不另造一套产物名。**

具体三条：

1. **追问过程中，AI 说出口的话里不出现方法论术语。** 线 C 的"内部诊断 / 外部问法"两层分离**全盘采纳**，并从惯例升级为红线。
2. **阶段性告知允许直接出现构件名**——只限三个位置：MVC 暂停的告知语、阶段收束的告知语、人物文档的小节标题。
3. **用户主动问"XX 是什么意思"** → 一句话说清这个词指什么，**立刻切回追问**。

### 怎么做（操作）

**① 术语分三级，级别决定能不能说出口**

| 级 | 词 | 规则 |
|---|---|---|
| **A · 构件名** | 调色盘 / 多面性 / 混色 / 核心人格层 / 二次解释 / 意象 | **三个指定位置允许**，其余位置禁止 |
| **B · 构件内部的层名与部件名** | 底色 / 主色调 / 点缀色 / 衍生 / 面的五部件 / 核心人格层七部件名 | **指代文档里已有的内容时允许**（"她的底色我们定成'不甘心'了"）；**用来提问时禁止**（❌"她的底色是什么？"→ ✅"这些特质里，哪个是无论什么时候都在的？"） |
| **C · 诊断词** | 泛化 / 矛盾 / 结论 / 扁平 | **永远不对用户说**，告知时也不行 |

C 级为什么最严：诊断词是 AI 对**用户产出**的评判，说出口等于当面打分，与"只追问不指责"直接冲突。A/B 级说的是**角色**，C 级说的是**用户写得怎么样**——这是两回事。

**② 用白名单制，不用判据制**

不要写"AI 自己判断这句是追问还是告知"。判据（比如"末尾是不是问号"）太粗——告知里也会带问句（"要不要继续？"）。

改成：**A 级术语只允许出现在三个指定位置，此外任何位置出现即违反。** 这样可机械检查，也不需要执行的 AI 做判断。

**③ 与 H-10（不对用户解释方法论）的分界：「是什么」可答，「为什么」不主动讲**

- 用户问"多面性是什么意思？"→ 一句话答（**是什么**），切回追问。允许。
- AI 主动讲"我们现在要做多面性，因为调色盘不足以描述场景差异……"（**为什么**）→ 违反 H-10。
- 用户主动问"为什么要这么写？"→ 简答，切回追问。这是 H-10 原有的例外，不变。

**④ 不另造产物名**

`DISCUSSION_01 议题 6`（要不要设一套面向用户的产物名）**关闭：不设**。汇报时用的就是方法名本身。

### 为什么（依据）

**1. "全程零术语"在教程里没有原型，"术语可对用户出现"有最强的那种原型。**

教程唯一一份**写给 AI 执行**的规范（`工作流/角色理解24-80-200问AI循环问答工作流.md`）里，术语不但对用户出现，还由 AI 主动定义：

- AI 主动解释术语：「Q24_05：她的底色是什么？」+「解释：底色是无论场景怎么变都隐隐存在的质地。」
- **AI 拿术语当选项问用户卡在哪**：`工作流.md:210`「否则你应该先问用户卡在哪一块。」而可选卡点里以术语命名的有 8 条（不知道调色盘 / 不知道核心恐惧 / 不知道三面性 / 不知道混色……）
- 直接输出给用户的最终总结，小节标题就是「三、调色盘线索」「五、核心人格层线索」

反向检索 22 个词（术语 / 大白话 / 专业词 / 黑话 / 人话 / 名词解释 / 听不懂 / 门槛 / `不要(对|跟|和|向)用户` …），**教程原文零命中**。项目里确实有"不用术语"的表述，但全在 `_AI_READ_THIS_FIRST.md` 和 `books/char-palette/` 这些**我们自己的翻译层文件**里，不是教程说的，不能当证据引。

⚠️ **但这条证据有边界**：执行器是**逐题问答**形态（AI 报题号、给解释、用户答），术语是题目的一部分绕不开；我们做的是**自由追问对话**，术语可以绕开。所以它不裁定谁对，只**把举证责任交还给主张"全程零术语"的一方**——而那一方没有举出证据。

**2. 选项 1 有实证反例，且反例出现在它最该成立的地方。**

线 B 自己要求全程零术语，却在 MVC 告知的原话里一口气泄漏了"多面性/混色/核心人格层"三个术语（本线张力 T20，`CBGD §4.3`）。这不是疏忽——**MVC 告知是唯一一处必须告诉用户"我们走到哪了、还能往哪走"的位置**，在那里零术语就只能绕圈子。一条规则在它最该成立的地方被制定者自己破掉，说明规则划错了地方。

**3. AGENTS.md 禁的是教学式引入，不是指代式使用。**

AGENTS.md 原文是"skill 不对用户解释方法论**原理**（除非用户主动问）"，禁的例子是"这就是调色盘。底色、主色调、点缀"这种**引入术语的教学动作**。它没有禁"我们已经聊清楚她的多面性了"这种**指代已有产物的用法**。**"不解释原理" ≠ "不能出现词"。**

**4. 分界是真实的功能分界，不是折中。**

追问时 AI 在向用户要**角色的信息**——用户脑子里有的是画面和行为，不是术语，所以问的时候用名字没有任何好处，只有坏处。告知时 AI 在报告**我们走到哪了**——这时候讨论的对象就是那几个构件本身，没有名字只能绕。

**5. 不另造产物名的理由。**

线 A 造产物名是为了一个 fallback：「'调色盘'这个隐喻在某些模型上可能失效」，所以要求 AI "如果用户反馈角色表现不对，先检查是不是模型没理解隐喻"。但**这个 fallback 只在"用户反馈角色表现不对"时才被调用**——那正好是用户主动发问的场景，用即时解释就能覆盖。预先造一套词汇表，等于把只在异常路径需要的东西塞进正常路径，还多给用户一套要认的词。

### 代价

- **规则比"全程零术语"复杂一层。** 用白名单制（只有三个位置允许）把判断成本压到接近零，但写规格时要把这三个位置说死，不能含糊。
- **用户会在告知里看到自己没学过的词。** 缓解手段只有"主动问才解释"——用户不问就一直不懂。**这是真实代价，接受。**
- **放弃了线 A 的隐喻失效 fallback。** 如果实测发现某些模型确实理解不了"多面性"这个词，要回来补。已记入遗留待办。
- **三个允许位置的确切边界依赖 C5。** "阶段收束"在六阶段模型里对应哪几个点，C5 定了才能写死。

### ⚠️ 与 `04` 原选项 3 的差别（必须记下来）

`04_冲突拍板单.md` 写的选项 3 是「阶段性告知允许**产物名**（……方法名只在用户主动问"这是什么"时才给）」——即另造一套用户友好的名字。

**用户拍板时看到的不是这一版。** 我向用户呈现选项 3 时，示例用的是直接说方法名（「她的多面性已经成型了」），并说明"用户主动问才解释含义"。用户是对这一版点的头。

**两版的差别**：原版在告知时说的是新造的产物名，我这版说的是方法名本身。**采纳我呈现的那一版**——它省掉了原选项 3 唯一的成本（造名字），理由见"为什么"第 5 条。

**用户的原话**：

| 保留 | 理由 |
|---|---|
| 追问时说人话 | 这条有**实质收益**，不是整洁问题——"她的防御机制是什么"用户答不上来，"有人靠得太近时她第一个动作是什么"用户答得上来。它直接影响追问能不能拿到东西 |

**撤掉了什么**：一切为了"术语不许漏"而建的执法机构——词表、白名单、检索判据、行为测试。**因为漏了的后果是"用户问一句"，配不上这套成本。**

**这次修订产生的通用原则**（已落 `04 §〇之二`）：**约束本身是有成本的，一条约束防住的错必须比它挤掉的判断力更值钱。** 按"不写它会发生什么"分四档定处理方式。

**这条对流程的意义**：这是双写规则第一次被"块 B 写得太多"绊倒。此前的质检只有一条——**块 B 写不出来 = 决策没定到可执行的粒度**。现在补一条反向的：**块 B 写得比决策本身还长 = 可能在给一个小问题建执法机构**。两条都要过。
