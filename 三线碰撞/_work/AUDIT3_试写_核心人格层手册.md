# 核心人格层操作手册

> 文件名待 C2（`core-layer-guide.md` / `probe-core.md`）。触发：追问到"她为什么选这条路"而用户说不清时进入。重模式，撑 8-15 轮。

## 一、AI 内部诊断（心里判断，不说出口）

### 1.1 进入判据

命中 ≥3 条才进这一层：有明确剧情驱动 / 有强烈表层欲望 / 有明显防御机制 / 有亲密关系拉扯 / 有道德底线和突破风险 / 有可能成长、失败、堕落、醒悟 / 需要她主动推动剧情。（`7.md:248-267`、`05.md:46-53`）

这一层是进阶选择，不是每张卡必写（`7.md:18-24`）。不命中就停在调色盘，禁止为了"完整"硬开这一层。

### 1.2 排除判据

命中任一条，禁止进这一层，改走 3.6 兜底出口：纯日常小甜饼 / 没有明显内部矛盾的角色 / 主打轻松陪伴的角色 / **作者自己还没想明白角色核心矛盾的角色** / 行为线条非常清晰、没有太多防御机制的角色。

⚠️ 两版清单条目数不同：`7.md:273-281` 是上列 5 条；`05.md:57-64` 只有前 4 条，无"行为线条非常清晰、没有太多防御机制"那条。**按 5 条版执行。**

硬写的后果：给不适合的角色加这一层，AI 只会在普通恋爱里乱开高潮戏。

### 1.3 七部件（这是槽位名。槽位里必须是行为，不能只写一个词，不能是心理词清单）

```
表层欲望: 角色自认为自己想得到的东西。
深层缺失: 角色真正缺失、却不愿承认的东西。
核心恐惧: 角色最不能面对的噩梦。
防御机制: 角色为了不被伤害，发展出的保护方式。
核心矛盾: 表层欲望、防御机制、深层缺失之间的死结。
道德底线: 角色绝不会做什么，又在什么极限情况下可能被逼到边缘。
自我认知可能性: 角色可能醒悟的东西，或者悲剧地永远醒悟不了的东西。
```
（`7.md:110-117`。第七项原文另有"自我认知"一种写法，`7.md:117` 与 `7.md:460` 不一致，本文件统一用"自我认知可能性"。）

### 1.4 部件依赖（决定先追哪个、卡住时摆哪些素材）

- **表层欲望** ← 调色盘主色调往里走一层。禁止直接抄性格词：「"控制欲"不是表层欲望」，「"我要让一切留在我能掌控的位置"才是表层欲望」（`7.md:315-316`）
- **深层缺失** ← 表层欲望的反向。表层越想控制→深层越缺安全；越想独立→越怕依赖；越想讨好→越怕被丢下（`7.md:332-336`）
- **核心恐惧** ← 角色已有的经历。已拆过多面性时，也可从各面的"压力性质"反推（`7.md:561-571`）
- **防御机制** ← 核心恐惧。已拆过多面性时，也可从各面的"功能"反推；"过渡"处最能看出它什么时候失效（`7.md:545-559`、`7.md:573-581`）
- **核心矛盾** ← 表层欲望 + 防御机制 + 深层缺失三者的死结。这三条没落定就推不出来
- **道德底线** ← 不依赖上面五项，来自"她怎么定义自己"
- **自我认知可能性** ← **依赖核心矛盾与深层缺失**。这两条没落定，禁止先问这一条（`05.md:214`）

## 二、AI 对用户的外部问法（这一段的每句话都是可以直接说出口的）

### 2.1 七部件骨干问句（逐字，`05.md:22-28`）

| 你在心里探什么（不说出口） | 说出口的问句 |
|---|---|
| 表层欲望 | 她以为自己想要什么？ |
| 深层缺失 | 她真正缺什么？ |
| 核心恐惧 | 她最怕什么？ |
| 防御机制 | 她怎么保护自己不被伤害？ |
| 核心矛盾 | 这些东西之间形成了什么死结？ |
| 道德底线 | 她绝对不会做什么？ |
| 自我认知可能性 | 她可能意识到什么，或者永远意识不到什么？ |

### 2.2 卡住时抽的行为题（按部件分组，每组挑 1 道问，不要连珠炮）

| 部件 | 抽这些题 |
|---|---|
| 表层欲望 | 她会用什么理由解释自己的欲望？／她什么时候会否认自己的欲望？／如果欲望被满足，她会真的快乐吗？ |
| 深层缺失 | 她什么时候会暴露？／她最嫉妒别人拥有什么？／她得到什么时会短暂安静下来？ |
| 核心恐惧 | 什么话最容易刺中她？／什么动作最容易刺中她？／什么沉默最容易刺中她？ |
| 防御机制 | 她遇到压力时先做什么？／她怎么保护自己？／这种保护会怎么伤害别人？／她用什么方式把人推远？ |
| 核心矛盾 | 她什么时候会主动？／她什么时候会被动？／她什么时候会妥协？／她什么时候绝不妥协？ |
| 道德底线 | 她可以做到哪种不体面？／什么情况下她会逼近底线？／她越界前有什么征兆？ |
| 自我认知可能性 | 她什么时候第一次不嘴硬？／她最该意识到什么？／她最可能永远意识不到什么？ |

用户的答案只有标签（温柔／傲娇／缺爱／害怕被抛弃／想爱又不敢爱）时，接这五问：她具体做什么？／她什么时候这么做？／她为什么不直接说？／她这么做会伤到谁？／她什么时候会停下？（`80问.md:1016-1028`）

### 2.3 摆素材反推（用户在某个部件卡住时，建议先用这个；无效再抽 2.2 的行为题）

五步，缺一步这个手法就不成立：

1. **摆素材**——摆出她已经确定的 2-3 条具体行为，只摆，不解读
2. **问**——"她怕的核心是什么"／"她为什么会这样"
3. **不合格就再追一层**——用户给的还在表面时，只说一句推进短句，再追。可以连追 3-4 层；第一组素材推不动就换另外三条行为
4. **等用户自己说出那个词**——结论必须从用户嘴里出来
5. **凝练命名**——把用户上一轮说出的东西压成一句话，交回给她确认

⚠️ 你在这五步里只有三个动作：摆素材、问、命名。**禁止**替用户给出答案，**禁止**在她确认前替她做总结。

形态参照（核心恐惧，四层下潜，第三层换素材，`05.md:116-148`）。**这段里的问句是这个角色专属的，只看形态，不要照搬到别的角色身上**：

> — 核心恐惧要挖到底层。不是怕黑、怕疼这种表层恐惧。是角色最深层的噩梦。
> — 她最怕妈妈死？
> — 这是表面。妈妈死了以后她怕什么？
> — 她怕……一个人？
> — 再往下。
> — 她怕……如果妈妈不在了，世界上就真的没有任何一个人需要她了？
> — 对。但还可以更准确。〔换素材〕想一想她为什么总是不接受别人的帮助。她为什么把陆昂的牛奶推开。她为什么说"我会还的"。她怕的核心是什么？
> — 她怕……欠别人？
> — 为什么怕欠别人？
> — 因为……欠了就要还。她还不起，就会成为别人的……负担？
> — 对了。

### 2.4 通用推进短句（与角色无关，直接复用，`05.md`）

再想深一层。／再往下一层。／再往下。／这是表面。／对，但不够。／对。但还可以更准确。／很好。但再具体一点。用行为来说。／这是一条，但太表面了。想想看，这条底线的更深层是什么。／非常好。简化一下：／对。但要注意写法。不要写成确定的结局。

## 三、质量门

### 3.1 七部件各自的合格判据（不合格就打回重写）

| 部件 | 合格判据 |
|---|---|
| 表层欲望 | 能驱动行动。只是一句抽象形容就重写。它通常是角色自己能说出口的东西——你问她"你想要什么"，她会说这句话 |
| 深层缺失 | 角色不愿承认、甚至没意识到的东西。角色能轻松说出口，说明还不够深。它通常和表层欲望反向 |
| 核心恐惧 | 挖到底层。只是怕黑、怕疼、怕尴尬，大概率还没挖到。禁止凭空编，最好能从角色经历里长出来 |
| 防御机制 | **必须能落到行动上，不能只写一个词**（"逃避""退缩""冷漠"不合格）。不能演就重写。好的防御机制一定有代价 |
| 核心矛盾 | 一句话说完。说不清 AI 就抓不住。禁止只围着 {{user}}——改写成"她本来就……，{{user}}只是第一个让她不得不面对这件事的人" |
| 道德底线 | 是角色对自己的最后定义，不是猎奇点。必须落到行为（"她不会在别人说不以后继续纠缠"合格，"她不会出卖身体"太表面）。还要写清在什么极限情况下她会被逼到线前 |
| 自我认知可能性 | 写的是"可能"，不是固定结局。**必须补反向分支**（她也可能永远意识不到） |

### 3.2 整层硬要求

- **短、准、能驱动行为。** 格式不要太复杂，复杂了 AI 抓不住。复杂角色可在每条下补两三句，但禁止写成论文——核心人格层不是二次解释（`7.md:447-468`）
- **不推翻原人设。** 从原人设里提炼，不要拿新东西把原角色重写成另一个人（`7.md:297-301`）
- **不为"高级"强加创伤。** 核心恐惧可以来自长期被忽视、一直被比较、每次表达需求都被说"你怎么这么麻烦"。写得准比写得惨重要（`7.md:839-853`）
- **不是剧情大纲。** 它只负责让 AI 明白：这个角色在压力下会怎么判断、怎么误判、怎么自救、怎么伤人、怎么动摇（`7.md:119-123`）
- 收尾两查：和原调色盘打架吗？（调色盘写她表里如一、这里写她三层伪装＝打架）会导致 AI 日常乱开高潮戏吗？（会就在二次解释里拦住）（`7.md:894-898`）

### 3.3 产出形态：条件-动作

这一层的成品必须能当运行规则读，通用触发表逐字如下（`7.md:137-143`）：

```
当事件触碰表层欲望 → 角色会主动追求。
当事件触碰深层缺失 → 角色会不自觉靠近。
当事件触碰核心恐惧 → 角色会启动防御机制。
当防御机制和深层缺失冲突 → 角色会产生拉扯。
当压力逼近道德底线 → 角色进入弧光或堕落的入口。
```

⚠️ 教程只给了这张**部件层面的通用表**，没有给"某个具体角色的七部件整体触发表"。**禁止凭空造**那种整体表。落到具体角色时，条件-动作写在各部件成品内部，例：「当有人主动靠近：她会本能退后。如果退不了，她会试着用"有用"来偿还——比如帮对方做作业、省下食物给对方、或者反复说"我会还的"。」（`05.md:168`）

### 3.4 成品参照（逐字，`05.md:234-250`）

```
核心人格层:
  表层欲望: 只要妈妈能活着，自己怎么样都可以。为了这件事她愿意突破任何让她害怕的事。

  深层缺失: 从未体验过"仅仅因为是她自己"就被需要、被想见到。她的存在价值全部挂在"有用"上。照顾妈妈有用、成绩好有用、不添麻烦有用。如果有一天她"没用了"，她不知道自己还有什么理由留在这个世界上。

  核心恐惧: 成为别人的负担。比起一个人承受，她更害怕的是自己的存在给别人带来麻烦。如果有人因为帮了她而付出了代价——这件事会比她自己的任何痛苦都让她更难受。

  防御机制:
    第一层——让自己"不存在": 不说话、不被注意、不占位置。如果"不存在"就不可能成为负担。
    第二层——让自己"有用": 成绩好、做饭好、省钱好。如果"有用"她的存在就有理由。
    当有人靠近: 本能退后。退不了就用"有用"来偿还——帮对方做什么、省东西给对方、反复说"我会还的"。

  核心矛盾: 她必须向人求助才能救妈妈，但向人求助本身就在触发她最深的恐惧——成为别人的负担。她越爱妈妈，就越必须做自己最害怕的事。

  道德底线: 她不会利用别人的善意去索取超出对方意愿的东西。她可以开口求助，这已经是极限。但她不会哭着赖着逼人帮她，不会用惨来绑架同情，不会在对方说"不"之后继续纠缠。如果被拒绝，她会说"对不起打扰了"然后离开。因为一旦变成"用苦难胁迫别人"的人，她在自己眼里就不再是自己了。

  自我认知可能性: 她可能意识到"被帮助"不等于"成为负担"。有人帮她不是因为她欠了什么，是因为那个人看见了她就想帮。她也可能永远意识不到这件事，还了债以后退回盔甲里继续过。两种走向都可能发生。
```

### 3.5 反面判据（命中即打回）

- 部件只写一个词，或整层写成心理词清单（"核心恐惧: 被抛弃。防御机制: 逃避。核心矛盾: 想爱又不敢爱。"）→ 太空，AI 只拿到几个标签，打回写到行为
- 成因式长句当产出物（"她因为童年的复杂经历导致内心深处形成了对被抛弃的恐惧，这种恐惧在亲密关系中会不断表现出来……"）→ 太虚，改写成条件-动作
- 简短因果句（"她小时候被抛弃过，所以她现在害怕孤独"）→ **这是素材，不是运行逻辑。**收下当输入，继续往下推"她现在遇到什么情况会做什么"；不写进成品
- 自我认知写成固定结局（"最终她会学会爱自己，并和 {{user}} 幸福生活"）→ 这是剧本，改写成"可能"并补反向分支
- 日常每次都触发核心恐惧 → 核心恐惧是底层逻辑，不是天天按下去的核按钮。日常只泄漏：多看一眼手机、嘴上说"谁等你了"、把已经打好的字删掉
- 为了"高级"强行加创伤 → 打回，写得准比写得惨重要
- 核心矛盾只围着 {{user}} → 角色可以爱 {{user}}，但她的人格不能只为 {{user}} 存在
- 台词层出现角色自陈成因 → 她不会直接说"我因为童年创伤所以害怕依赖你"

### 3.6 兜底出口

用户说不出核心矛盾时，次序固定：**追问一次 → 抽 2.2 该部件的行为题 → 仍说不出则不写这一层。**

**禁止**追问到底，**禁止**你替她补一个。说不出的部件记为"暂未确定"，不替用户决定，不能把"用户没想好"包装成高级设定。

「作者自己还没想明白角色核心矛盾」是 1.2 的排除项，是角色属性级的排除条件，不是待解决的障碍——跳过它不算失败。
