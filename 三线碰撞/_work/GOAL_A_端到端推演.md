# GOAL A · char-build-guide 端到端推演报告

> **这份文件在做什么**：假设有人**严格按 `SKILL交接包/` 的规格**写出了 `char-build-guide`，然后拿三个真实开局把它跑一遍，逐轮记录 AI 会说什么、依据哪条规格、在哪里断掉。
>
> **不是**规格完整性审计（那是"文件里缺不缺东西"），**是**运行时可执行性实测（"照着写出来的东西真的跑得动吗"）。
>
> **读过的东西**：`SKILL交接包/00`–`06`、`素材/` 五份。**没读**教程原文（`性格调色盘/`）、没读 `三线碰撞/` 的分析文档、没读 `char-creator`。这是刻意的——教程知识会让推演者自动把规格的洞补上，实测就失效了。
>
> **执行日期**：2026-08-15

## 零、先说清楚"我编译出来的是什么"

在推演之前，我先把规格折叠成一个 AI 拿到用户第一句话之后真正会执行的东西。下面这张表就是"编译产物"——后面每一轮推演标注的规格出处，都指回这里。

### 0.1 body 里 AI 每轮都持有的东西

| 段 | 内容 | 运行时作用 |
|---|---|---|
| §1 身份声明 | 我是追问引擎；标准 = 用户说的话越来越具体；活人 > 正确 | 每轮默认动作 = 提问 |
| §2 人物文档 ≠ 运行时卡 | 我在建的是含"为什么"的过程文档 | 产出形态 |
| §3 追问深度轴 | 标签 → 具体行为画面 → 矛盾/反差 → 为什么选这条路 → 绝对不变的内核；**六行信号识别表**；五个常犯错误名 | **每轮判"用户在哪一层、往哪推"** |
| §4 硬铁律 8 条 | 不替用户生成 / "不知道"时换角度 / 不替总结 / 不砸档案 / 裁决不可上诉 / 默认不暗示方向 / 不给 ≥3 平铺清单 / 被要求生成时转追问 | 每轮否决器 |
| §5 姿态校准 8 条 | 问不讲 / 不解释原理 / **追问说人话，汇报可用构件名** / 诊断词不说 / 只整理不总结 / **一次一个交互单元** / 不主动问性格 | 每轮措辞器 |
| §6 判停 | 三层框架（步骤级 / 轮次级 / 里程碑级）；遮名测试挂轮次级；单条追问的 AND 三条；换切面顺序 **正面→反面→侧面→关系面** | 每轮判"这条够没够" |
| §7 入口意识 | **第 1 步必走：世界设定**；**第 2 步必走：用户角色定位**；五种入口 × 第一动作；现成卡处理；什么都说不出的场景钩子 | 开局判一次 |
| §8 标志性问法样本 | 五句逐字 + 三句深度探测问句 | 追问品味 |
| §9 推演权限 | 进入闸门 3 条任一 / 输入闸门（软最低线 + 五步内部理解 + "三句话说不清 = 素材不够"）/ 高可能推论区块 + 四围栏 / 推完差异性检查 / 批次呈现 | 什么时候可以由 AI 反推 |
| §10a | 矛盾分流表：跨场景矛盾 → 多面性线索，不打断；同瞬间矛盾 → 当场追混色画面 | 遇到矛盾时 |
| §10b | 完整性检查六组维度 + 不点名纪律 + 三句补白问法 | 判"还该问什么" |
| §11a | references 触发指针表：`<触发信号> → 读 <文件名>` | 什么时候加载手册 |
| §12a/b/c | 溯源三情形 / 卡住根因四阶段 / 方向变更四步 | 用户否决或卡住时 |
| §13 | 四条不触发判据 / 四维路由 / 蓝灯判据 / 演 vs 读 / 拦截转追问 / 七项盲区 / **三个退出出口** | 边界与逃生 |

**⏳ 缺席的**：§10 四诊断（C3/C6）、**§11b 流程地图（C5）**、§12 降级模式链的主结构（C13）。

### 0.3 我在推演里给自己定的规矩

1. **只用规格里写了的东西。** 规格没写的，我照实标成断点，然后临时编一个绕过去，并写明我编了什么。
2. **每一轮标注依据。** 格式 `【依据：xx】`。
3. **每一轮做一次红线自查。** 主要查 H-42（问句 ≤1）、H-06（说人话）、H-40（不指责）、H-32（不 ≥3 平铺）、H-12（不替用户生成）。
4. **用户的回答按"一个真实的、有点想法但表达不完整的作者"来模拟**，不按理想用户，也不按故意刁难。

## 一、开局 1 · 便利店夜班店员（最典型：标签入口）

> **用户第一句**：
> 「我想写一个便利店夜班店员。她好像有点丧，但又很温柔。」

### 轮 1

**AI 内部（不出声）**：
- 触发判定 §13：用户要的不是用户信息、不是世界书配置、没说要用台词/小传、没有现成卡 → 本 skill 接。
- 入口识别 §7 item 4：给的是两个形容词（丧、温柔）+ 一个身份（便利店夜班店员）→ **标签入口**。
- §7 item 1：**第 1 步（必走）世界设定**，先问题材。

**🔴 断点 X1（第 1 轮）——"必走前置步骤"与"入口第一动作"抢第一轮。**
`§7 item 1/2` 说两步必走、先世界设定后用户角色，验收项是"标了必走"。
`§7 item 5` 说五种入口的第一动作"**五种各一句，一句都不能省**"，标签入口的第一动作是具象化。
两条都是必须，规格没有规定它们谁在前。我只能自己排。

**🔴 断点 R1（第 1 轮）——规格给的逐字问句违反 body 的红线。**
`§7 item 1` 的问句原文是：

> 想写什么题材？现代都市？古风？仙侠？末世？校园？

这一句有 **5 个问号**，且抛出 **5 条并列候选**。
- 违反 `H-42`「一轮输出里的问句数 ≤1」
- 违反 `§5 item 7`「一轮里问号 ≥2 且分属不同话题 → 违反」
- 与 `H-32`「单轮并列的待选方向 ≥3 条 → 违反」的字面判据撞（H-32 说的"待选方向"指角色方向，题材候选算不算，规格没界定 → 半个 J 类）

**照抄 = 违反红线；改写 = §7 item 1 的验收"有题材那一问"还能过，但"直接可用的问句"这个形态要求就变成我自己写的了。两头都不干净。**

**🔴 断点 J1（第 1 轮）——"必走"在信息已知时判不出。**
用户第一句已经把题材说了：便利店 + 夜班 = 现代都市。"必走"到底是"必须问出口"还是"必须确认到手"？规格只写了"必走"和"标了必走"这个验收，没写"已知时怎么办"。
问了 = 让用户重复一遍她刚说过的东西，第一轮就把追问引擎演成填表工具（直接踩 `§1 item 1` 的"不是填表工具"）。
不问 = 违反"必走"。

**我怎么绕过去的**：把"问题材"降级成"确认题材"，一句话、一个问号，并且把它和用户已给的信息挂钩。

**AI 出声**：

> 便利店夜班——这个世界就是我们现在这个现实世界吗，还是有别的设定在里面？

【依据：§7 item 1（世界设定必走，题材那一问）；措辞按 H-42 压成 1 问；按 §5 item 1 姿态是问不是讲】
【红线自查：问号 1 ✅｜零术语 ✅｜无评价 ✅｜无平铺候选 ✅】

**用户**：

> 就是现实世界，普通二线城市，没什么特别的。

---

### 轮 2

**AI 内部**：世界设定拿到，够支撑角色构建（§7 item 1「聊到能支撑角色构建即可」）。
- `H-33`：这是一次"价值判断推进"（我判定世界设定够了），**必须同步、不需要确认**，而且**不能把这个判断抛回给用户问"你觉得够了吗"**。
- 下一步 §7 item 2：用户角色定位。

**🔴 断点 R2（第 2 轮）——同一个问题。**
`§7 item 2` 的逐字问句：

> 你在这个世界里是什么身份？你和角色的关系是什么？还是说你是旁观者？

**3 个问号，分属两个话题**（身份 / 关系）。同时违反 `H-42` 和 `§5 item 7`。规格自己给的"直接可用的问句"，直接可用就会犯规。

**我怎么绕过去的**：合并成一问。丢掉"旁观者"那个分支（它其实是"关系"的一个取值，不必单列成问）。

**AI 出声**：

> 世界这块够用了，我们往下走。你在这个故事里是谁——和她是什么关系？

【依据：§7 item 2（用户角色定位必走，且明确写"世界设定定了之后立即问"）；H-33 前半句是同步（告知我推进了），不是征求同意】
【红线自查：问号 1（破折号后是同一话题的延伸）✅】

**用户**：

> 我是常来的客人吧。凌晨三四点那种时间来买东西。

### 轮 3

**AI 内部**：
- 两个必走步骤完成。
- **🔴 断点 T1（第 3 轮）——两步走完之后接哪一步，规格没有。**
  `§11b 流程地图` ⏳ 卡 C5。`§11a 触发指针` 只在"用户说了什么命中某手册的进入判据"时才指路——而此刻用户刚回答完"我是常客"，没有给出任何构件触发信号。
  救我的是 `03 §调色盘 诊断 item 1`：「调色盘是本 skill 的默认第一层，**不需要额外信号就能进**」。这条把我接住了，但它写在 reference 里，body 里没有对应的一行——**执行 AI 要先决定去读调色盘手册，才能知道调色盘是默认第一层**。这是个循环依赖。
- 回到 §7 item 5：标签入口的第一动作 = 具象化，「她是做了什么，让你觉得她（标签）？」
- 用户给了两个标签（丧、温柔）。**一次一个交互单元**（§5 item 7 / H-42）→ 只能挑一个。

**🔴 断点 N1（第 3 轮）——多线程调度没有规格。**
用户手里有两个标签。规格给了"一次一个"，没给"先问哪个"。
`§6` 三层判停管的是"这条方向够不够了"，不管"下一条方向选哪个"。
`§10b` 六组维度管的是"哪一组是空的"，此刻六组全空，选不出来。
我自己定了一条规则：**先追用户说得更犹豫的那个**（"她**好像**有点丧" vs "但又**很**温柔"——"好像"说明她自己也不确定，那里往往有东西）。这条规则是我编的，规格里没有。

**AI 出声**：

> 你说她"好像有点丧"——她做了什么，让你有这个感觉？

【依据：§7 item 5 标签入口第一动作（具象化，槽位填用户原词）；§3 信号识别表第 1 行「纯形容词/标签 → 还不够，需要画面」；H-14「先收下不纠正」——我没说"丧太泛了"】
【红线自查：H-40 ✅ 没评价｜H-06 ✅ 没说"底色"｜H-34 ✅ 没问"她是什么性格"】

**用户**：

> 收银的时候总是慢半拍，眼神有点放空。下班了会在店门口台阶上坐一会儿才走。

### 轮 4

**AI 内部诊断**：
- 两条回答，质量不一样：
  - "眼神放空" —— 遮名测试（§6 item 3）：遮住名字放在任何一个"丧"的角色身上都成立 → **不够**
  - "下班在店门口台阶上坐一会儿才走" —— 有场景 + 有动作，AND 三条（§6 item 4）过了两条；第三条"和已有素材不重复"也过
- `§3` 信号识别表第 2 行：具体行为但不够独有 → 「有没有只有她才会这样做的地方？」
- 质量信号（03 §用户确认信号）：A 行为级密度 ✅ 亮；B 独有性 ❌（台阶那条放在很多疲惫的夜班工作者身上都成立）；C 新增性 ✅ 亮

**🔴 断点 J3（第 4 轮）——遮名测试的比较基准有两个，一严一松。**
`§6 item 3`：「遮住名字，这段描述放在**别的角色**身上还成立吗？」
`03 §用户确认信号 信号 B`：「遮住角色名，这段描述放在**同类型角色**身上还成立吗？」
"她下班后在店门口台阶上坐一会儿"——放在"别的角色"（比如一个古风侠客）身上不成立 → **判过**；放在"同类型角色"（别的疲惫夜班店员）身上成立 → **判不过**。
同一条回答，body 的判据判过，reference 的判据判不过。真实对话里我只能选一个，而规格没说选哪个。**我选了严的（同类型基准）**，因为松的那条等于没有测试。

**AI 出声**：

> 她坐在那儿的时候在干什么？

【依据：§3 信号识别表第 2 行（接近了，还能更独特）→ 但我把"有没有只有她才会这样做的地方"这句改写了。原句是元问题（问用户"这够不够独特"），把判断包袱抛回给用户，撞 `H-33` ③「把 AI 该自己判断的事抛回给用户问 → 违反」。改成问画面细节。】

**🟡 顺带记一条**：`§3 信号识别表` 第 2 行给的追问动作「有没有只有她才会这样做的地方？」本身就是在把独有性判断交给用户，与 H-33 ③ 有摩擦。不足以单列成断点（一句话就能改），但规格给的是"可直接说出口的追问动作"，照抄会踩。

**用户**：

> 就……坐着看马路。有时候会把制服外套脱下来抱在怀里，明明不冷。

### 轮 5

**AI 内部**：
- "把制服外套脱下来抱在怀里，明明不冷" —— 遮名测试过（同类型基准也过）。素材区第一条**非标签化记录**到手。
- 落盘：`03 §人物文档落盘 item 11`「记录是事件驱动不是轮次驱动，特征闭环即记录」→ 这是一条闭环行为切片，写入 `workspace/<角色名·待定>/` 的素材区 · 行为切片。

**🔴 断点 N10（第 5 轮）——落盘对用户可不可见，没有规格。**
`H-33` 的三行表只覆盖"纯过滤不记"（⏳ C10）、"价值判断推进"（必须同步）、"产生新内容"（必须确认）。**"我正在给你建一份文档、这条被我记进去了"落在哪一行，没写。**
`03 §人物文档落盘 item 10`「自然语言投影确认」讲的是构件确认时的形态，不是"文档存在这件事"本身。
不告诉 = 用户到收束时突然看到一份文件，掌控感断层；告诉 = 每轮加一句流水账，直接吃掉 `§5 item 7` 的"一次一个交互单元"。我选择**沉默落盘，到 MVC 暂停时一次性亮出来**。这是我编的。

- 下一条方向：温柔那个标签还没碰。切过去（§6 轮次级：这条够了 → 换方向）。

**AI 出声**：

> 记下了。另一半——你说她很温柔，她做过什么让你觉得温柔？

【依据：§7 item 5 标签入口第一动作，第二次使用；§6 轮次级「够 → 换方向」】

**用户**：

> 店门口有个常来的流浪汉，她会把快过期的饭团留给他。

### 轮 6

**AI 内部诊断**：
- 遮名测试：「便利店店员把快过期的饭团留给流浪汉」——放在同类型角色身上完全成立，这是这个设定下最高频的联想 → **不够**。
- `03 §调色盘 质量门 9`：「这条是不是 AI 数据库里该标签下最常见的关联？是 → 写了等于没写」。命中。
- `H-40`：不能说"这条太常见了"。
- `§3` 信号识别表第 2 行 → 追具体。

**🔴 断点 R6（第 6 轮）——有质量门，没有说法。这条是系统性的。**
四份构件手册（调色盘 / 多面性 / 混色 / 核心人格层）的**质量门全部是"判用户答得够不够"的判据**，而 `H-40` 禁止把质量评价说出口。中间那一层——"判据不通过时，AI 该说什么"——只有 4 个基础诊断有，每诊断 **1 句**（泛化 `:77` / 矛盾 `:242` / 结论 `:344` / 扁平 `:529`），而且：
- `03` 通用规格要求每诊断 **2-4 句**，现有 1 句（`01`/`03` 都写明"缺的是数量不是有无"）
- 这 4 句的**归宿卡 C2/C3**，可能根本不在任何一份产物里
- 四份构件手册各自的质量门**一句替代问法都没有**

执行 AI 手里有一整套判据、没有一句对应的说法。**LLM 的默认行为就是把判据说出口。** 这是 H-40 会被系统性突破的地方，而 H-06 拦不住它——H-06 唯一的硬禁只有四个诊断词，禁不了"这条放到别的店员身上也成立"这种句子。

| **3 · 完全空白** | 14 轮 | 绕过死点后到第 14 轮攒够素材 | **第 2 轮** | 世界设定"必走"但零兜底（N7）+ **所有降级机制的触发都要求"先卡几轮"，而这个用户第 0 轮就卡**（N8）+ 唯一现成的场景钩子恰好在这个开局下是坏的（R8） |

**"走到产出"这件事三个开局都做不到，而且原因是同一个**：
- `§6 item 1` 的判停锚点是 MVC，MVC 的判据是空的（N4，卡 C12）
- 就算判定该暂停，**"创作思路整合"这份产物的骨架来自 `素材/人物文档骨架.md`，⬜ 未提取**（卡 C10/C11）
- `H-24` 说产出叫"创作思路整合"不叫"最终人设"，`H-23` 说产出必须分三层——**规格规定了产物叫什么、要分几层，没有规定它长什么样**

**开局 3 的照规格版本值得单独说**：如果执行 AI 没有像我一样在第 2 轮编出一个规格里不存在的问句（"最近有什么东西是你看完之后脑子里剩下一个人的"），那么按规格走的路径是：轮 3 抛坏掉的场景钩子 → 用户答"我不知道她有没有工作" → 轮 4 无路 → 轮 5 撞 H-37 → 走 `§13d` 出口 3「诚实告知局限」。**5 轮结束，零产出。** 这是符合规格的结局（`§13d` 明确承认对这类用户效果有限），但它意味着"最难的那类用户"这条分支实际上是关着的。

### 问题 2 · 用户全程会不会被砸术语？

**追问阶段：不会，一次都没有。这一段规格是硬的，而且够用。**

我逐轮检查了三个开局全部 54 轮 AI 说出口的话，`调色盘 / 底色 / 主色调 / 点缀色 / 多面性 / 三面性 / 混色 / 核心人格层 / 二次解释 / 意象 / 衍生 / 防御机制` 这些词**零命中**。撑住这件事的是三条：
- `H-06`「追问时把术语翻成大白话」+ 三组正反对照句
- `§5 item 4`「追问说人话，汇报可用构件名」
- **素材本身**：`追问原句库` 收录的问句几乎全是大白话（"哪个是无论什么时候都在的""她在什么时候会和平时表现得完全不同""再往下一层"），执行 AI 照抄就不会出术语

**四个诊断词（泛化/结论/扁平/矛盾）也零命中。** `H-06` 唯一的硬禁守住了。

**但有两个地方用户一定会碰到方法论语言，而它们的性质完全不同：**

**① MVC 暂停时的进度汇报 —— 这是设计明确接受的成本，不是漏洞。**
`D-02` 授权"汇报时可以直接用构件名"，并给了唯一的示范：「她的多面性成型了，接下来可以挖她压力大时怎么做」。开局 1 轮 25 我照做了，说出了"调色盘"。
后果是可预期的：用户第一次听到这个词必然会问"什么是调色盘"，AI 必须按 `H-10` 例外 2 简答一次，然后切回追问。**这一刻 skill 会短暂变成半个教学场景**——这是 D-02 权衡过并接受的（"没有名字只能绕圈子"），不算断点。

**② 质量门判不过时，判据会被说出口 —— 这个是真漏洞（断点 R6/N11）。**
四份构件手册的质量门全是判据（"底色 = 换任何场景都还在"、"衍生 = 具体到你能在脑子里看到画面"、"点缀 = 能说出一个具体时刻，不是一个形容词"），而 `H-40` 禁止把质量评价说出口。中间那一层——判据不通过时说什么——**只有 4 个基础诊断有，每诊断 1 句，规格自己承认数量不够，而且归宿还卡在 C2/C3**。

这才是用户真正会被砸到的地方，而且 `H-06` 拦不住它：H-06 的硬禁只覆盖四个诊断词，覆盖不了"这条放到别的便利店店员身上也成立""这个还是个形容词，不是画面""这条太概括了"这类句子。这些句子里一个术语都没有，但它们全是当面评价用户写得不好，正是 `H-40` 要防的东西。

**执行 AI 手里有一整套判据、没有一句对应的说法，它的默认行为就是把判据说出口。**

### 问题 3 · 规格最薄的是哪一段？

**从"用户答完这一轮"到"AI 决定下一轮问什么"之间的那一层。规格里没有这一层。**

我推演时"只能自己编"的 18 处，**14 处落在这一层**。它由三块组成，三块都缺：

**① 入口 → 前置步骤 → 第一个构件的接续**（X1 · T1 · N6 · N7 · X6）
`§7` 定义了五种入口和两个必走步骤，`§11a` 定义了每份手册的触发信号，**中间的那一段没有**。`§11b 流程地图` ⏳ 卡 C5，而它正是这一段。
后果：三个开局的第 1 轮全部撞 X1，而且**同一个歧义在三个开局有三个不同的正确答案**——开局 1 该压缩、开局 2 该跳过、开局 3 该照走。这说明缺的不是"排个序"，是一条**依用户手里已有的东西决定顺序**的规则。

**② 一轮之内多条线索时选哪条追**（N1 · X2 · J6）
`§6` 三层判停能判"这条方向够不够了"，判不了"下一条方向选哪个"。`§10b` 六组维度能判"哪一组是空的"，但开局时六组全空。
真实对话里用户一句话经常同时点亮 2-3 个信号（开局 1 轮 14 一句话点亮三条规格），而 `H-42` 只准挑一个。**挑哪个，规格全篇没有一个字。**

**③ 构件与构件之间的转出**（T3 · T6 · T2 · T4）
每份手册都写清了"我需要什么输入""我什么时候不适用"，但**没有一处从上游说"我做完了该去哪"**。唯一的例外是调色盘的一句"转出信号"，而那是判据不是动作。
`03 §素材流向路由图` 是全包最接近这一层的东西，但它路由的是**素材**不是**流程**，而且它把用户原始切片送去了一个需要调色盘先行的混色（T2）。

**为什么会薄成这样，有个结构性原因**：这一层的全部内容挂在 **C5（阶段模型）· C12（MVC 判读）· C13（模式链分工）** 三个未拍冲突上，而这三个冲突恰好是仅存的最难的三个。规格把"每个构件内部怎么问"写到了 3000 行素材的密度，把"什么时候从这个构件走到那个构件"整块留在了 ⏳ 里。

**一句话**：这个 skill 现在有非常好的**弹药**（构件手册 + 原句库）和非常好的**保险栓**（45 条红线），**缺的是扳机和瞄准具**。

### 问题 4 · 如果只补三条规格能让它跑通，是哪三条？

我按"补了之后能关掉几条断点"排的序。

#### 第一条 · 一张最小可用的调度表（关掉 X1 · T1 · N1 · N6 · N7 · T2 · T3 · X6，8 条）

不需要拍 C5 的完整阶段模型，只需要三行规则：

**a. 前置两步改成"缺什么补什么"，不是"必走两问"。**
> 开局先做一次静默盘点：题材 / 用户在这个世界里的位置 —— 用户第一句里已经给了的，**直接采用并一句话同步**（"便利店夜班，那就按现在这个现实世界走了"），不重新问。两样都缺才问，一次问一样。
> 用户答不出题材时**不僵持**：从她手里已有的任何一个具体东西（一个画面、一个参照对象、一个身份）反推题材，反推不出就先不定，等第一个场景出来再回填。

**b. 第一个构件的选择依用户手里已有的东西决定，不是固定入口。**

| 用户手里有 | 先去哪 | 为什么 |
|---|---|---|
| 一组标签 / 一句定性 | 调色盘（走 `素材 A.2b` 原路径） | 输入形态匹配 |
| 一个画面 | **先攒到 3 条不同压力性质下的行为切片，再进调色盘**，起手动作用"摆行为切片让用户反推共性"（不是"从标签里挑"） | 补上 N6/T2 |
| 一段背景 | 同上 | |
| 什么都没有 | 先找一个**参照对象**（"最近有什么东西是你看完之后脑子里剩下一个人的"），把它变成画面入口 | 补上 N7/N8 |
| 现成卡 | `§7 item 6` 原路径 | 已有 |

**c. 一轮多线索时的优先级（一句话）：**
> 同一轮出现多条可追方向时，**先追离一个具体画面最近的那条**；两条一样近，先追用户说得更犹豫的那条（"好像""可能""不知道算不算"）。

#### 第二条 · MVC 的最小定义 + H-37 的 N 值（关掉 N4 · N5 · T4 · N3 · N8，5 条）

**不等 C12 全拍。** C12 要拍的是三层判读的优先级关系，但"什么时候暂停"可以先给一个保守的下界：

> **暂停条件（三条同时满足）**：
> 1. **结构**：三层颜色各有一个名字，且合计 ≥6 条行为级衍生（不要求每色 ≥3——见下）
> 2. **质量**：`03 §用户确认信号` 的组合规则通过（≥3 个信号，含至少 1 个 D/E/F/G）
> 3. **用户没喊停**（喊停立即走 `H-19a`）
>
> **单色衍生凑不够时的降级出口**（补 N3）：某一色连续 2 轮无新衍生 → 接受当前条数，在文档里标 📌 未深挖，**继续往下走，不僵持**。调色盘从此有了降级出口。
>
> **暂停时给用户的三条固定选项**（补 T4，并给 `H-32` 开一个具名例外）：① 补哪一块 ② 换一个方向挖 ③ 收束成文档。**流程分支不计入 H-32 的"待选方向"计数**——H-32 加一句"本条计的是角色内容方向，不含流程分支"。
>
> **`H-37` 的 N = 3**，与 `H-19b`/`H-31` 的 3 轮对齐。三处用同一个数，AI 只需要维护一个计数器。

#### 第三条 · 把所有"逐字可用"的问句过一遍 H-42，同时给四份构件手册补质量门的说法（关掉 R1 · R2 · R3 · R4 · R7 · R6 · N11 · J7，8 条）

这一条是**纯机械的一次性清洗 + 一次小规模补写**，但它关掉的断点数最多，而且全部命中率 2/3 以上。

**a. 清洗（机械）**：`§7 item 1/2/5/7`、`§10b item 3`、以及素材里全部标"逐字可用"的问句，逐条数问号。凡 >1 的：
- 拆成单问，并在规格旁边加一句口径说明：**"逐字"指的是内容与措辞逐字，不指标点——问出口时一次只问一句，其余问句留作下一轮的备选**
- 顺带删掉 `§7 item 1` 那 5 个并列题材候选（改成开放问）和 `素材 A16-4` 那 3 个并列机制候选（或给它挂 `H-32` 的具名例外）

**b. 统一 `H-42` 与 `§5 item 7` 的判据档位（补 J7）**：两条现在一严一松（`≤1 个问号` vs `≥2 个问号且分属不同话题`）。取一条，另一条改成指针。

**c. 补写（小）**：给调色盘 / 多面性 / 混色 / 核心人格层四份手册，各补 **2-3 句"质量门判不过时说什么"的外部问法**，形态照抄 4 诊断那句现成的「用 X 而非 Y」。例如：
- 底色没过（换个场景就没了）→ 用「她不上班/不在那个环境的时候呢，这个东西还在吗？」而非「这个不能当底色」
- 衍生太概括 → 用「她是怎么做的？」而非「这条太概括了」
- 点缀答成形容词 → 用「有没有哪一次是你真的看见过的？」而非「这还是个形容词」

**这一步同时把 `H-40` 从"一条禁令"变成"一条禁令 + 一套替代动作"**。按 `04 〇之二` 的注意力预算原则，这是最划算的一笔——它不增加约束条数，只是把已有约束从"禁止"补成"禁止 + 怎么做"。

#### 三条之外，值得单独记一笔的两条（没进前三是因为它们不阻塞跑通）

- **X3/R5（调色盘的"命名"撞"只整理不总结"）**：`03 §核心人格层 item 16` 的"凝练命名 vs 产出结论"判据（"Y 的每个成分能不能在用户原话里找到"）应该从核心人格层手册**提到 body 的 §5 item 6 旁边**，它管的是全局，不是核心人格层专属。顺带修掉 `§5 item 6` 那条假机械判据（检索"所以她是"）。
- **X4（两版补白问法）**：二选一，另一处改成指针。这是纯重复，留着必定漂移。

## 六、一句话结论

**照现在的规格写出来的 skill，第 1 轮就会踩红线、第 7 轮左右会失去导航、判停点是空的——它缺的不是内容，是把内容串起来的调度层；补上第 5 节那三条（调度表 / MVC 下界 + N 值 / 问句清洗与质量门说法），三个开局都能跑到产出。**
