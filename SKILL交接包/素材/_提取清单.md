# 素材提取清单

> `素材/` 是**按产物切好的教程原文逐字摘录**，让写 skill 的 AI 不必打开教程。
> 提取源：`三线碰撞/_work/01_教程底册_组*.md`（586 条带 `文件:行号` 锚的逐条事实，已做 A/B 类标注）+ 回教程原文补全整段。
> **只提 A 类（追问角色本身的动作）。B 类（教方法论的教学手段）一律不进素材。**

---

## 素材是"引用源"，不是"理解源"

写作 AI **不需要理解教程的方法论**，只需要在施工规格要求它放一句原话时，从素材里取。所以素材的质量标准是：

1. **逐字准确**——不转述、不润色
2. **出处锚齐全**——每条带 `文件:行号`，让它能一键回原文核对（**例外路径**，不是默认路径）
3. **按用途分组**——按"给哪个产物用"组织，不按教程章节组织

---

## 提取时机规则

| 类别 | 什么时候提 | 理由 |
|---|---|---|
| **决策无关** | 随时可提，不会返工 | 无论剩余决策怎么拍，内容都一样，只是放进哪个文件不同 |
| **决策相关** | 对应决策拍完后 | 提早提会因决策变化返工 |

## `追问原句库.md` 的额外要求（这一份最重要，单独说）

**追问品味是这个 skill 唯一没法靠规格传递的东西。** 线 B 明确判定它必须在 body 内化，而不是外置成范例库。

所以这份素材不能只给问句列表，必须给**完整回合**：

```
【探底色】
引导者的问句：<逐字>
用户的回答：<逐字>
引导者的反应：<逐字>
最终落成什么：<逐字>
出处：<文件:行号>
```

按**探什么**分组（底色 / 主色调 / 点缀 / 多面性触发 / 混色触发 / 意象 / …），每组 2-4 个完整回合。

**同时要提"引导者卡住时做了什么"的回合。** 教程 42 个卡住实例里，引导者代劳的比例随层次递减——"是什么"层 65% 直接给答案，核心人格层 25%，意象层 **0%**。这个梯度本身就是要传递给写作 AI 的行为规范，不提就丢了。

（核心人格层部分的完整回合已在 `核心人格层_原文素材.md` 的 B 段，这份不必重复，交叉引用即可。）

## 不提取的东西（明确排除）

| 不提 | 为什么 |
|---|---|
| 正误并列对照表 | B 类教学手段。只提其中的**判据**，不提对照展示形式 |
| 课后笔记 | B 类教学检验 |
| 术语纠偏整节（"三面性不是三种性格"） | B 类。skill 不澄清术语 |
| 比喻教学（梵高的星空 / 操作系统 / 超级压缩包 / 七个频道 / 输入法联想） | B 类原理讲解 |
| "AI 会怎么误读"的机制讲解 | B 类。skill 直接执行检测，不解释检测背后的模型行为 |
| "90% 的人都写错了"式教学修辞 | B 类 |
| 教程内部的出入本身 | 已裁定过，给写作 AI 只会引起重新纠结。裁定结论写进施工规格 |

⚠️ **但"教程明确标为错误示范的具体句子"要提**——它们是给写作 AI 的反面判据。不提的是围绕它们的教学论述和并排展示形式。

## 提取中发现教程内部矛盾怎么办

**如实记录在素材文件的附录里，不要合并、不要选一版偷偷用。** 然后在**施工规格里裁定**它。

已发生的实例：`核心人格层_原文素材.md` 发现 `7.md:344-347` 教"从背景找核心恐惧"用的示范，恰恰是 `7.md:92` 判为错误的成因式句式。这条已在 `04_硬约束与红线.md` H-02 裁定——**成因式表述可以当梯子，不能当成品**。
