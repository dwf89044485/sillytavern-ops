## S1 的额外要求（这一份最重要，单独说）

**追问品味是这个 skill 唯一没法靠规格传递的东西。** 线 B 明确判定它必须在 body 内化，而不是外置成范例库。

所以 S1 不能只给问句列表，必须给**完整回合**，例如：

```
【探底色】
问：这七个标签里，哪个是无论什么时候都隐隐存在的？
答：<用户原话>
再问：<引导者接下来说了什么>
落点：<最后凝练成什么>
出处：10.大总结教程/02_调色盘篇.md:81-101
```

提取时按**探什么**分组（底色 / 主色调 / 点缀 / 多面性触发 / 混色触发 / 深层缺失 / 核心恐惧 / 意象 / …），每组给 2-4 个完整回合。

**同时要提取"引导者卡住时做了什么"的回合**——教程 42 个卡住实例里，越往"为什么"层走引导者越不代劳（是什么层 65% 直接给答案，核心人格层 25%，意象层 **0%**）。这个梯度本身就是要传递的行为规范。

## 一条提取纪律

**每条素材必须带 `文件:行号` 出处锚，且摘录逐字。**

理由：写作 AI 如果对某条素材有疑问，应该能一键回原文核对——但这是**例外路径**，不是默认路径。默认它信素材。没有锚就没法核对，等于逼它去通读教程。
