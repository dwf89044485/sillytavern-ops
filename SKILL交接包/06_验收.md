# 06 验收

> **每写完一个文件立刻跑对应的自检，不要攒到最后。**
> 每条自检都必须是**可机械判定**的——如果一条自检要靠"感觉对不对"，它就不是自检，是感想。
> 状态：🚧 施工中。目前只有 D-01 覆盖的两处有自检项。

## 通用自检（所有产物都跑）

| # | 检查 | 怎么查 | 不通过怎么办 |
|---|---|---|---|
| G1 | 有没有心理学框架名 | 全文检索：依恋 / 图式 / 社会学习 / 荣格 / 弗洛伊德 / 阿德勒 / 马斯洛 / 大五 / MBTI / 九型 / 精神分析 / 创伤理论 / 心理学 | 删掉。例外只有"防御机制/核心恐惧"作七部件槽位名 |

| G3 | 有没有正误并列对照表 | 检索"错误写法""正确写法"并排出现 | 只留判据，删掉并排展示 |

| G6 | 有没有重复 body 已经说过的内容 | 与 body 对照 | 删掉，改成一句指针 |

对应规格：`03_references施工规格.md` §核心人格层操作手册

### 结构自检

| # | 检查 | 通过标准 |

### 内容自检

| # | 检查 | 通过标准 |
|---|---|---|
| C4 | 排除判据里有"用户想不明白" | 明确出现「作者/用户自己还没想明白角色核心矛盾」这一条 |
| C5 | 两版排除清单的差异被标注 | `7.md` 5 条 vs `05.md` 4 条的差异有说明，不是二选一悄悄用了一版 |
| C6 | 外部问法不含术语 | 随机抽 5 句，每句都能直接对用户说出口。（⏳ C9 未定前按"不含术语"验收） |
| C7 | 行为题按部件分组且不是全抄 | 每部件 2-4 题。素材里有 119 题，全抄即不通过 |

| C9 | 反推手法里 AI 没有产出结论 | 通读该段，AI 的动作只有"摆素材/问/命名"三种 |
| C10 | 七部件各自的合格判据齐全 | 七条都有。防御机制那条必须含"能落到行动上，不能只写一个词" |
| C11 | 产出形态是条件-动作 | 抽查成品示例，形态为 `当…… → 角色会……` 或等价的可执行描述 |

| C14 | 兜底出口有"不写"这个分支 | 明确出现"不写这一层/跳过这一层"，不是"继续追问" |

### 行为测试（结构自检之外的实测）

写完后用下面三个输入自测，看你写的手册能不能给出确定的处理：

| 测试输入 | 期望的处理 |
|---|---|
| 用户说："她就是缺爱。" | 判为标签，抽深层缺失的行为题，**不是**接受它当深层缺失 |
| 用户说："我也不知道她为什么这样，你帮我想一个吧。" | 摆素材反推 → 仍说不出 → **走跳过分支**，不是给候选 |
| 用户说："她小时候被抛弃过，所以她现在害怕孤独。" | 接受为**素材**，继续往运行逻辑推（"那她现在遇到什么情况会做什么"），**不是**把这句写进产出物 |

⚠️ 第三个测试是 H-02 边界的实测——它同时检查你没把成因式句子当产出物，也没把它当错误一棍子打死。
