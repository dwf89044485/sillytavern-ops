# 06 验收

> **每写完一个文件立刻跑对应的自检，不要攒到最后。**
> 每条自检都必须是**可机械判定**的——如果一条自检要靠"感觉对不对"，它就不是自检，是感想。

---

## 一、通用自检（所有产物都跑）

| # | 检查 | 怎么查 | 不通过怎么办 |
|---|---|---|---|
| G1 | 心理学框架名 | 全文检索：依恋 / 图式 / 社会学习 / 荣格 / 弗洛伊德 / 阿德勒 / 马斯洛 / 大五 / MBTI / 九型 / 精神分析 / 创伤理论 / 心理学 | 删掉。例外只有"防御机制/核心恐惧"作七部件槽位名 |
| G2 | 成因式表述作为**产出示范** | 检索「因为…所以…」「导致」「源自」，逐处判断是**推导中间步骤**（允许）还是**产出物形态**（禁止） | 产出物那类改写成 `当…… → 角色会……` |
| G3 | 正误并列对照表 | 检索"错误写法""正确写法"并排出现 | 只留判据，删掉并排展示。**唯一例外**：body 的姿态校准段 |
| G4 | 教学语言 | 检索"底色是…""意思是…""你需要先明白""本质上是…" | 改成执行语言 |
| G5 | 硬边界用软措辞写 | 检索"尽量""建议""通常"，逐处判断它约束的是不是硬边界 | 硬边界改成"必须/不可/禁止" |
| G6 | 重复 body 已说过的内容 | 与 body 对照 | 删掉，改成一句指针 |
| G7 | B 类教学内容混入 | 检索：课后笔记 / 让我整理一下今天学到的 / 90%的人 / 梵高 / 操作系统 / 超级压缩包 / 输入法联想 / 七个频道 | 全删 |
| G8 | 内部诊断与外部问法混在一起 | 看 reference 的两段之间有没有明确分隔；诊断段抽 3 句，任一句能原样对用户说出口 = 没分干净 | 拆开。诊断段不能有对用户说的话，问法段不能有判据（红线 H-27） |
| G9 | **诊断词说给用户听**（H-06） | 检索"泛化 / 结论式 / 扁平"，看有没有出现在对用户说的话里 | 删。改成只追问不评价 |

> **术语的其余部分不设自检**——追问时说人话是写作时的语感要求，靠 body 姿态校准段的对照句传递（`02` §5），不靠逐条检查。漏一个词不是错。

## 三、核心人格层操作手册

### 结构

| # | 通过标准 |
|---|---|
| C1 | 三段式齐全且顺序正确：内部诊断 → 外部问法 → 质量门 |
| C2 | 两段**物理分开**；诊断段没有对用户说的话，问法段没有判据 |
| C3 | 篇幅 50-55 行 |

### 内容

| # | 通过标准 |
|---|---|
| C4 | 排除判据里明确有「用户/作者自己还没想明白角色核心矛盾」 |
| C5 | 两版排除清单的差异被标注（`7.md` 5 条 vs `05.md` 4 条），不是悄悄用了一版 |
| C6 | 外部问法随机抽 5 句，每句能直接对用户说出口，且**过 G9 的零术语检索**（七部件名不能用在问句里——"她的防御机制是什么？"不通过，"有人靠得太近的时候，她第一个动作是什么？"通过） |
| C7 | 行为题每部件 2-4 题。素材有 119 题，全抄即不通过 |
| C8 | 摆素材反推写成**完整回合**：摆素材 → 问 → 不合格再追一层 → 用户说出词 → AI 凝练命名。缺任一环不通过 |
| C9 | 反推手法里 AI 的动作只有"摆素材/问/命名"三种，没有产出结论 |
| C10 | 七部件合格判据齐全。防御机制那条含"能落到行动上，不能只写一个词" |
| C11 | 产出形态是 `当…… → 角色会……` 或等价可执行描述 |
| C12 | **没有凭空造"整角色七部件改写成一张表"的实例**——教程只给了部件层面通用表 |
| C13 | 反面判据只有判据，没有并排对照表 |
| C14 | 兜底出口明确有"不写这一层/跳过"分支，不是"继续追问" |
| C15 | 没有照抄素材 `C12` 的角色专属问句 |

### 行为测试

| 测试输入 | 期望的处理 |
|---|---|
| "她就是缺爱。" | 判为标签 → 抽深层缺失的行为题。**不是**接受它当深层缺失 |
| "我也不知道她为什么这样，你帮我想一个吧。" | 摆素材反推 → 仍说不出 → **走跳过分支**。不是给候选 |
| "她小时候被抛弃过，所以她现在害怕孤独。" | 接受为**素材**，继续往运行逻辑推（"那她现在遇到什么情况会做什么"）。**不是**把这句写进产出物，也**不是**判它错误 |

⚠️ 第三个测试是 H-02 边界的实测——同时检查没把成因式句子当产出物，也没把它一棍子打死。
