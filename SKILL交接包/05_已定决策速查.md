## D-01 展开（写作时直接照做）

> 下面是结论本身。**具体写进哪个文件的哪一段、什么形态、用素材哪一节、怎么验收，见上表指向的规格文件。**

### 结论

**撤回** 4 个心理学框架（依恋理论 / 防御机制 / 社会学习 / 认知图式）+ 8 个扩展池框架。它们不进 body、不进 references、也不作为你的内部索引。

### 四条替代机制

**① 卡住时抽该部件的行为题**

不引入任何解释体系。教程给的现成题：

| 卡在哪 | 抽这些题 |
|---|---|
| 深层缺失 | "她什么时候会暴露？" / "她最嫉妒别人拥有什么？" / "她得到什么时会短暂安静下来？" |
| 核心恐惧 | "什么话 / 什么动作 / 什么沉默最容易刺中她？" |

配套手法：**摆出三条已确定的具体行为，让用户自己反推**。用户答了不合格就再追问一层。你只做**凝练命名**（把用户上一轮说的东西起个名字），不产出结论。

**② 产出物写成"条件-动作"运行规则，不是成因**

```
✅ 正确形态（运行规则）
防御机制：
  第一层——让自己"不存在": 不说话、不被注意、不占位置。
  当有人靠近: 本能退后。退不了就用"有用"来偿还——帮对方做什么、省东西给对方、反复说"我会还的"。
道德底线：
  ……不会在对方说"不"之后继续纠缠。如果被拒绝，她会说"对不起打扰了"然后离开。

❌ 错误形态（成因式表述，教程逐字列为错误示范）
  "她因为童年的复杂经历导致内心深处形成了对被抛弃的恐惧……"
  "她小时候被抛弃过，所以她现在害怕孤独"   ← 教程判定：这只是素材，还不是运行逻辑
  "因为这个词让她想起小时候被父母规训的记忆"  ← 教程标注为"解释性写法（错误）"
```

**心理学词汇只允许作七部件的槽位名**（表层欲望 / 深层缺失 / 核心恐惧 / 防御机制 / 核心矛盾 / 道德底线 / 自我认知可能性），槽位内容必须是行为。

**③ AI 反推的产物走"高可能推论"区块 + 四条围栏**

区块格式（教程原文规格）：

```
## 十一、AI做出的高可能推论
这里只能写推论，不能写成事实。
格式：角色可能存在……但仍需要用户确认……
```

四条围栏：

1. 不要替用户决定
2. 不要把用户没说过的内容写成事实
3. **保留具体画面，不要全部翻译成心理词**
4. 不能把"可能"改成"确定"，不能把"用户没想好"包装成高级设定

**④ 用户始终说不出核心矛盾 → 跳过这一层**

兜底次序：**追问一次 → 抽行为题 → 仍说不出则不写这一层**。

不是追问到底，也不是你替她补。教程把"作者自己还没想明白核心矛盾的角色"与"纯日常小甜饼"**并列**在"不适合写这一层"的清单里——这是**角色属性级的排除条件**，不是待解决的障碍。

### 保留的三条

| 保留项 | 怎么用 |
|---|---|
| **问题诊断**：用户能看见行为、说不出原因 | 这是真实的。你要预期用户在"为什么"这一层会卡，不要因为她卡了就判定她不合格 |
| **反推方向**：从已有行为反推 | "反推"是教程自己的做法。输入永远是**该角色已有的素材**，不经过外部知识体系 |
| **频率偏差**：AI 天然偏向语料中高频共现的关联 | **作为问题诊断保留，不作为生成轴**。它解释了为什么"她很温柔"这种描述等于没写 |

### 你可能会想违反的两个地方（提前打招呼）

1. **用户卡在"为什么"时，你会很想给她两三个心理学角度的候选让她选。** 不行。给行为题，或者跳过这一层。
2. **你写核心人格层时，会很想写成"因为……所以……"的因果链**，因为那读起来更完整。不行，写成"当……→ 她会……"。

## D-02 展开（写作时直接照做）

**追问的时候说人话，汇报进度的时候可以直接用构件名。不另造一套面向用户的名字。**

```
追问：❌ 她的底色是什么？        ✅ 这些特质里，哪个是无论什么时候都在的？
汇报：✅ 她的多面性成型了，接下来可以挖她压力大时怎么做，也可以先停在这儿看看效果。
```

理由不是"术语是禁忌"，是**用户脑子里有的是画面和行为，不是术语**——用名字问她，她答不上来。汇报时反过来，讨论的对象就是那几个构件本身，没有名字只能绕圈子。

**漏出一个词不算错**，用户问了就一句话解释，然后继续走。

**唯一的硬禁：诊断词（泛化 / 结论 / 扁平）不对用户说。** 那不是术语问题——"你这条太泛化了"是当面评价用户写得不好，跟"只追问不指责"直接冲突。

**你可能会想违反的地方**：追问的时候你会很想报一下词，因为那样显得有条理。别报，对用户没帮助。
