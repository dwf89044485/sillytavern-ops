## 二、逐项核查（有原文支撑的修正）

### 2.1 案例库时机（`03` 的 C8）——我的倾向确认成立

我在 C8 里主张"陈乖乖有真实对话可用、姜糖/三明月按 B 的意见暂缓"。核查结果：**两半都成立，但第一半的理由要改。**

**大总结 7 章不是逐轮对话录。** 体裁是"夹叙夹议的讲解文 + 对话片段"，每章固定结构是"开篇短对话 → 讲解穿插问答 → **大段晴空独白 + 完整成品** → 柚子课后笔记"。对话约占 35-45%，讲解和成品占 55-65%。陈乖乖的三面性五部件、11 条衍生，基本是晴空**直接写出完整条目**，不是对话里一点点磨出来的。

所以 **"陈乖乖的追问过程是现成的、可以原样抽用"这个说法不准确**——需要从讲解文里定位截取。

**但能截出高质量片段。** agent 摘了三段（每段 ≥3 个来回）：遮名泛化检测（01 章开篇）、去放大器 + 逻辑共存追问 → 定底色"不甘心"（02 章）、意象候选被逐个否决（07 章）。而且指出了**提取时必须切割 B 类尾巴**——比如片段 A 应在柚子说"好像很多角色都能用？"处截止，删掉后面"想法是模糊的、角色是具体的"那句归纳教学。

**姜糖和三明月确认没有对话纹理。** 教程 6 是作者自述式实战复盘（"我怎么想的，每一步做了什么决定"），全程独白；教程 11 是规则讲解 + 成品示范，里面的"采访"是**作者自己问自己**，不是外部追问。agent 的明确判断：要做"展示追问过程"的案例，**必须由 AI 虚构对话**。

### 2.2 意象——B 的执行方式不成立，但意象的地位比三套认为的都高

这是核查里信息量最大的一项，分两层。

**第一层：执行方式。教程立场是"引导式找到"，不是"AI 主动提议候选"。**

> 🍊 柚子：那陈乖乖的意象应该是什么？
> ☀️ 晴空：**妈妈不告诉你答案。妈妈教你怎么找到它。**
> —— `07_意象篇.md`

晴空的实际动作是三样：**否决错误候选**（柚子提"影子/灰尘"→"太消极了"；提"蚂蚁"→"太功利了，不像她"）、**给方向性提示**（"她的快乐很小很小。一道做对的题。妈妈把碗里的饭吃完了。一片晒到她脸上的阳光"）、**最终由柚子写出后确认**（"你刚才写的东西，妈妈一个字都不想改"）。

- **B 套的"意象总是尝试，AI 主动提炼并提议，用户觉得对就留"——执行方式不成立。** 晴空提议的是"错误候选的否决理由"和"搜索方向"，不是最终意象本身。
- **A 套 G7 的"意象是'找到'型任务，不示范"——大体成立但需要 nuance。** 晴空确实不给最终答案，但她大量示范"如何找"（三个问题的框架、红线手绳/草稿纸/校服这些线索串联），而且在第 79 行主动给了方向提示。所以"不示范"要精确为"**不示范最终答案，示范搜索路径**"。

**第二层：意象是不是可选。这一层的结果和三套的假设都不一样。**

大总结 07 章**没有出现任何"不是必选项/可跳过"的表述**。而同一套教程里，另外三个进阶层**都明写了**：

> 「三面性是工具，**不是必选项**。」——`03_三面性篇.md`
> 「和三面性、混色一样，核心人格层是**进阶选择**。」——`05_核心人格层篇.md`

07 章反而把意象列进七步流程的最后一步，无跳过说明。教程 11 同样把意象列为必做六步之一，也没标可选。

**这意味着：在教程的语境里，意象的地位高于三面性/混色/核心人格层——后三者作者反复说"可选"，意象他一次都没说。**

唯一的反证来自 C 套 DISCUSSION_01 的审查 A："教程作者自己的角色卡中，**秋明月就没有意象**"——这条不在本次三个 agent 的阅读范围内，**未被核实**。

→ **C18 的判断依据齐了**：执行方式采 A 的 G7（修正为"不示范最终答案，示范搜索路径"）+ 否决 B 的"AI 主动提议"；地位上"总是尝试"有教程支撑，比 A 主文档的"不提"和 C-DISCUSSION_01 的"降为条件触发"都更贴原文。剩下待核的只有"秋明月有没有意象"。

### 2.6 两处引证需要修正（结论不变）

- **情绪串（A 的 G9）**：结论成立——教程明说"这种'串'**不需要你刻意去写**'她同时感到快乐和焦虑'这种解释，你只需要写过程里那些看起来矛盾的动作"。但 A 的 G9 依据里引的"串会自然发生，你不用管它"**不是原文**，是转述。教程也确实从没要求主动识别另一种情绪。

### 2.7 教程 11 是六步不是五步（对 skill 无实质影响）

A 的 G3 概括为"基础信息 → 小传 → 采访 → 情绪阈值 → 意象"五步。教程总结章明写是**六步**，第一步是「理解 AI」（"你写的每个字都在替 AI 选联想词"）。

后五步的顺序和内容 A 概括正确。第一步是纯 B 类（教读者原理，AI 不需要被说服），**按翻译层规则本来就不该融入 skill**——所以 A 的五步概括对 skill 是对的，只是引用教程时应注明原文是六步。

## 三、共同盲区：三套都漏掉的东西 🔴

这是本次核查最有价值的部分。三个 agent 各自"忘掉清单、独立重找"，找出的东西高度不重合于三套的提取结果。

### 3.1 两条被三套一致低估的高频核心判据

这两条在教程里反复出现（一个 4 处以上、一个横跨 3 篇教程），但三套都没把它作为硬约束：

**① "删了 AI 会不会演错？不会就删"——通用冗余检测**

教程 0 号至少 4 处复用（外貌 / 世界观 / B 类世界 / 世界书条目），是全书最高频的判断标准之一。

A 套把它（f17"删一句看 AI 会不会演错"）**降级为通用技法**，理由是"本质是奥卡姆剃刀应用于提示词工程，不是作者独创"。B 套只在快速路径的基础信息完成标准里出现过一次"删行测试"。

**独创性判断可能没错，但降级的后果是它没有落盘位置。** 一条在源材料里出现 4 次以上的判据，在三套产物里都没有明确的执行位置。

**② "先有调色盘，再有 X"——顺序铁律**

教程 2、4、7 都写了同一条：

> 「先有调色盘，再有三面性。**没有调色盘的三面性是空壳。**」——教程 2
> 「**没有调色盘的混色是一团糨糊。**」——教程 4

三套都把多面性/混色/核心人格层写成"信号触发的分支"，**但没有一套把"调色盘未成型时不得进入这些层"写成硬前置条件**。B 套的信号路由表尤其危险——检测到场景差异信号就路由到 probe-faces，不检查调色盘状态。

### 3.2 教程 2 号里"作者称之为最高频的错误"，三套都没有

> 「**这是最高频的错误**」：把二次解释写进三面性 ——`2.进阶，三面性……`

配套判据：三面性里出现"因为/本质上/其实/内心"这些词，大概率是写错位置了——**三面性只管"怎么运作"，不管"为什么"，"为什么"属于二次解释**。

作者亲口标注为最高频错误的东西，三套产物里一条都没有。

### 3.3 按教程章节归类的其余盲区

只列三套都没覆盖的。有些是操作细节，但都是可执行判据。

**教程 0（基础信息 / 世界观）**
- AI 数据库默认值检测（B 有，A 无）
- 背景删条检测（"删掉任一条背景角色不变 → 废条"）
- 基础信息不得混入性格标签（理由："AI 还没读到后面精心写的小传和采访，就已经拿着这两个标签开始联想了"）
- 关系写具体画面不写抽象形容
- 世界观 A/B/C 分型的**篇幅规则**（A 极简增量 / B 1-3 条 / C 分层拆分）
- 压缩 vs 删除的区分（"压缩保留信息；删到 AI 无法还原世界 = 不可接受"）
- 世界观绝对零度格式（无主观评价、无比喻意象、列表优先）

**教程 2（多面性）**
- 拆面五部件（触发条件/能量状态/语料/身体行为模式/功能）— A 提过名字，无内容
- **语料分流规则**：有多面性 → 语料从调色盘剔除、分到各面；无多面性 → 语料留调色盘
- 面间过渡与渗透（"面不是开关"）

**教程 4（混色）**
- **衍生"撞到一起"筛选**——混色的操作起点是"先摊开衍生，找同场景会同时触发的颜色"。三套都只有"发现矛盾就混色"，没有这个前置动作
- **禁止用"但/然而"制造混色**（"'但'这个字在强行告诉读者注意这里有反差，混色不需要任何标记"）
- 混色密度控制（"如果到处都是混色，那就没有混色了，因为没有反差"）

**教程 7（核心人格层）**
- **检查清单 8 问**（§十六）
- 核心恐惧须从背景长出，不要凭空编
- 防御机制须落成具体行为（"'防御机制: 逃避'太空"）
- 道德底线不要写成猎奇点
- 自我认知写"可能"不写死结局
- 核心矛盾不能只为 {{user}} 存在（人格独立性）
- **不要把这套写法当新模板盖掉原来的所有东西**（"这样会写废"）

**教程 1**
- **性格对冲（主/副/对冲）**——调色盘的前身，教程 1 §一
- 手写重复 = 二次强调（"重复内容说明作者潜意识认为重要"）

**教程 3（台词人设）**——这些归 dialogue-persona，但三套都没提取
- **存疑机制**（"不给结论，打断 AI 的惯性思考"）— 与 C 套的 C-9 呼应
- 观察者视角（"第三人称解释不是替角色说话，是在观察角色说话"）
- **台词不分类**（"一旦你分了类，就在告诉 AI'她在这种场景下应该这样说话'。这和写标签有什么区别？"）
- 覆盖面检测（高兴/生气/崩溃/日常都要有样本）

**教程 5（开场白）**——归 A 说的"char-build-guide 内部环节"，但没有内容
- 引子/目标检测（"没有创造任何目标让角色去行动 → 玩家拿到手会不知所措"）
- **八股规避**（"如果开场白主动规避 llm 爱用的八股句式，后续生成时会很大程度延缓文风劣化"）

**教程 6（姜糖）**
- **写卡前三问**：核心驱动力 / 用户会怎么玩 / 这张卡能玩多久

**教程 9（用户信息）**——归 user-info-calibration
- 行为翻译 / 只写特化不写常态 / 禁止部分 / 正写不反写 / token ≤ 角色卡 1/4

**24 问工作流**
- "她最吸引人的地方"（不是问优点，是问"为什么会想一直看她"）
- "她最不该被写成什么"（防误读第一道护栏）
- "她过去学会了什么**错误规则**"（防御往往来自过去学会的错误规则）
- "哪些背景只是素材，不该变成全部解释"（防止角色被背景吞掉）

### 3.4 一条被证实的、三套都有但表述最弱的规律

教程里晴空的追问节奏有明确规律，agent 从原文归纳出六条，其中三条对应 A 的 G8（肯定+追问成对）：

- **先让用户产出，再纠偏**："你先按你的想法写，然后妈妈帮你改"
- **逐条挑毛病，再给改写示范**："妈妈现在告诉你，这段里面有多少东西是废话……我们一条一条看"
- **答到点子上时短肯定，然后立刻推进**："非常好。那她的安静，本质上是一种保护。"
- **深层追问用多层"再往下一层"直到落到行为**（05 章核心恐惧挖三层）
- **当前工具不够时切章节，不死磕**
- **用户写出终稿后停止追问**（"你刚才写的东西，妈妈一个字都不想改"）

A 的 G8 有前三条的实质，但依据只写了"Agent 1 提出"。现在有原文了。

## 六、方法论确认

派 agent 读原文这一步是必要的，证据是它逮到了**三套互相比对永远发现不了的三类错误**：

1. **杜撰的教程锚点**（B 的三条判据挂了不存在的原文依据）——只有回到原文才能发现
2. **事实性误读**（A 的世界观 A 类"一个字都别写"、KNOT 的七部件名称）——三套里只有一套写了，另两套没写，比对时只会显示为"A 独有"而不是"A 错了"
3. **共同盲区**（"删了会不会演错"、"先有调色盘再有 X"、"最高频的错误"）——三套都没有，比对时完全不可见

第 3 类最危险：**盲区在文档对文档的比对里是不可见的**，它只在"文档 vs 源材料"的比对里才会现形。
