小伴龙 AI · 最终形态产品原型与功能说明书

面向 3–8 岁儿童的拟人化 AI 陪伴与共创产品：以全屏 Spine 4.2 活态小伴龙为核心载体，通过分龄话题引导、房间微光唤醒共创技能与分层成长记忆实现自然陪伴，并配套家长悄悄话传话、成长周报与未成年人合规防线。

核心双面体验哲学：儿童端做减法，家长端做透明

儿童端（极简无按钮）：没有菜单栏、功能图标或选项卡片。孩子打开即见活态小伴龙，开口聊天即驱动一切；提到画画或故事时，房间对应物件亮起柔和微光并伴随口语邀请，顺滑展开纯净创作界面。

家长端（清晰透明可控）：通过长按家长锁 + 成人验证进入。完整呈现让小伴龙传话（悄悄话）、成长周报、作品与绘本馆、记忆审计、时长/作息/宝箱防沉迷管控与零隐藏会员权益。

话题引导机制、大模型记忆架构与技术底座

自然语音陪伴：持续对话与话题引导体系

  • 开场不冷场优先级：家长待执行悄悄话 → 昨日未完故事/画作记忆 → 昼夜/天气/节气趣事 → 角色今日小秘密，绝不干问「你想聊什么」。
  • 单轮三步法：共情复述 + 拟声词画面扩写 + 1 个低门槛轻钩子（二选一 / 猜一猜 / 请孩子出主意），避免连环审问把孩子问懵。
  • 冷场阶梯救场：回「嗯/不知道」时切换为小伴龙求助（「我找了个发光盒子，你帮我猜猜？」）；沉默 8 秒先做趣玩小动作，30 秒转安静待机。
  • 聊→猜→编→画→演螺旋：按兴趣自然衔接技能，保持 8–15 分钟健康专注时长，不靠情感绑架留人。

大模型侧：L0 / L1 / L2 分层记忆处理

  • L0 短期会话（Redis，TTL 30m）：保留当前最近 6–10 轮原话与当前技能状态，负责指代消解与即兴连贯。
  • L1 情节摘要（异步提炼）：会话结束 5 分钟后由小模型抽取结构化事件与未完钩子，绝不将历史全文塞进 Prompt。
  • L2 正向档案（带权重衰减）：仅存白名单槽位（昵称、年龄段、≤8 条 14 天衰减兴趣、待传话队列、禁区）；写入前强过 PII 防火墙丢弃住址/学校/全名。
  • 低预算 Prompt 组装：固定系统提示词缓存（~400 Token）+ 结构化记忆与传话（≤250 Token）+ L0 最近轮次，总上下文压在 ~1,200 Token 内。

四层统一技术架构（端 · 网 · 云 · 管控中台）

  • 1. 客户端渲染层（Flutter / Cocos2d-x）：Spine 4.2 接收统一 JSON 演出指令（姿势/口型 Viseme/环境物件微光），双端一致呈现。
  • 2. 端侧 Native 音频 SDK（iOS / Android）：封装 AEC 回声消除、端侧 VAD 毫秒级打断信号、Opus 编解码与 WebSocket 全双工长连接。
  • 3. 云端实时编排网关（Orchestrator）：流式 ASR → 前置安全审 → 意图路由 & LLM（流式输出正文 + 动作/物件标签）→ 后置合规护栏 → 流式克隆 TTS，并挂载画画/故事/绘本/多角色插件。
  • 4. 记忆与家长中台：异步记忆提炼管线、家长传话队列与正向改写网关、成长周报聚合与安全熔断 1 分钟告警。

未成年人合规红线与透明会员权益

  • 2026-07-15 暂行办法对齐：14 岁以下监护人实名明示授权、常驻「AI 伙伴」标识、禁虚拟亲属称谓与情感依赖诱导、强制防沉迷与隐私一键清空。
  • 控本与分级路由：常规对话走流式级联链路控本，高情绪互动按需切高阶全双工链路；生图与绘本结合安全模型与配额精控。
  • 透明会员权益：免费日常陪伴零广告零儿童弹窗；AI 陪伴会员解锁深度畅聊、连贯绘本、伙伴剧场与高清 PDF 导出，老 VIP 支持差价升级联合年卡。
