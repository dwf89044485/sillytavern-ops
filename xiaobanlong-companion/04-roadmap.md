# 小伴龙 Talk 四阶段路线 v1

> 本文件覆盖 [01-product-brief.md](01-product-brief.md) 里「第一刀只做陪伴 + 画画 + 讲故事」的排序。
> 画画 / 讲故事仍做，但放到 **Talk V1.5**。V1.0 先过「聊得住、延迟与分钟成本」。
> 交互 Demo 在 [`demo/`](demo/)。工程落地仍是 Flutter + 原生；Demo 用 Web 验证流程与过关门槛，不替代 SDK。

落地产品到阶段 3 都是独立 App **Talk（Flutter + 原生）**。阶段 4 才把云中台迁回主 App（Cocos2d-x + 原生）。

| 阶段 | 落地产品 | 核心验证命题 | 关键内容 | 过关门槛（进入下一阶段） |
|---|---|---|---|---|
| 1 · Talk V1.0 | Talk（Flutter + 原生） | 聊得住吗？延迟与分钟成本过关吗？ | 原生音频 SDK + Flutter Spine 4.2 活体；放弃线上 5–8s F5-TTS，改流式云复刻 TTS；全屏房间 + 百科 + 息屏晚安故事；监护人合规与安全双围栏 | 首字延迟 ≤1.2s、单分钟语音成本 ≤0.08 元、3–6 岁理解率 ≥85%、安全红队 100% 拦截 |
| 2 · Talk V1.5 | Talk（Flutter + 原生） | 插件架构顺畅吗？画图故事有人付费吗？ | 云端 Skill Registry 与多轮状态机；Flutter 双态舞台与作品墙；AI 魔法画板（2–3 轮补齐再出图）、分支互动故事、无屏语音小游戏、家长传话筒；灰度会员与次数包 | 意图路由 ≥92%、新技能接入不改主中控、AI 付费用户毛利率 ≥40% → 达标即可并行启动主 App 迁移 |
| 3 · Talk V2.0 | Talk（Flutter + 原生） | 能否做成长期成长伙伴与第二收入曲线？ | 家长技能组装台 + 长期记忆图谱 + 每周成长报告与情绪预警；4–6 页连环绘本、七彩大陆多伙伴（唐小丫 / 发条熊 / 飘飘象）、好习惯打卡；SVIP 限时测试 S2S 实时通话；探索拍照认世界 | 次月留存与续费稳定、周报打开率 ≥40%；成熟技能直接反哺主 App |
| 4 · 主 App 迁移 | 主 App（Cocos2d-x + 原生） | 放大到 1 亿盘子并借老内容砍成本 | 100% 复用云中台与原生音频 SDK；Cocos 只写最薄 Spine 与技能画布壳；存量 5000+ 内容语音直达（导流降本 50%+）、老绘本伴读延伸聊、宝箱柔性防沉迷；严禁把 AI 免费塞进 15 元老会员 | 4–6 岁留存回升、主 App AI 毛利率 ≥40% |

## 与人设、技能协议的衔接

- 人设仍以 [02-persona-v0.md](02-persona-v0.md) 为准。V1.0 只跑闲聊 / 百科 / 晚安，不调用画画技能。
- 技能协议 [03-skill-protocol-and-prototype.md](03-skill-protocol-and-prototype.md) 从 V1.5 起生效。V1.5 起才允许「说话办事」。
- 技能始终由家长开启。V2.0 的组装台是家长排日程，不是孩子装插件市场。
- 不做开放第三方插件商店。新技能进 Registry，主中控不改。

## Demo 过关怎么演

`demo/` 里三个阶段都能点。语音、生图、S2S、拍照均为模拟。KPI 条对照上表门槛，绿过红不过。

| Demo 阶段 | 必须能点完 |
|---|---|
| V1.0 | 三轮叫名闲聊、百科一问、息屏晚安、红队拦截、看到首字延迟与分钟成本 |
| V1.5 | 画板 2–3 轮后出图、分支故事选一次、语音小游戏、家长传话、次数包见付费墙 |
| V2.0 | 组装台改一格、打开周报、翻完 4 页绘本、换一个伙伴说话、打一颗习惯卡 |
