## 三、互补关系(写作时配对呈现)

### 原则 ↔ 反例配对(step-guides 内"常见错误"的写法)

每条核心原则与对应反例**成对出现**:先给原则(怎么写),后给反例(写错长什么样)。已识别 27 对,写 step-guides 时逐一落实。示例:

- P22 写倾向不写唯一答案 ↔ CE-08 "受质疑时总会冷笑反击"
- P31 解释不能变成新事实 ↔ CE-12 手术/复健/选拔被补出
- P39 不写表演说明书 ↔ CE-14 "愤怒时提高音量,悲伤时沉默"
- P01 静态不放过期状态 ↔ CE-01 地点复位/关系倒退
- P27 不让关系代替整个人 ↔ CE-10 拿走 user 后失去行动原因
- P17 不以完整记录为目标 ↔ CE-05 日程表/物品栏

### 案例 ↔ 反例证据链(diagnostics 的写法)

反例是症状描述,案例是实验证据,diagnostics 每条症状附对应案例作证:

- CE-07 补造事实 ← c05 贺明珠的弟弟(Claude)
- CE-15/16 小动作与比喻复读 ← c06 唐酥耳钉/程雾眼镜
- CE-17 公共模板 ← c11 贺明珠职场谦让 + c04 唐酥车票
- CE-25/26 生活结构失衡 ← c03 程雾整轮写纸张(DeepSeek)
- CE-19 四层全写满 ← c02/c10 夏燃两次反证

### 框架 = 决策工具,原则 = 落笔规则(step-guides 的两栏结构)

framework 提取的"判断标准"类单元(f01/f02/f07/f12/f13/f16/f17)是**决策工具**,principle 提取的是**落笔规则**。写 step-guide 时每步分两栏:先判断(用框架),再落笔(用原则)。如 step2:先用 f07 五情境测试判断要不要写生活结构,再按 P12-P17 落笔。

## 四、阶段 2 写作规则(由本审查推导)

1. **一个主题一个家**:每个主题只在主表述位置完整写一次,其余位置引用,不重复展开。
2. **原则配反例**:step-guides 的"常见错误"必须引用对应 CE 编号的内容,不新写。
3. **案例作证据**:diagnostics 每条症状附对应案例编号,案例原文只在 case.md 提取时保留,skill 内引用结论。
4. **术语作锚点**:GLOSSARY 术语条目之间互相引用;SKILL.md 与 references 中首次出现术语时用加粗,不重复定义。
5. **框架先行**:每步结构 = 判断(该不该写/写多少,用框架)→ 落笔(怎么写,用原则)→ 检查(写错没,用反例)。
