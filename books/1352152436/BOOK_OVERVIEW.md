# BOOK_OVERVIEW — AIRP 人物生境写法教程

> 阶段 0 产出 · Adler 整书理解(结构/解释/批判/应用)
> 源文本: `AIRP人物生境教程整理.md`(768 行,约 2.3 万字)
> 日期: 2026-08-15

## 一、主旨

**核心主张(一句话)**:人物生境写法不为角色预写答案,而是用尽可能少、彼此分工明确的内容,建立足以让人物在陌生情境中继续生活的生成条件。

三层展开:

1. **认识论立场**:人设不是"资料库",也不是"规则清单",而是一段会参与后续生成的上下文条件(2.1)。模型不会先创造一个完整的人再让她开口;人设的作用是改变哪些回复更容易出现——让属于这个人的理解、选择、表达更易生成,让不属于她的更难生成,同时保留陌生情境下的发挥空间。
2. **组织原则**:把人物拆成四层,每层只做一件事——基础信息固定客观坐标;生活结构提供可供行动的现实;人物性情写她怎样理解事情;场景表达补前三层无法自然带出的表达范围。四层是**一套整理顺序**,不是四份必须写满的表格;可省略的层直接省略,栏目齐全不等于人物完整(6.2)。
3. **节制哲学(贯穿全书的元原则)**:写倾向不写唯一答案(4.6);让解释停在人物根部,不预写心理分析(4.11);分清事实/解释/空白,空白不是缺陷(4.12);用删减完成角色,每段文字承担不同作用(6.4);写到人物能够继续生活为止,而不是写到穷尽(6.7)。

## 二、骨架

### 六部分结构

| 部分 | 职责 | 性质 |
|---|---|---|
| 一、基础信息 | 让模型确认这个人是谁、以什么身体/身份/长期社会坐标存在 | 执行层(必经) |
| 二、人设怎样进入模型的回复 | 解释为什么这样写有效:提示词原理、三重示范、长上下文位置效应、"掌握人物"六项观察 | 原理层(非执行) |
| 三、人物的生活结构 | 主线没触发她时,她原本生活在什么里面 | 执行层(可省略/并入基础信息) |
| 四、人物性情 | 她怎样看待发生在自己身上的事、在乎什么、冲突时向哪边走 | 执行层(核心) |
| 五、人物如何进入场景 | 这些内容怎样成为声音、动作和对局面的推动 | 执行层(可省略) |
| 六、把人物生境落进角色卡 | 五步整理顺序、删减检查、人设之外另有位置 | 整合层(必经) |

### 关键子结构

- **静态人设 vs 动态事实**(1.3):会过期的状态("正在住院""尚未认识{{user}}")不写进静态人设,交给开场、正文历史、剧情记录或状态层。处理办法不是追加"不要回到过去",而是不把过期状态放进静态层。
- **事实/解释/空白三层**(4.12):已确定发生的事实、作者依据事实理解到的长期性情、留待剧情以后形成的部分。解释不能悄悄变成新的事实(贺明珠被 Claude 补造了弟弟)。
- **删除测试**(1.2 / 6.4):删除它以后,模型对人物的生活、选择或他人如何看待她,是否会产生实质性误判?
- **倾向性表达**(4.6):"往往/容易/更愿意/很难/除非"vs"永远/绝不会"——只有真正构成绝对边界的事实才用后者。
- **六项观察标准**(2.3):连续性、变化性、迁移能力、独立性、时间连续、成长能力——作者检查输出用的观察方向,不写进世界书。

### 证据基础

- 长期累计上千次尝试提供问题与方向;实际引用来自 74 份有效对照输出(3.6)。
- 四个同源人物:程雾(古籍修复师)、夏燃(攀岩/运动康复)、贺明珠(销售负责人)、唐酥(自由职业感)。
- 对照方法:冻结原始资料 → 几种模型直出人设 vs 作者用同一批事实整理人物生境人设 → 相同人物/场景/来话各保留第一次有效演绎。
- 教程诚实声明:不能证明某种写法在所有模型和所有场景中必然获胜;生活结构对夏燃新增价值很小;补造事实与小动作复读没有因方法改善而消失(3.7)。

## 三、术语

| 术语 | 定义 |
|---|---|
| 人物生境 | 不为角色预写答案,用最少、分工明确的内容建立的最小生成环境 |
| 生成条件 | 足以让人物在陌生情境中继续生活的上下文材料 |
| 基础信息 | 人物的客观坐标:姓名、年龄、身份、身体、长期社会坐标 |
| 生活结构 | 人物长期嵌入的现实:工作、场所、责任、关系、能力与限制 |
| 人物性情 | 人物怎样赋予事情意义:在意什么、怎样看待自己、冲突时保全什么 |
| 场景表达 | 人物表达自己的范围:发言倾向、表达体量、情绪经过、主动行动线 |
| 静态人设 | 剧情推进后依然成立的资料(曾获得全国冠军) |
| 动态事实 | 属于某一阶段的状态(正在住院、尚未认识{{user}}),由动态记录承载 |
| 识别锚点 | 模型在不同场景中都应该保留的外貌特征(发色、瞳色、显著结构) |
| 事实/解释/空白 | 已确定的历史、作者的性情理解、留待剧情形成的部分 |
| 三重示范 | 写进提示词的每个例子都可能同时成为内容示范、语言示范、镜头示范(2.1) |
| 唯一答案 | "她受质疑时总会冷笑反击"式的固定反应规定;其反面是写倾向 |
| 表演说明书 | "愤怒时提高音量,悲伤时沉默"式的情绪→动作映射表(5.7) |
| 公共模板 | 模型在材料不足时套用的职业/关系公共路径(职场谦让、车票与离开) |
| 补造事实 | 模型为证明人设而擅自制造的、资料中没有的往事 |

## 四、批判(作者盲点与局限)

1. **样本有限**:实验基于 4 份人物资料 × 数个模型(DeepSeek V4 Flash、Gemini 3.1 Pro、Claude、Kimi K3),结论不能推广到所有模型与场景。
2. **增益不普遍**:生活结构对夏燃(已有攀岩场域)新增价值很小;场景表达对夏燃可以删短。方法有效是有条件的,不是每个角色都需要完整四层。
3. **未解决问题**:补造事实没有消失(旧信年代、任职年限、公司领导、贺明珠的弟弟);小动作复读与心理旁白仍存在。方法改善的是"性情能否进入具体生活",不是文笔。
4. **模型行为依赖**:教程明确"至于某种写法是否真的让角色更自然、是否适用于当前模型,则必须通过实际输出验证,不能从论文标题直接推出"(2.2)。原理层是方向性参考,不是永恒规律。
5. **隐含的写作能力前提**:教程的整理方法假设作者已经理解自己的角色(采访/小传是发现人物的工具,在写作后台)。对"角色本身还没想清楚"的用户,这套方法提供的是容器,不是内容。
