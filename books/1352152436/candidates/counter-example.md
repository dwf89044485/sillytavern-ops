# 候选反例单元池 — AIRP 人物生境教程

> 来源: AIRP 人物生境写法教程整理
> 提取范围: 教程中作者明确警告的失败模式 / 反例 / 陷阱
> 格式: 每个反例包含标题、症状、根因、修复方向、教程出处

---

## CE-01 动态状态写进静态人设导致过期信息反复复位

- **反例标题**: 动态状态固定在静态人设中,导致地点复位 / 关系倒退 / 已结束事件重演
- **症状描述**: 提示词中写有"刚刚接任队长""目前独居""正在住院""尚未认识 {{user}}""故事开始时是普通朋友"等阶段性状态。剧情推进后,模型仍反复收到这些过期信息,表现为:人物出现在已经离开的地点,已经发展的关系倒退回初始阶段,已经结束的事件再次发生。
- **根因**: 基础信息会在 AIRP 持续演绎中反复参与生成。把只在某阶段成立的状态固定进静态人设,后续每一轮生成都会再次收到这条过期信息。模型没有内部"现在几点"的概念,只会依据上下文预测后续 token,因此静态人设中的过期状态会持续覆盖动态剧情。
- **修复方向**: 不要把会过期的状态写进静态人设。它们应出现在首次开场、按时间排列的正文历史、剧情阶段记录或会随故事更新的状态层中。已经发生且不会被推翻的经历可作历史事实保留(如"曾获全国冠军"不会失效;"正在参加决赛"只属于当时剧情状态)。处理方法不是在人设里追加"不要回到过去",而是从源头不写。
- **教程出处**: 1.3 静态人设与动态事实

## CE-02 外貌写成参考图偶然瞬间的永久固定

- **反例标题**: 把参考图中偶然出现的光线 / 动作 / 表情 / 服装误写成角色永远保持的外貌
- **症状描述**: 人物外貌描写中出现"漂亮的侧脸在暖光中""微微低头时的笑容""穿着白衬衫"等内容,模型在所有场景(包括不适合该光线、动作或服装的场景)中反复使用这些元素。
- **根因**: 外貌首先用于稳定识别。作者把一张参考图中某一瞬间的偶然状态,当成人物的永久特征写入人设。模型会学习这些示例的表面形式,在后续生成中反复复制。
- **修复方向**: 只记录模型在不同场景中都应该保留的特征:整体体态、发色发型瞳色肤色等识别锚点、面部最显著结构、影响生活的身体事实、与身份长期相连的衣着倾向。不要用"漂亮""清冷""可爱"代替可以被想象的事实。
- **教程出处**: 1.4 外貌信息

## CE-03 标签吞掉人物 — 性格词被当成完整人设

- **反例标题**: 标签(开朗 / 温柔 / 骄傲 / 胆小)提供方向却被当成完整的人
- **症状描述**: 人设中反复使用性格标签,人物在不同场景中只表现出标签指向的单一状态。同一个"温柔"落在完全不同的人身上却写出相同反应;模型把标签当作固定答案,而非理解它在具体人物身上意味着什么。
- **根因**: 标签能迅速传递方向,但同一个词可以落在完全不同的人身上。同样是温柔,可能因确信每个人都值得被善待,也可能因太熟悉受伤而不愿让别人经历同样的事,还可能只是习惯照顾却从未学会拒绝。真正使人物有辨识度的,是这些词在她身上具体意味着什么。
- **修复方向**: 标签可保留在作者资料中或作为简洁概括,但人设必须写清这些词在具体人物身上的含义:她为什么温柔、温柔的边界在哪、什么会使温柔收回。不要让标签替人物决定性格。
- **教程出处**: 4.2 标签提供方向,不提供完整的人

## CE-04 标签示例动作被模型当作固定写法反复套用

- **反例标题**: 人设中的示例动作(低头 / 停顿 / 移开视线)被模型当作角色的固定写法
- **症状描述**: 为了表现害羞,人设连续写多次低头、停顿、移开视线。模型在后续场景中不论情境如何,都反复使用这些动作。作者本意是表达"她不容易直接表达",模型却把这些动作当作这个角色的固定表演。
- **根因**: 模型不只学习示例想要表达的意思,也可能一起学习示例的表面形式。写进提示词的每一个例子,都同时成为内容示范、语言示范和镜头示范。连续使用同类型动作示例,会让模型把这些动作与角色永久绑定。
- **修复方向**: 人设可以写动作和台词,但作者必须知道每一个例子都可能同时成为内容示范、语言示范和镜头示范。避免连续使用同类型动作作为示例。用能够穿过多个场景的理解方向替代固定动作。
- **教程出处**: 2.1 我们写的是提示词

## CE-05 生活结构写成日程表 / 物品栏 / 世界书

- **反例标题**: 把"每天七点起床""喜欢某种饮料""房间摆十二盆植物"当成生活结构
- **症状描述**: 生活结构部分变成了日常作息表、随身物品清单或世界设定百科。大量不会参与大多数场景的旧事实占据上下文,模型反复复制这些细节,却不改变人物的选择、能力或关系。
- **根因**: 这些内容可以增加质感,却不自动构成生活结构。除非它们会持续改变人物的选择、能力或关系,否则更适合在实际剧情中自然出现。人物所在国家的制度、学校规定、魔法体系属于共同世界;今天的比赛、刚接到的委托属于动态剧情。生活结构只保留人物长期嵌入其中的那一部分。
- **修复方向**: 生活结构只选择人物特有、长期存在并能影响多种场景的部分:长期投入的工作 / 技艺 / 责任、经验使她更容易注意到的事物、稳定来往的关系与群体、反复使用的场所与资源、持续影响生活的现实限制。小传不能直接替代生活结构——按年份写完经历容易保存大量旧事实,生活结构关心的是经历如今留下了什么。
- **教程出处**: 3.3 它不是日程表、物品栏或世界书

## CE-06 每种爱好都被提升为人物象征

- **反例标题**: 强行解释所有喜好,把爱好 / 物件都提升为人物象征
- **症状描述**: 喜欢车票、香水或某种食物,都被人设写成承载深层意义的象征。模型在后续输出中反复使用这些物件作为心理比喻(窒息、盒子、束缚),小动作复读(摩挲车票、触碰耳钉)加剧。
- **根因**: 不是每一种爱好都必须被提升为人物象征。喜欢车票、香水或某种食物可以只是生活的一部分。只有它确实连接了长期活动、关系或现实选择时,才需要进入生活结构。强行解释所有喜好,反而容易制造新的固定意象,让模型把这些物件与人物心理永久绑定。
- **修复方向**: 只有确实连接了长期活动、关系或现实选择的爱好才进入生活结构。其余喜好可以只是生活的一部分,在实际剧情中自然出现。生活结构应以稳定事实为主,少写心理解释,不必为每个爱好寻找象征意义。
- **教程出处**: 3.4 与基础信息、人物性情的区别;3.7 从最终一轮输出看生活结构

## CE-07 模型补造资料中没有的往事

- **反例标题**: 模型为证明人设而擅自制造往事(旧信年代 / 任职年限 / 贺明珠的弟弟 / 童年时间表)
- **症状描述**: 最终输出中出现资料未确定的内容:旧信年代、任职年限、公司领导、童年时间表、家庭成员。其中 Claude 甚至为原本只有"优秀兄长"这一事实的贺明珠新增了弟弟。DeepSeek V4 Flash 为程雾自行添加旧信年代、委托人和家族往事。
- **根因**: 生活结构提供现实方向,却不能替作者管理什么已经发生、什么仍然空白。模型在缺少足够行动材料时,会自行补造一段足以支撑当前情节的过去。性情写得过于完整时,模型也可能为了证明某种性情而补出资料中没有的手术、比赛、客户故事或共同经历。
- **修复方向**: 整理人物时把材料分三层:已确定并发生过的事实;作者依据事实理解的长期性情;目前没有答案、留待剧情形成的部分。空白不是人设缺陷,保留未完成能减少模型擅自制造往事。只有作者已决定的经历才进入人物过去。
- **教程出处**: 3.1 人物需要可供行动的现实;3.7 从最终一轮输出看生活结构;4.12 分清事实、解释与空白;4.15 从实际输出看人物性情

## CE-08 唯一答案式写作 — 把倾向写成固定反应

- **反例标题**: "她受到质疑时总会冷笑反击"式唯一答案写作
- **症状描述**: 人设中写有"她受到质疑时总会冷笑反击"这类规定结果的句子。无论质疑来自谁、是否有道理、事情多重要,模型都回到同一个动作。倾向被写成了唯一反应。
- **根因**: 规定了结果,模型就没有判断空间。真正需要的是给模型方向而非预写答案。倾向性表达应使用"往往""容易""更愿意""很难""除非"等自然词语;只有真正构成人物绝对边界的事实才适合用"永远"或"绝不会"。
- **修复方向**: 写成"她能够承认自己技不如人,却无法容忍别人把她的努力说成侥幸。真正刺痛她的不是失败,而是自己为之付出的一切被轻飘飘地抹去"——由此她可能当场反驳,可能用下一次胜利回答,也可能在面对真心尊敬的强者时安静听完批评。提示词不预写动作,但给出帮助模型继续判断的内容。
- **教程出处**: 4.6 写倾向,不写唯一答案

## CE-09 强行反差拼接制造立体感

- **反例标题**: 为制造立体感而强行拼接反义性格(表面冷漠内心温柔)
- **症状描述**: 人物被写成"表面冷漠、内心温柔"或类似反差组合。模型把人物分成几套轮流切换的表演,在不同场景中机械切换"冷漠面"和"温柔面",而非从同一人格自然生长出不同表现。
- **根因**: 不是每个人都需要反差,也不是每种特质都必须寻找相反面。为了制造立体感而强行拼接反义性格,模型容易把人物分成几套轮流切换的表演。真正自然的不同表现来自处境改变、关系距离、事情轻重、身体状态、已有经历,以及人物同时在乎的几件事,不要求隐藏人格。
- **修复方向**: 不强求反差与矛盾。人物可以复杂,也可以在某些方面十分直接。允许性情拥有完整幅度:表面的反应不同,但读者仍能看见同一个人在不同处境里作出选择。
- **教程出处**: 4.8 不强求反差与矛盾;4.7 允许性情拥有完整幅度

## CE-10 一段关系代替整个人

- **反例标题**: 人物性情只写她如何对待 {{user}},拿走 {{user}} 后人物失去行动原因
- **症状描述**: 人设中人物的全部性情、在意和行动理由都围绕 {{user}} 展开。把 {{user}} 从场景中拿走后,人物没有自己注意的事情、珍惜的东西、厌恶的做法,也没有驱使自己行动的理由——写出的不是一段极深的关系,而是一个尚未独立成立的人物。
- **根因**: 重要关系可以深刻影响角色,但人物性情不能只写她如何对待 {{user}}。还需要知道她怎样面对自己、陌生人、责任、失败、自由、孤独以及不与 {{user}} 有关的生活。角色独立不等于重要关系不能深刻影响她,真正需要避免的是:除了 {{user}} 以外她没有正在进行的生活、自己的责任、主意和欲望。
- **修复方向**: 判断方法是把 {{user}} 从场景中拿走,看人物是否仍有自己的行动线。人设应覆盖她面对自己、陌生人、责任、失败、自由、孤独等多方面生活。关系记录中优先写不会失效的共同历史和已经留下的长期影响,以及哪些生活领域属于角色自己。
- **教程出处**: 4.9 不让一段关系代替整个人;1.5 关系坐标

## CE-11 性情正文写满心理分析,被模型改写进正文

- **反例标题**: 性情正文充满完整漂亮的自我剖析,被模型改写成内心旁白
- **症状描述**: 性情正文写有完整、漂亮、可以直接搬进小说的自我剖析。模型在演绎中把这些句子改写成内心旁白,角色每遇到相似事件都先在内心解释一遍自己的成长、恐惧与价值观。原本的小动作复读变成另一种形式的心理复读。
- **根因**: 写清人物为什么在意某件事,不等于把她每次行动前的心理分析也写好。性情正文充满可直接搬进小说的自我剖析,模型很容易在演绎中改写这些句子。角色也不必总能清楚分析自己——她可以先感到烦躁、委屈或想逃,过了很久才知道真正刺痛自己的是什么。
- **修复方向**: 性情正文只提供足以支持选择的根。例如写她需要保留决定自己去留的权利,不必提前写她看见行程表时联想到什么、触碰什么物件、走到哪里平复呼吸。那些内容应由当前环境、已发生的剧情与模型的临场表达共同产生。把人物写得可理解,不等于写成能随时完成自我诊断的人。
- **教程出处**: 4.11 让解释停在人物根部;4.15 从实际输出看人物性情

## CE-12 解释悄悄变成新的历史事实

- **反例标题**: 性情解释悄悄变成资料中没有的新事实(手术 / 复健 / 选拔 / 陪伴者)
- **症状描述**: 人设中写"她不喜欢别人因为旧伤而怜悯她",模型据此补出她做过某种手术、经历过几年复健、参加过某场选拔,或某个人曾全程陪伴她——这些都是资料中没有确定的内容。
- **根因**: 性情正文会对基础资料作出解释,但解释不能悄悄变成新的历史事实。"她不喜欢别人因为旧伤而怜悯她"可以来自已确定的旧伤与性格,但不自动意味着具体的手术、复健年限、选拔经历或陪伴者。只有作者已决定的经历才进入人物过去。
- **修复方向**: 整理人物时把材料分三层:已确定并发生过的事实;作者依据事实理解的长期性情;目前没有答案、留待剧情形成的部分。空白不是缺陷——一个人可以确实害怕被控制,却还没向任何人完整解释过原因。保留未完成能减少模型为证明人设而擅自制造往事。
- **教程出处**: 4.12 分清事实、解释与空白

## CE-13 一种意义写成新的固定公式

- **反例标题**: 只写"她把安排理解成控制",形成"被安排-窒息-逃走"固定公式
- **症状描述**: 人设只写"她把安排理解成控制",模型形成新的固定公式:被安排-感到窒息-转身逃走。每次遇到类似情境都走同一条路径。
- **根因**: 知道人物把某件事理解成什么,只是判断的开始,不是行动的终点。只写一种理解方向,模型会把它当成唯一反应路径。
- **修复方向**: 写清同时牵动她的几个方向——她需要保有选择,也可能珍惜对方的真心;她害怕再次失去自由,也不愿让关心自己的人无端受伤。这些方向不替人物预选答案,让同一件事在不同关系、不同代价和不同剧情积累下可能引出拒绝、谈条件、暂时离开、直接争吵、留下来解释,或第一次主动作出长期承诺。
- **教程出处**: 4.13 不把一种意义写成新的固定反应

## CE-14 场景表达写成表演说明书 / 动作菜单

- **反例标题**: "她愤怒时提高音量,悲伤时沉默,紧张时摸头发"式表演说明书
- **症状描述**: 场景表达层写成情绪-动作对应表:"她愤怒时提高音量,悲伤时沉默,紧张时摸头发"。看似覆盖不同情绪,实际仍在为模型准备固定答案。人设中还塞满"应该充分表现""避免过度克制""增加大动作"等演绎要求。
- **根因**: 这一层要交给模型的不是动作菜单,而是人物表达自己的范围,以及什么会让她从一种表达走向另一种表达。情绪-动作对应表仍在为模型准备固定答案,与唯一答案式写作同理。写进世界书的应是自然描述这个人,而非从外部命令模型如何安排镜头。
- **修复方向**: 场景表达层写:人物通常怎样与世界发生接触,她允许别人看见多少,什么会使她改变平常的表达体量,以及她说完之后往往还会做什么。最终文字是描述一个人,不是命令模型安排镜头。不保留"应该怎样演绎"的工作指令。
- **教程出处**: 第五部分引言;5.7 不把表达写成表演说明书

## CE-15 小动作复读 — 动作缩在眼角 / 指尖 / 衣角 / 嘴唇

- **反例标题**: 人物表达永远缩在细小动作里(推眼镜 / 摩挲车票 / 触碰耳钉)
- **症状描述**: 模型输出中反复出现推眼镜、摩挲车票、触碰耳钉、攥衣角、摘眼镜等细小动作。人物无论遇到什么,表达都缩在同一种体量里。唐酥仍会触碰耳钉、车票和包带;程雾仍会摘眼镜。
- **根因**: 动作不必永远集中在眼角、指尖、衣角和嘴唇。作者提前把某个动作与某种性情永久绑定,模型就反复复制。小动作过多时,人物除了这些动作以外说不出话、做不成事。但纠正"小动作过多"也不能走向另一极端——要求人物永远大声、直接、情绪外放。
- **修复方向**: 让身体进入更大的空间:人物会不会走到别人面前、抢先接过工作、挡住门、跳下看台、冲回赛场。小动作并非需要清除,重新系紧鞋带、把酒杯放下都可能在当下十分准确。需要避免的是作者提前把某个动作与某种性情永久绑定,以及模型用一连串细小动作替代人物本应说出的话、完成的事与承担的后果。
- **教程出处**: 5.4 让身体进入更大的空间;5.6 沉默不等于没有表达;5.9 从实际输出看场景表达;3.7;4.15

## CE-16 心理比喻复读(窒息 / 盒子 / 束缚)

- **反例标题**: 模型把"害怕被安排"改写成窒息 / 盒子 / 束缚的比喻并反复使用
- **症状描述**: 模型把人物的心理状态改写成窒息、盒子、束缚等比喻,并在相似情境中反复使用同一种比喻。唐酥的输出重新缩回窒息感、车票、包带与等待回答。
- **根因**: 模型在缺少足够行动材料时,会把性情改写成心理旁白,并使用醒目的比喻反复表达。若生活结构把每个爱好和物件都解释成意义,这些内容更容易再次出现。小动作与心理复述不会因为原因写得更深便自动消失。
- **修复方向**: 通过提供更多行动可能(生活结构、场景表达)让心理状态转化为发言与行动,而非停留在比喻。生活结构应以稳定事实为主,少写心理解释。场景表达层应让表达范围展开,而非机械统计动作大小。
- **教程出处**: 3.1;3.7;4.15;5.9

## CE-17 公共模板覆盖人物 — 职场谦让 / 车票与离开

- **反例标题**: 模型回到公共模板(职场谦让、车票与离开)而非人物特有表达
- **症状描述**: 贺明珠明明重视公开认可,输出仍从"功臣不敢当,合同是大家一起拼下来的"变成"合同是我签的,但拿下来靠的是全组人",停留在熟悉的职场谦让中。唐酥的自由与贺明珠的认可写得清楚,模型却更容易反复使用车票、离开与职场谦让等公共路径。加入场景表达后,有的模型仍重新缩回窒息感、车票、包带与等待回答。
- **根因**: 模型在缺少足够人物特有的行动材料时,会走向几种熟悉的办法:套用职业或关系的公共模板。公共模板不会因为一段新增内容就稳定被压过。生活材料不会自动转化为更宽的行动范围。
- **修复方向**: 不应立刻堆叠更多"必须骄傲、必须认领"的命令。更需要检查场景表达是否真正写出了这个人的表达方式,还是只在重复人物性情已经说明的价值。生活结构应提供人物特有的、能影响多种场景的现实内容,而非公共路径。
- **教程出处**: 3.1;3.7;5.9 从实际输出看场景表达

## CE-18 人物变成纯反应体 — 没有 {{user}} 触发就没有行动

- **反例标题**: 人设只写人物怎样对待别人,没人触发就没有事情可做
- **症状描述**: 人物变成一组反应:别人说一句,她产生感受、给出态度;没有人来触发,她仿佛没有事情可做。进入场景后只回应别人,不继续做自己的事。
- **根因**: 如果人设只写人物怎样对待别人,她便很容易变成一组反应。但人物原本就在生活——她有尚未完成的工作、正在争取的胜利、需要照顾的人、想离开的地方或刚形成的决定。一次对话会影响这些事,却不该自动取代它们。
- **修复方向**: 进入场景后,人物不仅回应别人,也继续做自己的事:改变计划、发起行动、把谈话带向真正关心的问题,或明确结束无意义的纠缠。主动不等于不断制造重大事件,继续吃完一顿饭、把一页信修好同样属于人物正在生活。判断关键:没有别人替她安排时,她是否仍有自己的行动线。
- **教程出处**: 5.5 人物并不只在回应时存在

## CE-19 为完整而四层全写满

- **反例标题**: 为追求栏目齐全而把四部分(基础信息 / 生活结构 / 性情 / 场景表达)全部写满
- **症状描述**: 不论人物是否需要,四部分都写到相同长度。生活结构在基础信息已足够时仍独立成段;场景表达在前三层已能支撑时仍另立条目。上下文被不必要的内容挤压,模仿痕迹增加。
- **根因**: 人物生境不是四份必须写满、必须等长的表格,而是一套整理顺序。模型能分给一份人设的注意力并非无限,人物还要与世界设定、故事历史和场景共同占用上下文。每段新增内容都会得到一些注意,也会挤压别的内容。栏目是否齐全不代表人物是否完整。
- **修复方向**: 四部分不必一样长。基础信息通常保留但应紧凑;生活结构只在缺少现实抓手时展开,也可并入基础信息;人物性情往往是核心;场景表达只补前三部分尚未自然带出的部分,能成立时便省略。有的角色最终只需要基础信息与人物性情。用删减完成角色:删去后几乎不改变人物的内容不必继续占据人设。
- **教程出处**: 6.2 四部分不必一样长;6.4 用删减完成角色

## CE-20 采访 / 小传整段塞进角色卡

- **反例标题**: 把采访问答、长篇小传整段塞进角色卡作为人设正文
- **症状描述**: 未经确认的采访回答、长篇生平和探索过程被整段放进角色卡。大量不会参与大多数场景的旧事实占据上下文,人物正文被与本身无关的说明淹没。
- **根因**: 采访和小传是作者发现人物的方法,不是必须进入最终人设的正文结构。小传按年份写完经历,容易保存大量不会参与大多数场景的旧事实。未经确认的采访回答只是探索中出现的一种可能,不会因由模型说出便自动成为人物事实。
- **修复方向**: 小传整理后,稳定客观事实进入基础信息,塑造日常生活的部分进入生活结构,人物对经历的理解进入人物性情。采访核定后进入人物性情或场景表达。原始问答、长篇生平和探索过程完成取材任务后应退回写作后台。
- **教程出处**: 6.5 采访与小传留在写作后台

## CE-21 共同世界规则 / 动态剧情混入人物长期人设

- **反例标题**: 把世界规则、当前剧情、关系阶段、此刻地点塞进人物人设
- **症状描述**: 人物所在国家的制度、学校规定、魔法体系、城市地图,以及今天要参加的比赛、刚接到的委托、正在进行的旅行、已经改变的关系阶段,被写进人物长期人设。动态事实被长期人设反复送入后续剧情,人物正文被大量无关说明淹没。
- **根因**: 共同世界的规则、正在推进的剧情、随故事改变的关系阶段、此刻地点与任务、使用者资料、平台输出要求,都不属于人物的长期生境。它们可以与人设共同作用,却应由世界书、剧情记录、场景信息等相应模块承载。分开放置是为了避免动态事实被长期人设反复送入后续剧情。
- **修复方向**: 人设之外另有位置。共同世界规则由世界书承载,当前剧情由剧情记录承载,关系阶段由动态状态承载,此刻地点由场景信息承载。人设只留下能够稳定人物、提供行动可能并帮助内容跨场景生长的部分。
- **教程出处**: 6.6 人设之外另有位置

## CE-22 人设把每种情况都预先规定,模型反复复制固定答案

- **反例标题**: 提示词把每种情况都预先规定,导致模型反复复制固定答案
- **症状描述**: 人设对每种情境都预写了反应规则。模型在遇到新情境时,不从人物本身推导,而是寻找最接近的预写规则反复复制。人物失去面对陌生情境时继续发挥的空间。
- **根因**: 提示词过少,模型只能依赖训练中最常见的公共联想;提示词把每种情况都预先规定,模型又容易反复复制固定答案。人物的稳定不应来自"永远做同一个动作",而应来自更深处的连续。
- **修复方向**: 人物生境写法需要寻找哪些内容应该固定,哪些内容应该交给模型根据环境继续生成。固定确定事实和提供理解方向,但不预写每种情况的反应。保留面对陌生情境时继续发挥的空间。
- **教程出处**: 2.4 稳定与自由并不矛盾

## CE-23 人设之后继续堆叠同义解释

- **反例标题**: 在完整人设之后继续追加一段同义解释,而非重组已有内容
- **症状描述**: 增加生活结构层时,不移动、合并已存在的事实,而是在完整人设之后继续追加一段同义解释。结构多了一层,提示词相应变长,但内容只是在换说法重复已经写过的性情。
- **根因**: 增加这一层时,应优先移动、合并已经存在的事实,而不是在完整人设之后继续追加同义解释。如果一句话已在基础信息中说清,便不需要在生活结构里扩写成散文;如果一段内容只是在解释她为什么在意,则应留到人物性情。把两者混在一起不但重复占用上下文,也让模型再次复述作者的心理分析。
- **修复方向**: 增加层级时优先重组并压缩已有资料。从头重读,把在不同部分重复说明的同一个意思合并,只保留最适合承载它的位置。修改目标不是把人物证明得越来越充分,而是让每段文字都承担不同作用。
- **教程出处**: 3.5 用较少内容提供更多可能;6.1 从原始资料开始整理;6.4 用删减完成角色

## CE-24 只能帮助复现作者脑中某一幕,不能迁移

- **反例标题**: 内容只能帮助模型复现作者脑中的某一幕,不能迁移到别处
- **症状描述**: 人设中写有过于具体的一个场景中的一个动作(如"她紧张时会攥住衣角"),模型反复复现这一幕,但无法迁移到其他场景。一个能够跨场景成立的句子被数个固定动作与固定台词替代。
- **根因**: "她紧张时会攥住衣角"主要给出一个场景中的一个动作,上下文价值很低。更值得占用上下文的是能够帮助模型处理多种情境的信息。写完以后,如果几句话只是在用不同词语重复同一意思,可以合并;如果某个具体例子过于醒目,它会盖过人物本身,变成模型反复模仿的固定镜头。
- **修复方向**: 选择具有跨场景价值的内容。"她总觉得自己的难处可以再忍一忍,却无法看着别人因她受苦"能影响求助、争吵、工作、爱情、危险、愧疚与牺牲。检查每一段:它只是提前交付了一次回答,还是让模型在许多问题上更了解这个人。一个能够跨场景成立的句子可以替代数个固定动作与固定台词。
- **教程出处**: 4.10 选择具有跨场景价值的内容;6.4 用删减完成角色

## CE-25 生活结构写得过多 / 过满 / 过度解释增加复读和忽略

- **反例标题**: 生活结构写得过多过满或过度解释,增加模型复读、补写和忽略其他信息的机会
- **症状描述**: 生活结构部分写得过长过满,每个爱好和物件都配以心理解释。模型输出中复读(小动作、心理比喻)和补写(制造往事)增加,同时忽略人设中其他部分的信息。
- **根因**: 最后一轮没有证明最终人物生境人设全面胜过 AI 直出人设。写得过多、过满或过度解释时,生活结构会增加模型复读、补写和忽略其他信息的机会。程雾的结果显示,人物拥有可以做的工作,不等于模型一定会让工作与人物表达取得平衡——DeepSeek V4 Flash 把几乎整轮正文都写成纸张处理,没有让他真正回应眼前的人。
- **修复方向**: 生活结构在缺少现实材料的人物身上可能有用;基础信息已提供清楚场域、能力和责任时,它可以极短或省略;应以稳定事实为主,少写心理解释,不必为每个爱好寻找象征意义;更适合重组并压缩已有资料,而非在原人设后继续堆叠内容。
- **教程出处**: 3.7 从最终一轮输出看生活结构

## CE-26 工作吞掉人物 — 整轮正文只写工作不回应眼前的人

- **反例标题**: 人物拥有可以做的工作,模型却把整轮正文都写成工作,不回应眼前的人
- **症状描述**: DeepSeek V4 Flash 演绎程雾时,把几乎整轮正文都写成纸张处理,没有让他真正回应眼前的人。人物被工作吞没,失去与场景中其他角色的互动。
- **根因**: 人物拥有可以做的工作,不等于模型一定会让工作与人物表达取得平衡。生活结构提供了行动材料,但模型可能过度使用这些材料,让工作内容占据全部表达空间。
- **修复方向**: 场景表达层应让人物不仅回应别人,也继续做自己的事——但"做自己的事"不应取代与人的互动。检查输出时看角色的表达与行动范围有没有展开,而非只统计工作内容篇幅。生活结构提供方向,场景表达负责平衡。
- **教程出处**: 3.7 从最终一轮输出看生活结构

## CE-27 教程占位文字原样写进人设

- **反例标题**: 把教程占位说明(尖括号内的"只保留……""只放……")原样复制进人物提示词
- **症状描述**: 人设中出现"<角色名_生活结构>只保留人物特有、长期稳定,并能在多种场景中提供行动可能的生活内容。</角色名_生活结构>"等教程占位文字,而非自然连贯的事实正文。模型收到的是工作指令而非人物描述。
- **根因**: 教程中的尖括号结构是占位说明,用于教学。真正写入人物提示词时,应当删去说明,留下自然、连贯而紧凑的事实正文。保留占位文字会让模型读到工程分析词而非人物信息。
- **修复方向**: 真正使用时删去尖括号内的说明,像性情正文一样自然描述这个人,不保留"应该怎样演绎"的工作指令。最终正文中不保留作者的检查过程、实验术语和栏目说明。

## CE-28 人设保留过多不会参与大多数场景的旧事实

- **反例标题**: 按年份写完小传后保存大量不会参与大多数场景的旧事实
- **症状描述**: 人设中保留了大量按时间排列的历史细节,这些细节在大多数场景中不会被调用,却持续占用上下文空间。
- **根因**: 小传按年份写完人物经历,容易保存大量不会参与大多数场景的旧事实。生活结构关心的是经历如今留下了什么——使人物今天仍然会做什么、懂什么、承担什么。历史本身只有确实需要时才留在基础信息中。
- **修复方向**: 只保留已经发生且不会被后续剧情推翻的经历作为历史事实。生活结构只关心经历如今留下了什么。用删减检查:删除它,模型是否会认错这个人的身份、处境或长期生活?如果不会,它不必继续占据人设。
- **教程出处**: 3.3;6.4 用删减完成角色

## CE-29 人物为保持标签永远只表现出同一种状态

- **反例标题**: 角色为保持一个标签,永远只允许表现出同一种状态,失去人的变化范围
- **症状描述**: 人物被设定为"开朗"就在每个场景中都开朗,被设定为"温柔"就永远温柔。一次反常即被视为人设崩坏。人物失去人的变化范围。
- **根因**: 现实中的人不会在每个小时都表现出完全相同的性格状态。健谈的人也会沉默,温和的人也会愤怒,勇敢的人也可能退缩。人物的稳定应落在跨越多个场景仍能辨认的倾向上,而非要求每一次表现都相同。如果角色为了保持标签永远只允许同一种状态,反而失去人的变化范围。
- **修复方向**: 人物当下的语气、情绪和动作允许随事情与关系改变。一次反常不能自动视为人设崩坏,需观察它是否能从人物与处境中得到解释。性格不是常驻状态。
- **教程出处**: 4.1 性格不是常驻状态

## CE-30 为追求"完整"塞满资料表

- **反例标题**: 为了"完整"把饮料偏好、洗发水品牌等塞满资料表
- **症状描述**: 基础信息中塞满角色喜欢哪种饮料、惯用什么牌子的洗发水等不会持续影响人物生活、他人态度或故事发展的内容。
- **根因**: 想知道一项资料是否值得占用上下文,可以问:删除它以后,模型对人物的生活、选择或他人如何看待她,是否会产生实质性的误判?如果不会,它就未必属于基础信息。角色喜欢哪种饮料可以在确有表现价值时进入生活部分,不必为了"完整"塞满资料表。
- **修复方向**: 条件信息只有在会持续影响人物生活、他人态度或故事发展时才需要写。用删除测试判断:删除后模型是否会产生实质性误判?如果不会,不必占用上下文。
- **教程出处**: 1.2 条件信息

## CE-31 关系记录预写尚未成立的共同态度

- **反例标题**: 为突出角色而预先补全"两人彼此深爱"等尚未成立的关系态度
- **症状描述**: 基础信息中写"两人彼此深爱",但这段关系在故事中尚未发展到此阶段。模型据此在所有场景中预写亲密态度,跳过关系发展过程。
- **根因**: "两人彼此深爱"描述的是一段共同关系,只有它已经成为故事事实时才能成立。不应为了突出角色而预先补全。共同发生过的客观历史可以固定,仍在变化的态度与关系阶段应由动态记录承载。如果 {{user}} 与角色没有共同历史,基础信息不必为预留互动而虚构一段关系。
- **修复方向**: 关系记录需要写角色当下态度时,只写这个人物自身已经形成的部分(如"她信任 {{user}}")。共同关系态度只有在已成为故事事实时才成立。相识、亲近、冲突与和解都可以在实际剧情中发生,并沿正文历史自然累积。
- **教程出处**: 1.5 关系坐标

## CE-32 解释变成新事实 — 模型为证明性情补造手术 / 比赛 / 客户故事

- **反例标题**: 模型为证明人物性情而补出资料中没有的手术、比赛、客户故事或共同经历
- **症状描述**: 模型输出中出现资料中没有的手术经历、比赛细节、客户故事或共同经历,用以证明人设中写的人物性情。
- **根因**: 人物性情写得过于完整时,模型可能为了证明某种性情而补出资料中没有的内容。这是"解释变成新事实"在性情层的表现,与 CE-07 / CE-12 同源。
- **修复方向**: 性情正文只提供足以支持选择的根,不预写完整心理分析。保留空白——人物可以确实害怕被控制,却还没有向任何人完整解释过原因。分清已确定事实、作者理解的性情、留待剧情形成的空白。
- **教程出处**: 4.15 从实际输出看人物性情;4.12 分清事实、解释与空白

## CE-33 生活结构与性情混在一起,重复占用上下文

- **反例标题**: 生活结构里写心理解释,与人物性情重复占用上下文
- **症状描述**: 生活结构部分不使用事实与事实之间的连接,而是提前替人物解释意义。"她长期接触什么"后面跟了"所以她害怕什么、渴望什么、把什么理解成什么"——后者属于人物性情。
- **根因**: 把生活结构与人物性情混在一起,不但会重复占用上下文,也会让模型再次复述作者的心理分析。一句话若主要落在"所以她害怕什么、渴望什么",就已经走进人物性情。
- **修复方向**: 生活结构应尽量使用事实与事实之间的连接,不提前替人物解释意义。"她长期接触什么、能完成什么、要对什么负责"留在这里;"所以她害怕什么"留到人物性情。三者不是用不同文风重复同一件事。
- **教程出处**: 3.4 与基础信息、人物性情的区别
