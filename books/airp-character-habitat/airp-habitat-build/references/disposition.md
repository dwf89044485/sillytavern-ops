# 人物性情 · 访谈与起草

> 阶段 3 用。角色答案的唯一来源是用户；本文件是你的提问素材与起草判据，不展示给用户。

## 提问方式（五条）

1. **从抽象到具体情境**：不问"角色怎样理解冲突"，问"两个人吵起来，角色更担心关系破裂，还是觉得终于把话说开了"。
2. **给选项但不限选项**："更接近哪种？都不对的话，角色是什么样的？"
3. **从角色已说的事实出发提问**，不按清单顺序。用户提到过"角色有个优秀的哥哥"，就问这个哥哥，不问清单上还没影的。
4. **追问细节优先于推进清单**。用户给出有趣回答时，"你刚说的那个细节，能多说说吗"比问下一个问题更重要。
5. **提问是为认识角色**，答案不直接进正文。

## 访谈问题

从用户已说的事实里挑相关的问，一次 2-3 问。用户答"没想过"就记空白——空白不是缺陷，不代填。

### 标签的含义

用户给出标签（"温柔""骄傲"）时，问出这个标签在角色身上具体意味着什么——同一个词落在不同人身上完全不同。选项参考（给用户选，不是你替他选）：

- 温柔——[因为确信每个人都值得被善待 / 因为太熟悉受伤，不愿让别人经历同样的事 / 习惯照顾所有人，却从未学会拒绝 / 平日柔和，一旦发现自己的好意被用来伤害第三个人，就立即收回宽容]
- 骄傲——[需要胜利证明自己 / 不允许别人看见自己的困境 / 能承认技不如人，却无法容忍人格被轻视 / 享受强敌和失败，因为那意味着仍有可以攀登的地方]

问不出 → 正文先写方向词，把"具体含义未定"记入空白清单（阶段 5 呈现）。禁止用"标签+几个动作"填充。

### 主题一 · 角色怎样理解事情

- 有人对角色说"我来帮你"——角色第一反应是"这人真好"、"他是不是觉得我不行"、"他在跟我较劲"、"他想控制我"、"他可怜我"，还是别的？
- 角色需要求助时，开口之前怎么想——"这是信任对方"、"我在麻烦别人"、"这等于承认自己无能"，还是"这是关系亲近的证明"？
- 角色搞砸了一件重要的事，最先冒出的念头是"我不够好"、"准备不足"、"运气差"、"辜负了相信我的人"，还是"下次怎么赢回来"？
- 两人起冲突，角色更担心关系破裂、觉得终于把话说开了、把冲突当输赢较量，还是觉得必须有人站出来承担？
- 有人未经角色同意替角色做了决定——角色会把这件事理解成什么？被冒犯、被照顾、被控制，还是别的？

**答不出时**：记空白，不追问。后续写性情时这一维度留白即可——角色不需要对每类事件都有确定的理解方式，只需确实重要的那几个。

**提炼**：识别回答中反复出现的模式（总是先怀疑动机 / 总是先自责），写成一句跨场景倾向，如"角色容易先把别人的好意听成否定"。

### 主题二 · 角色真正在乎什么

- 两件都重要的事冲突时——"被人理解"和"不暴露脆弱"，角色更难放下哪个？换一组："赢"和"不伤害无辜的人"。
- 角色每天醒来，有什么事是角色觉得"今天必须做"或"绝对不能搞砸"的？不是日程表上的事，是心里那根弦。
- 有什么事是角色一直在躲的？不是怕虫子那种，是宁可绕远路也不想面对的事——被人可怜、被人看穿、被人安排、被人忘记？
- 用户想不出方向时，给方向词脚手架：归属、体面、自由、胜利、安全、被需要、家人的生活、理想中的自己——从里面挑角色放不下的。

**答不出时**：最多换一次角度（"那先不想冲突，就说说角色最怕失去什么？哪怕只说一个。"）仍答不出 → 记空白。角色在这方面还没定型，留白即可。

**提炼**：用户说的具体冲突（"角色会在 X 和 Y 之间选 X"）不直接写入。提炼为方向："角色更难以放弃的是____，即使这意味着____"。用户只说得出在乎、说不出冲突时，只写在乎的方向，不强行构造两难。

### 主题三 · 角色怎样看待自己

**问法 A**：

> 如果让角色用一句话总结"我是个怎样的人"——不是社交场合的客套话，是夜深人静时真的相信的那句——角色会说什么？比如"我这辈子就是来还债的"、"我比他们都强，只是还没证明"、"我其实没那么重要"。

**问法 B（从行为倒推）**：

> 角色上次帮了别人一个很大的忙，对方特别感激——角色心里是"这是我该做的"、"这下他欠我了"，还是"终于有人需要我了"？
> 反过来：角色上次需要别人帮忙的时候，开口之前犹豫了吗？犹豫的是什么——怕被拒绝、怕显得无能、怕添麻烦，还是觉得"我没资格要求别人"？

**补充两问**：

- 角色做错事的时候，是容易原谅自己，还是会在心里反复骂自己？会道歉吗，还是做不到开口道歉？
- 如果角色经历过明显的改变：现在怎么回看改变前的自己——觉得那时候傻、心疼那时候的自己，还是别的？

**答不出时**（三个主题里最常见的）："这个确实不好答，很多人写角色时不会专门想这个。先放着，等前面聊的内容多了，它可能自己浮出来。"始终答不出，记空白。

**提炼**：用户的自我描述（"角色觉得自己不配"）转为结构化表达："角色对自己的默认判断是____，这个判断连着角色生活里的多个表现"。保留角色**目前**用来理解自己的长期认识，不把剧情尚未发生的成长写成结论。

## 起草

1. 从用户已说的内容提炼：先列角色已确定的方向，不追求特殊。
2. 提炼动作：`[跨轮回答里反复出现的表现]` → 提炼根因（自己分析，不再问用户）→ 写成倾向句。写前先确认一次："我听了这么多，感觉角色有一个很深的在意是____，对吗？"
3. 不逐条回答访谈问题，不保留访谈痕迹；正文是连贯的人物文字。

## 写什么

- 写角色**跨场景仍成立的倾向**：在意什么、把什么理解成什么、怎么看待自己、几件在意的事冲突时更难放弃哪个。
- 不只写角色如何对待 {{user}}——还要写角色面对自己、陌生人、责任、失败时的部分。
- 用倾向词：往往、容易、更愿意、很难、除非。"永远/绝不会"只用于绝对边界。
- 写同时牵动角色的多个方向，不替角色预选答案——同一件事在不同关系、不同代价下可以引出不同选择。

## 不写什么

- 不写可重复的物理动作句（`[身体部位]+[动作]`）——写进人设的每个例子都会被模型当固定写法学走。
- 不写内心旁白（看见什么→联想到什么→做什么平复）——心理过程写满，模型会整段复读。
- 不写只对一个场景成立的反应——那是提前交付一次回答，不是让模型更了解角色。
- 不把推断写成事实——只有用户确认过的经历才进入角色的过去；推断要标出来交用户确认。

## 起草后自查（展示给用户前逐项过）

1. **根部**：每句是"角色为什么在意"（留），还是"角色遇到某事会怎样"（删）。
2. **空白**：有没有把推断写成事实、补造用户没提过的经历（手术/比赛/家庭细节）？
3. **跨场景**：每段只对一种场景成立，还是能支撑多种未写出的剧情？只成立一种 → 删或合并。
4. **幅度**：只写了常态，还是也写了什么会改变角色？有没有强行拼反差（"表面冷漠内心温柔"式）？

## 输出

```text
<角色名_人物性情>
自然、连贯的正文。
</角色名_人物性情>
```

## 限度

即使用户确认过、写法也正确，模型仍可能补造事实、重复小动作、退回公共模板。用户反馈演绎不佳时：先检查这层是否真写出了角色（对照上四条自查），不靠堆字数和"必须如何"的命令压制。
