  source_quote: |
    "衍生就是一个超级压缩包，它压缩了很多东西，而ai是可以解开这个压缩包并使用的......把抽象的特质展开成具体的场景和行为，并给出背后的原因。"
  summary: |

  type: framework
  source_chapter: 11号教程 第五章
  source_quote: |
    "这一章写的不是情绪的样子。写的是情绪的阈值。什么让她从正常状态变成开心。什么让她从开心停下来。什么让她从正常状态变成愤怒。什么让她从愤怒冷却。你写的是一条条线。"
  summary: |
    一种替代传统"情绪描写"的角色情绪建模方法。不写"开心的时候她会微笑/眼睛弯成月牙"（因为这些AI数据库里已有），而是为每种核心情绪定义三条线：触发（什么让她进入该情绪）、过程（情绪的变化轨迹，不是静止画面）、结束（怎么从该情绪出来，出来以后落到哪）。模型的核心洞察是：情绪之间有互相渗透（开心时焦虑可能正在追上来），这种渗透不需要解释，动作本身就说了。

  title: "绝对内核"锚定法
  type: framework
  source_chapter: 6号教程 第三章
  source_quote: |
    "每个角色身上都有一个'绝对的东西'，一个不管发生什么都不会改变的内核。你要在一开始就把它定死，后面所有的设计都围着它转......这个'绝对'一旦定下来，后面所有的画面、衍生、两面性全都有了方向。"
  summary: |
    在设计角色的第一步（甚至先于调色盘），先确定一个"绝对不变的内核"。这个词不是标签，而是一个可在所有场景中反复验证的命题（如"偏爱没有输过"）。一旦确定，后续所有衍生、画面、拆面、进化规则都围绕这个不变内核展开。其核心价值在于：防止作者自己在写作过程中摇摆（写出角色"差点打破内核"的矛盾描写），也防止AI在演绎中侵蚀角色的核心设定。变化的东西给新鲜感，不变的东西给安全感。
  tags: [角色锚定, 不变内核, 设计起点, 防止摇摆]

  title: 三面性判断标准
  type: framework
  source_chapter: 2号教程 第三章；大总结教程 03_三面性篇
  source_quote: |
    "这个角色在不同场景下，行为模式是否有根本性的切换？注意用词：根本性。不是'稍微放松一点'，不是'语气变了'，是整套行为逻辑都换了一套。"
  summary: |
    决定一个角色是否需要三面性（多面性拆解）的判断框架。核心判据不是"有没有不同场景"，而是"不同场景的压力性质是否截然不同"。压力性质指社会规训、情感压力、生存极限等本质差异——只有压力性质不同的场景才需要拆面。同时提供反向判断：找不出两个以上压力性质截然不同的场景就不需要硬拆，否则AI会在模式间生硬切换导致角色割裂。

  type: framework
  source_chapter: 4号教程 第三章；大总结教程 04_混色篇
  source_quote: |
    "什么是物理事实？就是不带任何感情的客观描述。'她说就是有点热。那天是阴天，不算热。'两句话放在一起，不需要解释，读的人自己就看出来了......它让AI不需要去'演'一个复杂情绪，只需要把两个事实摆在一起。"
  summary: |
    混色写作中最核心的技巧：将两个客观物理事实并置，利用它们之间的反差让读者/AI自己完成情绪的拼合。例如"她说'我没事'+她的手在抖"——不需要写"她其实很害怕但在逞强"，两个事实之间的裂缝自动产生混色效果。这个技巧的精妙在于：它不要求AI"表演复杂情绪"，只要求AI"重现画面"，而画面本身已是混色的。避免了一切"她的微笑中流露出复杂情感"式的八股写法。

- id: f12
  title: 从单色衍生到混色画面的转换方法
  type: framework
  source_chapter: 4号教程 第四章；大总结教程 04_混色篇
  source_quote: |
    "第一步：把你调色盘里的衍生全部摊开看一遍。看看哪些衍生之间会在现实中'撞到一起'......第二步：把这些撞在一起的瞬间写成画面。只写动作，不写解释。第三步：不要解释混色，让它自己在那里。"
  summary: |
    将调色盘中分列的衍生转换为混色画面的四步操作法：一、摊开所有衍生找"会撞在一起"的颜色组合（在同一个现实场景中会同时被触发的两种以上颜色）；二、把碰撞瞬间写成具体动作画面（只写动作、台词、物理事实）；三、不加任何解释（不写"因为""本质上"）；四、控制密度（混色是点睛之笔，不是底色。大部分时间情绪单一，混色只出现在碰撞点）。这是一个从"分解"到"融合"的系统化转换流程。
  tags: [混色流程, 衍生碰撞, 画面写作, 四步法]

    一个检验角色描写质量的操作性测试：遮住角色名字后，仅凭描写内容是否能唯一识别出这个角色。如果遮住名字后描写"放在谁身上都行"（如"精致的脸蛋、白皙的皮肤"），说明写的是万能模板而非角色特征。这个测试适用于外貌、行为描写、对话风格等，核心思想是"特征=只有这个角色才有的东西"。
