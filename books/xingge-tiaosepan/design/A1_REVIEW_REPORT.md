## 一、一致结论

### 1.1 A1 必须展示"追问过程"，不能只展示"方法论产物"

**三个 agent 一致。**

如果 A1 写成"陈乖乖的调色盘：底色不甘心/主色调把乖当盔甲/点缀藏着的温度，共 11 条衍生"——这是产品说明书。agent 看到不知道该怎么问。

agent-1："agent 需要的是'晴空妈妈问了什么→柚子怎么回答→晴空妈妈怎么接'的完整追问链路。"

agent-2："主镜头对准引擎，方法的成功作为引擎成功的副产品出现。"

agent-3 给这个坑起了名字：**把 A1 写成 testimonial（证言）而不是 case study（案例研究）。** testimonial = "作者用追问法帮柚子从七个标签走到了完整调色盘，效果很好"——只说方法有效，不说方法怎么用。

### 1.2 A1 应该展示 I 段"说不出的东西"

I 段能写抽象规则（"追问到只有她才这样就停""不替用户生成""多入口路由"）。A1 应该展示这些规则在真实对话中的纹理：

| I 能说的（抽象规则） | A1 补充的（对话纹理） |
|---------------------|----------------------|
| "追问到只有她才这样就停" | 晴空妈妈问了"为什么安静"，柚子说"不想添麻烦"，晴空妈妈没有停——继续问"这背后只有不想添麻烦吗？"→ 追问的深度感 |
| "多入口路由" | 三个真实入口长什么样：标签入口（7 个形容词）vs 画面入口（一个丧尸咧嘴笑）vs 快速入口（闭上眼看一段生活） |
| "不替用户生成" | 晴空妈妈等柚子自己说出"不甘心"而不是告诉她"你的底色应该是不甘心"；姜糖案例中作者否掉 AI 的"差点冲破偏爱" |
| "路径不固定" | 陈乖乖从标签→基础信息；姜糖从画面→内核→基础信息最后写；三明月完全跳过调色盘 |

agent-2："I 给 agent 一张引擎蓝图，A1 给 agent 一段引擎运转的录影。蓝图说'这里有挑战动作'，录影展示'挑战动作长这样、在这个时机出现、用户这样回应'。"

### 1.3 char-build-guide 的 A1 必须保留关键追问回合的对话片段，不能完全叙述化

普通 skill（世界书配置）的 A1 可以叙述化——"作者遇到绿灯不触发→检查关键词→调整→解决"。因为方法是一组操作步骤。

但追问引擎的"方法"就是**对话本身**。"晴空妈妈通过追问让柚子发现了不甘心"——这种叙述概括丢失了全部类比价值。agent 不知道追问怎么问的、用什么措辞、在哪切入。

agent-2 具体要求："保留 2-3 个追问回合的原始对话（用户答→引擎挑战→用户修正→到达下一步），每个回合标注引擎做了什么动作（挑战/接住+推进/命名/校验）。"

### 1.4 反面案例不放 A1，放 B 段

agent-3 给了三个理由：

1. A1 的定义是"作者亲自用过这个方法论的案例"。教程里的错误是柚子犯的，晴空妈妈的追问本身就是正确的。作者没有"亲自用错"过。
2. B 段的定义天然匹配——"作者警告的失败模式"。AI 替用户生成、追问过度、暴露术语——属于 B 段。
3. A1 放反面案例会模糊其作用——agent 需要"正确的追问长什么样"，不是"错误的追问长什么样"。

**例外：正面案例的"问题"部分可以自然包含用户犯错→追问纠正的情节。** 柚子写"极度自卑"的标签化错误被追问纠正为"不甘心"——这是正面案例的问题部分，不是反面案例。

## 二、关键分歧

### 2.1 选几个案例

| agent | 推荐数量 | 理由 |
|-------|---------|------|
| agent-1 | **3 条** | 用满上限。覆盖标签入口、画面入口、快速路径三种不同追问形态 |
| agent-2 | **1-2 条** | 陈乖乖（调色盘篇）为主；如需第 2 条取核心人格层篇——同角色不同深度 |
| agent-3 | **3 条** | 按入口类型差异化，不按角色差异化。如果必须砍到 2 条，去掉三明月 |

### 2.2 选什么案例

| 案例 | agent-1 | agent-2 | agent-3 |
|------|---------|---------|---------|
| **陈乖乖**（标签入口，调色盘篇） | ✅ | ✅ 首选 | ✅ |
| **姜糖**（画面入口，实战篇） | ✅ | ❌ | ✅ |
| **三明月**（快速路径，入门篇） | ✅ | 未提 | ✅（最低优先级） |
| **陈乖乖**（核心人格层篇，同角色更深层） | 未提 | ✅ 可选第 2 条 | 未提 |

### 2.3 争议焦点：姜糖适不适合 A1

**agent-2 的反对**（最具体的反对意见）：

> "姜糖篇里没有追问引擎在运转。是作者自己走完了全程。画面→内核→意象→混色→多面性——这是构建弧线，对追问引擎的 agent 来说，它不知道'追问'这件事到底长什么样。姜糖展示的是'好的角色卡长什么样、怎么拼出来'，不是'引擎怎么转'。姜糖的构建弧线是 E 段和 A2 的素材，不是 A1 的素材。"

**agent-1 的隐含回应**（来自案例选择逻辑，非直接反驳，agent-1 和 agent-2 各自的报告是独立产出的）：

agent-1 选姜糖的理由不是"它展示了追问对话"，而是"它展示了画面入口的追问方向不同于标签入口"——作者问自己三个问题（核心驱动力/用户动力/长期性）、做丧尸化颜色转换、否决 AI 的"差点冲破偏爱"。这些**是追问**，只是追问对象是自己。agent-1 关注的是追问形态的多样性，agent-2 关注的是追问的对话纹理。

## 三、各 agent 独到见解（未被其他 agent 覆盖）

### agent-1 独到

- **追问的"否决"动作是追问引擎的一半技术。** 姜糖案例中作者否掉 AI 的"差点冲破偏爱"（"偏爱没输过，哪来的差点冲破？"），三明月案例中作者标注"她在说谎"。如果 A1 只写"问了→答了→得到了"，漏掉否决。
- **结果必须可验证。** "角色变活了"不是结果。结果必须是：柚子的原话（"原来那只是七个标签，现在是一个人"）、姜糖的数据（新号两天 91 赞）、三明月的定位（被作者确认为"平替"方案）。

### agent-2 独到

- **追问的"挑战"措辞和力度只有 A1 能展示。** 晴空妈妈不说"你的标签不对"，她说"一个极度自卑的人能做到年级前列吗？"——用角色自身的行为反证标签。I 段可以抽象地说"挑战用户的第一个答案"，但展示不了挑战的具体措辞。
- **深化节奏中的**"接住一部分、推另一部分"**。** 柚子说"不想给别人添麻烦"→ 晴空妈妈接住"不想添麻烦"但推"一个不甘心的人选择乖，背后只有不想添麻烦吗？"——这是追问引擎最精密的操作，I 段无法表达。

### agent-3 独到

- **A1 的"结果"部分需要和 I 段的判停标准对齐。** 如果 I 段判停标准是"遮住角色名换一个角色还成立吗"，A1 的"结果"应该体现这个判停——"追问产出的内容遮住名字后别的角色不成立"（可检查），不是"角色变立体了"（太抽象）。否则 agent 收到矛盾信号。
- **信息密度公式：** 每条 A1 ≈"问题 1 句 + 使用 2-3 句 + 结论 1 句 + 结果 1 句"= 5-6 句。3 条 = 15-18 句。"使用"部分必须同时包含两个信息：追问问了什么（具体措辞方向）+ 追问沿什么方向推进（标签→行为？画面→内核？）。

## 五、对后续段落设计的启示（审阅中自然浮现）

虽然审阅聚焦 A1，但三个 agent 在分析过程中不约而同触及了其他段的设计：

- **A2（trigger）**：agent-2 指出姜糖的构建弧线更适合 E/A2——因为它展示了"用户可能以什么形态进入"（画面入口的语言信号）。A2 的 trigger 描述可以参考姜糖案例中用户的实际状态（"脑子里只有一个画面"）。
- **E 段（执行步骤）**：agent-1 和 agent-2 都提到姜糖和三明月的路径属于 E 段的多入口路由逻辑，不是 A1。
- **B 段（边界）**：agent-3 明确指出 AI 替用户生成、追问过度、暴露术语属于 B 段素材。姜糖中"不要写成'她差点咬下去'"是典型的 B 段素材。
- **I 段（方法论骨架）**：agent-3 提出 I 段的判停标准和 A1 的"结果"表述需要对齐，这在写 I 段时需要考虑。
