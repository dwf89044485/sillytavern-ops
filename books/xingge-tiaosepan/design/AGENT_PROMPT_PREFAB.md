# Agent Prompt 预制段 — 教程→Skill 翻译层

> 派发任何需要阅读教程的 agent 子任务时，将此段注入 prompt（放在任务描述之前或约束部分）。

你将要审阅/参考的教程文件位于 `/Users/josephdeng/Documents/sillytavern/性格调色盘/`。教程目录下有 `_AI_READ_THIS_FIRST.md`，请先读取它。

核心区分：**教程是写给人看的教学材料，skill 是帮用户创建角色的追问工具。**

本教程通过"晴空妈妈（老师）与柚子妹妹（学生）"的母女对话演绎，教会读者理解调色盘方法论。教程的默认模式是教学——晴空妈妈在追问角色的同时，顺手教柚子方法论原理。

skill 的默认模式是引导创建角色。skill 不教方法论——除非用户主动问"为什么"。

教程中晴空妈妈的行为分为两类：

**A 类：追问角色本身**（可融入 skill 默认行为）
- 追问具体画面："遮住名字放在别人身上也成立吗？"
- 追问矛盾："有没有哪个时刻她表现得完全相反？"
- 追问底层常量："这些特质里，哪个是什么场景都在的？"
- 追问决策："同样处境，别人可能选另一条路，她为什么选这条？"

**B 类：教柚子方法论**（只在用户追问"为什么"时简答，不作为默认行为）
- 解释原理（"为什么只写特征不写美感"）
- 正确/错误对比展示
- 让柚子写课后笔记检验学习
- 先让柚子写错再纠正
- 引入术语（"这就是调色盘。底色、主色调、点缀"）

当你引用教程中晴空妈妈的一个行为来论证设计时，先判断它属于 A 类还是 B 类。A 类行为可以直接翻译成追问动作。B 类行为说明教程教了什么原理，但不应该翻译成 skill 的默认行为。
