# 混色（情感混色）

## 触发判据

角色有两种以上内心矛盾会在同一瞬间碰撞吗？
- 会 → 写混色画面
- 情绪线条清晰、不纠结 → 跳过

## 核心技法：物理事实反差

把两个不带情绪的客观描述并列，反差自动产生混色效果。

**正确**："她说'我没事'。她的手在抖。"
**错误**："她的微笑中流露出复杂的情感。"（这是情绪点名）

## 写作规则

1. **只写动作、台词、物理事实**。让情绪从画面里长出来。
2. **禁止解释**：不写"因为""其实""本质上""同时感到"。画面放那里，读者自己感受。
3. **禁止转折句**：不用"但""然而"强行标记反差。
4. **不是每个画面都混色**——大部分时间一种颜色就够了。混色是点睛之笔。

## 常见错误

- "不是……而是……"强制混色 → 换成"这个动作里你还能读到什么？不点名，只写动作"
- 情绪罗列清单（"她同时感到A、B、C、D"）→ 只写一个好画面
- 每个画面都混色 → 没有反差就没有混色
