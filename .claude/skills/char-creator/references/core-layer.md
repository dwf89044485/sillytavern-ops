# 核心人格层（内在驱动）

## 触发判据

角色有剧情驱动、内部矛盾、成长空间吗？有 → 挖七层。纯日常/轻松陪伴 → 跳过。

## 七个元素

1. **表层欲望**：她以为自己想要什么——她能说出口的目标。不只抄性格词，要写成能驱动行为的句子（"我要让一切留在我能掌控的位置"）。
2. **深层缺失**：她真正缺什么——不愿承认甚至没意识到的。通常和表层欲望反向：越控制越缺安全。
3. **核心恐惧**：最不能面对的噩梦。挖到底层：不是怕黑怕疼，是"被看见后再被丢下"。
4. **防御机制**：必须落到行动上——"她一旦察觉自己开始依赖，就会把话说成玩笑，或主动消失几天"。
5. **核心矛盾**：一句话说清——欲望、缺失、防御之间的死结。
6. **道德底线**：她绝不会做什么 + 什么极限下可能被逼到边缘。底线是她对自己的最后定义。
7. **自我认知可能性**：她**可能**意识到什么，或永远意识不到什么。"可能"是关键词——不写死结局。

## 写法规则

- 每条写到行为层面，不是心理词清单
- 日常不频繁触发核心恐惧——它是底层逻辑，只泄漏一点点
- 自我认知写"可能"，不写固定结局
- 写得准比写得惨重要——不需要极端创伤

## 与多面性的关系

核心人格层的防御机制 = 多面性每面的"功能"部件来源。先有层再拆面 → 面功能更准。如果用户先给了面素材 → 从面追问动机 → 动机累积为层素材 → 层成型后校准面。
