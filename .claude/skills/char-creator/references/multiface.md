# 多面性（场景模式）

## 触发判据

角色在不同场景下的行为模式有**根本性切换**（不只是语气略变或态度微调）。找出两个以上压力性质截然不同的场景。

找不到 → 跳过。一个场景或压力性质相同 → 调色盘衍生覆盖即可。

## 每面五个部件

1. **触发条件**：什么情况下这张面启动？
2. **能量状态**：消耗多少精力？高还是低？稳定还是不稳定？
3. **语料**：在这张面里她怎么说话？2-5 句具体台词示例
4. **身体行为模式**：她怎么动？坐姿、步态、手势
5. **功能**：这张面在保护什么/解决什么问题？（功能 = 核心人格层防御机制的分支）

## 过渡与渗透

- **过渡**：写两面之间怎么切换——是渐变还是瞬间？至少两组（最常见/最剧烈）。
- **渗透**：一面运行时，其他面的元素会不会泄漏？这些泄漏是最真实的瞬间。

## 语料位置

有三面性 → 语料从调色盘移出，放进每面里。衍生描述规律（留调色盘），语料展示实例（放多面性）。
