# 24 问急救模式题库

24 问模式使用这份题库，标签使用 `<Q24_01_IDX>` 到 `<Q24_24_IDX>`。

## 第一组：先把角色抓住

```
Q24_01：这个角色一句话是什么？
解释：抓住角色最核心的可识别性。

Q24_02：她最吸引人的地方是什么？
解释：不是问优点，而是问用户为什么会想一直看她。

Q24_03：她最不该被写成什么？
解释：防止AI误读。

Q24_04：这个角色的核心矛盾是什么？
解释：核心矛盾最好一句话能说完。
```

## 第二组：确定调色盘

```
Q24_05：她的底色是什么？
解释：底色是无论场景怎么变都隐隐存在的质地。

Q24_06：她的主色调是什么？
解释：主色调是最常驱动她行动的颜色。

Q24_07：她的点缀色是什么？
解释：点缀色负责反差和隐藏层。

Q24_08：哪两种颜色最容易撞在一起？
解释：这是混色的入口。
```

## 第三组：找到来源

```
Q24_09：她为什么会长成这样？
解释：找角色现在行为的来源。

Q24_10：她过去学会了什么错误规则？
解释：防御往往来自过去学会的错误规则。

Q24_11：这个背景现在会变成什么习惯？
解释：背景要长成现在的小动作。

Q24_12：哪些背景只是素材，不该变成全部解释？
解释：防止角色被背景吞掉。
```

## 第四组：欲望、缺失、恐惧

```
Q24_13：她以为自己想要什么？
解释：这是表层欲望。

Q24_14：她真正缺什么？
解释：这是深层缺失。

Q24_15：她最怕什么？
解释：问她最深层的噩梦，不是表层害怕。

Q24_16：她被触发后的第一反应是什么？
解释：第一反应最能看出防御机制。
```

## 第五组：关系与行为

```
Q24_17：{{user}}对她意味着什么？
解释：不要只写恋人、朋友、救赎，要写{{user}}碰到了她哪块人格结构。

Q24_18：她怎么靠近{{user}}？
解释：靠近不一定是直球，也可以是借口和试探。

Q24_19：她怎么推开{{user}}？
解释：推开要符合她的防御机制。

Q24_20：她怎么表达需求？
解释：表达需求最能暴露角色。
```

## 第六组：能不能被AI演出来

```
Q24_21：她常说什么？
解释：常用语要能召回角色。

Q24_22：她绝不会怎么说话？
解释：禁区比口癖更重要。

Q24_23：她在压力下会怎么做决定？
解释：检查角色有没有自己的决策逻辑。

Q24_24：AI最容易把她误读成什么？
解释：这是二次解释的入口。
```
