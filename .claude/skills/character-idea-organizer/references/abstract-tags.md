# 抽象词清单（标签化判定锚点）

用于判定用户答案是否"只有抽象标签"。
**命中清单中的词，且答案里没有具体行为描述 → 直接判"标签化"，必须追问一次具体行为。**

清单分两部分：
- **文档挖出来的种子词**：源文档明确标为"错误回答"或"抽象标签"的词
- **扩展词**：文档未列、但单独使用时同样属于抽象标签的常见词

## 三、判定规则

```
用户答案进来
  ↓
【第一步：清单硬匹配】
扫描答案是否命中上述清单中的词
  ├─ 命中，且答案里没有"她会……""她什么时候……""在 X 场景下……"等具体行为描述
  │     → 判"标签化"，必须追问一次具体行为
  ├─ 命中，但答案里有具体行为描述
  │     → 判"够用"
  └─ 没命中 → 进第二步
  ↓
【第二步：抽象判断方法】
用四条规则判断：
1. 能不能画出画面（能不能看到动作、场景、时间）
2. 能不能被演员演出来（不是只能被配音念出来的台词）
3. 删掉角色名是否成立（换成"任何一个 X 的人"答案是否还成立）
4. 是否只有情绪词（"她感到 X""她觉得 X""她很 X"）
  ├─ 满足任一"抽象"特征 → 判"标签化"
  └─ 都不满足 → 判"够用"
```

## 四、追问示例

用户回答："她很温柔。"

skill 追问（参考 `24-80-200工作流:93`）：

> 这里的温柔具体会表现成什么行为？
> 比如她会记住别人随口说的话，还是会过度照顾别人，还是会用温柔回避冲突？

用户回答："她害怕被抛弃。"

skill 追问（参考 `80问教程:122-123`）：

> 她害怕被抛弃时会怎么保护自己？
> 是会先推开对方、还是会过度讨好、还是会变得很黏？

如果用户仍答不出，记为"暂未确定"，不要替用户决定。
