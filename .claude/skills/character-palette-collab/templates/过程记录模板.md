# 过程记录模板

每轮交互结束时，把当前状态写入 `过程记录.md`。**散在上下文不适合，所有状态必须落盘。**

## 格式

```
# <角色名> 过程记录

## 会话信息
- 最近一次交互时间：<日期时间>
- 当前阶段：<入口探测 / 素材收集 / 动机追问 / 多框架推演 / 组装轮廓 / 补全档案 / 一致性验证>
- 下一步待做：<一句话说明下一步要做什么>

## 本轮记录（<日期时间>）
- 聊了什么：<一段话概述本轮讨论内容>
- 新素材：<本轮新增的素材，指向素材库.md 条目>
- 已闭环特征：<本轮用户明确认可的特征点>
- 待定项：<本轮讨论中、未闭环的候选>
- 否决记录：<用户否决了什么，为什么否决>

## 历史轮次
（按时间倒序，每轮一段）
```

## 规则

1. **每轮交互结束必写**，包括用户中途离开、只聊了一句的情况
2. 写完后告知用户"状态已保存，下次直接说'继续'就能续上"
3. 会话开始时，先读 `过程记录.md`，向用户确认上次的进度（"上次我们聊到 XX，要继续吗？"）
4. 如果角色从未被记录过，先创建目录再写

## 示例

```
# 秋明月 过程记录

## 会话信息
- 最近一次交互时间：2026-08-04 14:30
- 当前阶段：多框架推演
- 下一步待做：对"学校乖乖女/舞台上暴烈"的反差做推演候选，等用户勾选

## 本轮记录（2026-08-04 14:30）
- 聊了什么：用户给了"在家穿衣大胆"的切片，说不清为什么
- 新素材：素材库.md 条目 03（穿衣反差切片）
- 已闭环特征：底色"叛逆"（用户认可）
- 待定项：穿衣反差的 3 条推演候选（社会学习/依恋/认知图式）未勾选
- 否决记录：无

## 历史轮次
- 2026-08-04 13:00：入口探测，用户从"一个摇滚少女"画面进入，聊了舞台上的画面
```
