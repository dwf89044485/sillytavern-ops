# 推演候选模板

对作者无解的关键素材，AI 输出推演候选时**必须**按此格式。禁止出形容词，只许出行为场景。

## 格式

```
【素材】：<该素材的一句话概述>（来自：<素材库.md 条目编号>）

【推演候选】（2-3 条，每条结构差异最大）

候选一：
- 行为场景：<一段具体的行为描述，能直接当调色盘衍生用>
- 心理学机制：<依恋理论 / 防御机制 / 社会学习 / 认知图式 / 扩展池框架名>
- 推演依据：<从哪段经历推出来的，为什么合理>

候选二：
- 行为场景：<同上>
- 心理学机制：<同上>
- 推演依据：<同上>

候选三（可选）：
- 行为场景：<同上>
- 心理学机制：<同上>
- 推演依据：<同上>
```

## 示例（作者无解"为什么她在家穿衣大胆"）

【素材】：在外端庄、在家穿大胆衣服的行为反差（来自：素材库.md 条目 03）

【推演候选】

候选一：
- 行为场景：她在家会把衣服脱到只剩最少的布料，洗完澡裸着等湿气散干才穿睡衣。如果哪天家里会来外人，她会提前把所有大胆的衣服收进衣柜最深处，穿回宽松长袖，直到外人走了才拿出来。
- 心理学机制：社会学习（Goffman 前台/后台）
- 推演依据：反差源于"场合管理"——她把"家"定义为唯一不需要表演的后台。如果她从小在需要时刻注意形象的家庭/环境长大，家就是她唯一的后台。

候选二：
- 行为场景：她换上新买的露背裙会站在镜子前转一圈，但从来不会穿着出门。她会拍照发给自己最信任的那个人看，问"好看吗"，得到肯定后把裙子挂回衣柜，接下来几天心情都很好。
- 心理学机制：依恋理论（安全基地）
- 推演依据：大胆衣服不是穿给自己看的，是穿给"想被看见的人"看的。如果她成长中很少有"被完整看见"的经历，她会用这种方式试探"是否有人愿意接受完整的我"。

候选三：
- 行为场景：她在家穿衣大胆，但如果有人突然进门，她的第一反应不是换衣服，是愣住——像被发现了什么秘密。缓过来以后才笑着说"你怎么不敲门"。
- 心理学机制：认知图式（隐私与羞耻）
- 推演依据：如果她从小被要求"不该让别人看到真实的自己"，家是唯一能卸下这层规则的地方。被人撞见时，她怕的不是暴露身体，是暴露"原来我在家是这样的"。

## 规则

1. 候选之间必须有结构性差异（不同心理学机制/不同人格层），同义改写不算
2. 每条候选必须能从**已有的经历素材**里推出来，不能凭空编
3. 数量 2-3 条，不多不少
4. 行为场景要具体到能演——一个动作、一句话、一个习惯
