## 一、教程对红线的态度（原文引证）

1. **教程1**：「Ai一旦参与创作，也就是我前面分类的，第3类作品，在ai扮演中劣化最严重的！**绝不能让Ai代替你成为创作者！**」
2. **教程1**（半手写 vs 手写的核心区别）：「核心重点就在于'这是ai写的'。ai输出就意味它帮你把一些内容改成它资料库里认为'正确'的内容……把你的内容加上Ai缺点」
3. **教程7**（核心人格层，**最精确的红线表述**）：「这套东西不能靠AI直出。或者说，**AI可以帮你整理，但不能替你决定。**」
4. **教程6**（姜糖收尾）：「AI能帮你整理格式、优化措辞、查错别字。但AI想不出那个画面。那个画面只能从你的脑子里长出来。」
5. **教程1/4**（衍生与混色为什么不能 AI 直出）：「这是ai目前和未来一段时间做不到的、只有人类才能做的事：把毫无逻辑、毫无关联的两个性格组合在一起。」「只有你知道哪种蓝和哪种黄应该撞在同一笔里。」
6. **工作流24-80-200**（规则原文）：
   - 规则 4：「如果用户回答"不知道""跳过"，记录为"暂未确定"，**不要替用户决定**。」
   - 规则 12：「**不要把用户没说过的内容写成事实。**」
   - 定位声明：「它仍然不是让AI替用户写人设。它只做：提问。追问。记录。归纳。整合用户自己的创作思路。」
   - 禁止事项：「不能替用户决定未知设定」「不能把"可能"改成"确定"」「不能把"用户没想好"包装成高级设定」。
7. **手写整理**：「不要放弃自己的追求……核心的部分一定要是自己的，不要被 AI 带偏。」

**教程的红线总结：AI 可以提问/追问/记录/归纳/整合（用户自己的思路），不可以替用户决定、不可以把推论写成事实。**
「归纳整合」在允许清单里——AI 可以帮用户整理他自己说出来的东西，这是教程与"纯追问"解读的关键区别。

## 二、晴空妈妈救援实录（教程里"用户卡住"的真实处理）

### 实录 1：找意象（大总7）——最完整的卡住救援

柚子连续 5 次给不出意象（影子/灰尘→蚂蚁→墙角的草→苔藓→石缝里的小花），晴空的完整处理链：

1. **否定带理由**：柚子说"影子？灰尘？"→ 晴空：「太消极了。记住，她的底色是'不甘心'。她在活着。她在努力。」——否定 + 引用已确认素材。
2. **半句脚手架**：晴空：「她安静，她在角落里，她一个人，她很慢，她一直在……」→ 柚子接「在长？」→「对了。」——**特征全来自已确认素材，留空让用户填**。
3. **窄化追问**：柚子"墙角的草" → 晴空：「但那个太泛了。什么草？长什么样？有什么特别的？想更具体一点。」
4. **素材回链**：柚子"苔藓"（错）→ 晴空不评价，摆素材：「你想想她的红线手绳。她妈妈给她编的。褪了色。还戴着。想想她的草稿纸。正面写完翻过来写背面。想想她的校服……她的世界里所有的东西都是旧的、小的、被反复使用的……什么东西有这种质感？」——**在用户素材里找答案**。
5. **把答案藏在提示里**：柚子还是卡 → 晴空：「妈妈给你一个方向。……她的快乐很小很小。一道做对的题。妈妈把碗里的饭吃完了。**一片晒到她脸上的阳光。**她像什么？」→ 柚子：「冬天窗台上那一小格阳光？」→ 晴空不说对错，直接：「**你来展开试试看。**」——**说出答案的最后一步留给用户；用"展开"代替"确认"，候选瞬间变成用户的**。
6. 柚子展开后：晴空：「这很好。你找到了她的核心状态：窄、小、有限、但在里面是暖的。等待。现在试着把她和{{user}}的关系也放进去。」——确认 + 命名总结 + 下一个任务。
7. 最终：「你刚才写的东西，妈妈一个字都不想改。」

### 实录 2：底色提取（大总2）

- 柚子：「嗯……'极度自卑'？」→ 晴空：「先去掉'极度'。……陈乖乖真的是'极度自卑'吗？**一个极度自卑的人，能做到年级成绩前列吗？**一个极度自卑的人，能在走投无路时鼓起勇气给别人打电话求助吗？」——**矛盾对撞：拿用户自己的两句话互相打，让用户自己修正**。
- 柚子：「她觉得自己不够好？但又一直在努力？」→ 晴空：「你刚才说了两样东西……那她的底色就可以是：**不甘心**。」——**在用户素材上命名，不是凭空生成**。
- 主色调：柚子"安静和乖"→ 晴空：「太表面了。我们往里走一层。她为什么安静？为什么乖？」→ 柚子"不想添麻烦"→ 晴空：「**再想想。**一个'不甘心'的人选择表现得很乖，这背后只有'不想添麻烦'吗？」→ 柚子答出"安静是最安全的"→ 晴空命名：「把'乖'当盔甲」。——**"往里走一层"+"再想想"+把用户已有素材（不甘心）嵌进追问**。

### 实录 3：核心恐惧挖掘（大总5）——纯追问链（教科书级"只追问不填空"）

6 轮追问，晴空全程不替答：

> 柚子：她最怕妈妈死？
> 晴空：**这是表面。**妈妈死了以后她怕什么？
> 柚子：她怕……一个人？
> 晴空：**再往下。**
> 柚子：她怕……如果妈妈不在了，世界上就真的没有任何一个人需要她了？
> 晴空：**对。但还可以更准确。**想一想她为什么总是不接受别人的帮助。她为什么把陆昂的牛奶推开。……她怕的核心是什么？
> 柚子：她怕……欠别人？
> 晴空：**为什么怕欠别人？**
> 柚子：因为……欠了就要还。她还不起，就会成为别人的……负担？
> 晴空：**对了。**

要点：每轮先接住（"这是表面""再往下""对，但还可以更准确"），再给方向提示，**方向提示全部引用用户已有素材**（"想一想她为什么总是不接受别人的帮助"），最后命名总结。

### 实录 4：质量不够时的处理（大总5 表层欲望 / 大总2 衍生）

- 柚子：「她想要钱！想给妈妈治病！」→ 晴空：「**对，但不够。**'想给妈妈治病'是一个目标。表层欲望要写得更像一种驱动行为的信念。她真正以为自己想要的东西，用一句话说是什么？」→ 柚子自己改出：「只要妈妈能活着，其他的都不重要？」→「这就对了。」——**肯定 + 说清缺什么标准 + 让用户自己升级**。
- 柚子写了三条空泛衍生（"她努力学习成绩好"）→ 晴空逐条挑毛病（"太概括了""这是你的总结""是一句鸡汤"）→ **示范一条**（"算题时的较劲"，全基于已确认的"不甘心"）→ 柚子说"这个画面我能看到"。——教学场景的"AI 示范"，skill 需弱化（见 _AI_READ_THIS_FIRST 的翻译层说明）。

### 实录 5：让用户列误读方向（大总6）

晴空问"想想AI最容易把陈乖乖写成什么样子"→ 柚子列出 5 条（可怜虫/社恐极端/傲娇/暗恋少女/热血坚强）→ 晴空：「非常好。每一条都是AI可能跑偏的方向。现在我们针对这些写防护。」——**防误读方向的生成也让用户做**。

## 三、工作流的卡住规则（明确写下来的规则）

1. **标签回答 → 必须追问一次具体行为**（规则 3，硬规则）。工作流自带追问示例就是**三选一**：
   > 「这里的温柔具体会表现成什么行为？**比如她会记住别人随口说的话，还是会过度照顾别人，还是会用温柔回避冲突？**」
2. **"不知道/跳过" → 记录"暂未确定"，不替用户决定**（规则 4）。追问一次后仍不知道 → 再记录为暂未确定。**教程的耐心上限是 1-2 轮，不是 3 轮。**
3. **标签下钻四连问**（24 问）：它具体会做什么？它什么时候出现？它为什么会出现？它会不会伤到别人？
4. **标签下钻五连问**（80 问）：她具体做什么？她什么时候这么做？她为什么不直接说？她这么做会伤到谁？她什么时候会停下？
5. **三遍法**（80 问使用方式，救援设计）：第一遍只回答能立刻想到的 → 第二遍把抽象词改成具体行为 → 第三遍检查有没有打架。**第一遍明确降门槛**。
6. **大量"不知道" → 收缩**（24 问）：「如果24问里有大量不知道，不要急着扩写。先补这三块：她的底色是什么？她真正缺什么？她被触发后会做什么？」
7. **24 问都答不出 → 诊断**（24 问）：「如果用户连24问都答不出来，就不要急着让她写调色盘……因为那时候的问题不是写法不够高级，**而是角色还没有在作者脑子里站起来。**」
8. **卡住抽题**（200 问）：某一块卡住时抽对应块的题；「如果用户一上来就被要求回答200问，大概率会从创作变成考试」。
9. **三栏回答格式**（24/80/200 问通用）：我的直觉答案 / 具体行为 / 还没想明白——给用户的结构脚手架。
10. **回答标准**（80 问）：「不要只写'她害怕被抛弃'，要写'她害怕被抛弃时会怎么保护自己'。」
11. **三类区分**（工作流规则 11）：最终总结必须区分用户已确定 / AI 高可能推论 / 仍待用户决定；只能叫"创作思路整合"不能叫"最终人设"。
12. **止损**（手写整理）：「**没必要说什么答什么，也没必要一直问下去。**AIRP 不是和苏格拉底对话，聊的差不多……就开始你的聊天了。」

## 五、教程能给出的答案（对应 handoff 六个产出要求）

### 1. 红线边界：教程 7 原话 + 行为判据

**表述**：「AI 可以帮你整理，但不能替你决定。」（教程7 原文）

**从晴空行为提炼的判定标准**：AI 说出的任何内容，素材源是否全部来自用户已经给出的东西？
- 是 → 允许：命名（不甘心）、归纳、整合、示范，全部基于用户刚说过的素材。
- 否 → 越线：凭空生成设定、把 AI 推论写成事实。

晴空命名"不甘心"之前柚子已经说了"觉得自己不够好+一直在努力"；晴空提示"阳光"之前已经把柚子的素材罗列了一遍。**晴空从来不在空白处创作，只在素材上加工。** 这和 handoff 候选 A"确认权"兼容但更硬——不只是"用户点头才算数"，而是"AI 给的必须长在用户的素材上"。

### 2. 救援机制：教程实际执行的六级链

```
第 0 级  接住再问     "这是表面。妈妈死了以后她怕什么？""再往下。"
第 1 级  矛盾对撞     用用户自己的两句话对撞（极度自卑 vs 成绩年级前列）
第 2 级  枚举候选      "是 A 那种，还是 B 那种，还是 C 那种？"（工作流自带）
第 3 级  半句脚手架   特征罗列（全来自已确认素材）+ 留空
第 4 级  素材回链     把已确认素材摆出来，让用户在素材里找答案
第 5 级  藏答案提示   提示里几乎包含答案，但说出答案的最后一步留给用户；
                      用户说出后用"你来展开"交还所有权
```

配套规则：
- 标签回答 → 必追一次具体行为（硬规则）
- 追问一次仍不知道 → 记录"暂未确定"，不替用户决定，继续往下
- 大量不知道 → 收缩到三块核心（底色/缺失/触发后反应）
- 角色还没立起来 → 不急着写进阶内容（问题不是写法，是角色没站起来）
- 质量不够 → "对，但不够"+ 说清缺什么标准 + 让用户自己升级

### 3. 升档触发（可判断信号）

- 回答是标签/万能词 → 下钻四连问（必须）
- 回答是总结/鸡汤/结论 → "这是你的总结"→ 要画面
- 回答与已有素材矛盾 → 矛盾对撞
- 回答"不知道" → 暂未确定（1-2 轮即停，教程没有 3 轮耐心）
- 连续答不出同一件事 → 逐级上脚手架（实录 1 的六级链就是）

### 4. 话术示例

实录 1-4 全部原话可用（见上），全部自然口语、零术语。

### 5. 止损规则

- 追问一次无果 → 记录"暂未确定"，不替用户决定，继续往下（工作流规则 4）
- 大量不知道 → 收缩到三块核心（24 问）
- 24 问都答不出 → 角色没立起来，先抓轮廓，不写进阶（24 问）
- "没必要一直问下去"（手写整理）
- 用户说"总结"就总结（工作流用户指令）

### 6. 红线档的提示方式：教程不提示，把所有权嵌进动作里

教程没有"以下选项由 AI 提供"这种声明。所有权靠三个动作保证：
1. **说出答案的最后一步永远是用户的**（"她像什么？"让用户说）
2. **用户说出后用"你来展开"交还**——展开的过程就是把候选变成自己的过程
3. **多选形态自带裁决动作**（"你的角色是哪种？"）

## 六、教程没回答、留给我们讨论的

1. 教程的"采访/小传"是正式创作方法（用户有能力），handoff 的场景是"用户卡住了"（用户没能力）——**同样的手段（假设场景）在卡住场景下的形态要不要改？**
2. 教程的晴空模式大量代劳（示范衍生），已被 _AI_READ_THIS_FIRST 判定为教学成分不融入。**但"示范一条+交还"的边界在 skill 里怎么执行？**
3. 教程的止损（追问一次→暂未确定）非常果断，handoff 三套方案都更粘（连续 2-3 轮）。**skill 采用教程的果断版还是折中？**
4. 教程没有"用户敷衍"（随便吧/都行）的处理——晴空的柚子从不敷衍。**敷衍通道要我们自己设计。**
