# 4 个基础诊断的精确判断标准

> 本文档为 SKILL.md 中 4 个基础诊断提供精确到可执行的判断规则。
> 设计原则：同一段用户输入，AI 10 次判断应得到 10 次一样的结果。

---

## 一、晴空妈妈的判断方法提炼

在写具体规则之前，先提炼教程原文中晴空妈妈的判断逻辑，这些逻辑是所有诊断规则的底层依据。

### 方法 1：遮名测试

> "如果你把这句话遮住名字，换成别的角色名字，这些形容词还能成立吗？"

**提炼为规则**：一段描写如果遮住角色名后，放在同类型（同性别、同年龄段、同身份）的任意角色身上都成立 → 触发泛化。

### 方法 2：默认值检测

> "17岁中国女高中生，AI的数据库里默认就是年轻的、皮肤还可以的、头发是黑色的。你不需要重复这些默认值。你只需要写偏离默认的地方。"

**提炼为规则**：用户写的特征如果是该类型角色的"默认配置"（中国女高中生→黑发黑眼、年轻皮肤），没有偏离 → 触发泛化。

### 方法 3：行为可行性检验

> "一个极度自卑的人，能做到年级成绩前列吗？一个极度自卑的人，能在走投无路时鼓起勇气给别人打电话求助吗？"

**提炼为规则**：用户给的标签 A 和标签 B 如果放在同一个人身上，在现实中会导致行为矛盾（A 的典型行为会阻止 B 的典型行为发生） → 触发矛盾。

### 方法 4：行为 vs 标签分离

> "你告诉AI'她极度自卑'，AI就会用它数据库里最刻板的方式来演绎'极度自卑'"

**提炼为规则**：用户给的标签是"AI 数据库里的通用模板"而非"这个角色独有的行为模式" → 触发泛化。

### 方法 5：画面可拍摄性检验

> "你让AI自己看见'她用书本把零食推到桌角'，AI就能自己感受到她的回避。你不需要替AI下结论。"

**提炼为规则**：一段描写如果无法被摄像机拍到（没有物理动作、没有空间位置、没有可观察的感官事实） → 触发结论检测。

## 二、泛化检测（Generalization Detection）

### 2.1 核心判断逻辑

**遮名测试 + 默认值检测**：用户给的描写如果遮住角色名后，放在同类型角色身上也成立，或者只是 AI 数据库的默认值 → 触发。

### 2.2 精确判断规则

#### 规则 A：纯形容词检测（明确触发）

用户给出的描述**只包含抽象形容词**，没有具体行为、场景或画面。

**判断公式**：如果一段描述中，所有信息都可以被归类为"性格形容词"或"外貌形容词"，且没有任何一个词指向具体可观察的行为或特征 → 触发。

**正例（触发）**：
- "她很温柔" → 纯形容词，无行为
- "她是一个善良的人" → 纯形容词
- "她五官精致秀气，是美人胚子" → 形容词堆砌，遮名后任何好看角色都成立
- "她性格很好，很坚强" → 纯形容词
- "她气质优雅" → 不可观察的抽象判断

**反例（不触发）**：
- "她会默默把杯子续上水" → 具体行为，可观察
- "她算题时会在草稿纸正反面反复算" → 具体场景+行为
- "高一时确诊慢性肾衰竭，每周透析2到3次" → 具体事实
- "手上有冻疮愈合后的暗红色痕迹" → 具体特征

#### 规则 B：形容词+轻微行为（灰色地带 → 弱触发）

用户给出了形容词 + 一个模糊的行为倾向，但行为没有具体场景。

**判断公式**：如果一段描述包含 1 个抽象形容词 + 1 个行为动词，但该行为动词没有"时间、地点、具体动作"中的至少 2 个 → 弱触发（标记为"可能泛化"，AI 可以追问但语气更温和）。

**处理方式**：标记为"弱泛化"，AI 追问时用"能给我一个具体的画面吗？"而非"这太泛了"。

**正例（弱触发）**：
- "她温柔，会照顾人" → "照顾人"是行为动词但没有具体场景 → 弱触发
- "她是那种会记住别人说过的话的人" → 有行为倾向（记住话）但没有具体场景 → 弱触发
- "她不善言辞但很细心" → 两个形容词 → 弱触发（比纯形容词稍好但不够）

**反例（不触发）**：
- "老师表扬她成绩进步时，她的耳朵会发烫，低头小声说谢谢老师" → 完整场景+行为
- "她知道班里谁和谁关系好，谁的笔没墨了，会悄悄把备用笔放在别人桌角" → 具体行为+场景

#### 规则 C：默认值检测（明确触发）

用户写的特征是该类型角色的"出厂设置"。

**判断公式**：如果用户写的特征满足以下条件之一 → 触发：
1. 外貌特征与 AI 数据库默认值完全一致（中国女高中生→黑发、黑眼、年轻皮肤）
2. 性格特征是该身份/年龄段的常见模板（穷人家的孩子→懂事、努力）
3. 描写使用了文学比喻（"像清泉一样的眼睛""像小草一样"）

**正例（触发）**：
- "她有一头乌黑亮丽的长发" → 中国女生的默认值
- "她皮肤白皙" → 17岁女生的默认值（除非特别到有辨识度）
- "她像一朵出淤泥而不染的莲花" → 文学比喻，AI 只会模仿写法
- "她是一个典型的乖乖女" → 标签化模板

**反例（不触发）**：
- "刘海是自己剪的，有些参差" → 偏离默认值的具体特征
- "手指关节有冻疮愈合后的暗红色痕迹" → 偏离默认值的具体特征
- "校服洗到发白，袖口有缝补痕迹" → 偏离默认值的具体特征

#### 规则 D：混合段落（分段处理）

用户在一个段落里同时包含抽象形容词和具体描写。

**判断公式**：将段落拆分为"形容词部分"和"具体行为部分"。如果形容词部分占段落总信息量的 50% 以上 → 触发。如果具体行为部分占 50% 以上 → 不触发。

**示例分析**：
> "她很温柔，会在朋友难过的时候默默陪着，轻轻拍对方的背。"

- 形容词："温柔"（1个抽象词）
- 具体行为："朋友难过时默默陪着""轻轻拍背"（2个具体行为信息点）
- 具体行为占主导 → 不触发

> "她是一个善良又坚强的女孩，虽然生活很苦但她从不抱怨。她每天都会早起给妈妈做饭。"

- 形容词："善良""坚强""从不抱怨"（3个抽象信息点）
- 具体行为："早起给妈妈做饭"（1个具体行为）
- 形容词占主导 → 触发

### 2.3 判断流程图

```
用户输入
  │
  ├─ 是否包含至少 1 个具体可观察的行为/特征？
  │   （行为有：时间/地点/动作中的至少 2 个）
  │   │
  │   ├─ 否 → 触发泛化（规则 A / 规则 C）
  │   │
  │   └─ 是 → 继续检查
  │           │
  │           ├─ 具体行为信息量 ≥ 抽象形容词信息量？
  │           │   │
  │           │   ├─ 是 → 不触发
  │           │   │
  │           │   └─ 否 → 弱触发（规则 B）
  │           │
  │           └─ 行为是否有具体场景（时间/地点/触发条件）？
  │               │
  │               ├─ 有完整场景 → 不触发
  │               │
  │               └─ 只有行为动词无场景 → 弱触发
  │
  └─ 是否包含文学比喻？
      │
      ├─ 是 → 触发泛化（规则 C-3）
      │
      └─ 否 → 按上述规则继续
```

### 2.4 正例与反例汇总

**应该触发（6个）**：
1. "她很温柔" → 纯形容词
2. "她五官精致秀气，气质优雅" → 遮名测试不通过
3. "她像一朵清莲" → 文学比喻
4. "她有一头乌黑亮丽的长发" → 默认值
5. "她是一个善良坚强又独立的女孩" → 形容词堆砌
6. "她特别可怜，特别善良，特别自卑" → 三个"特别"+形容词

**弱触发（3个）**：
1. "她温柔，会照顾人" → 有行为动词但无场景
2. "她是那种会记住别人说过的话的人" → 有行为倾向但无场景
3. "她不善言辞但很细心" → 两个形容词，比纯标签稍具体

**不应该触发（6个）**：
1. "她会默默把杯子续上水" → 具体行为
2. "数学遇到不会的题，她会在草稿纸上一遍一遍地算" → 完整场景+行为
3. "陆昂把东西放她桌上，她会用书本推到桌角" → 完整场景+行为
4. "手指关节有冻疮愈合后的暗红色痕迹" → 具体特征
5. "刘海自己剪的，有些参差" → 偏离默认值的特征
6. "她知道家里所有的数字，妈妈每次透析多少钱" → 具体行为倾向+可观察事实

## 三、矛盾检测（Contradiction Detection）

### 3.1 核心判断逻辑

**行为可行性检验**：用户给的两个标签/描述放在同一个人身上，在现实中是否会导致行为矛盾？即：标签 A 的典型行为模式是否会阻止标签 B 的典型行为模式发生？

### 3.2 精确判断规则

#### 规则 A：行为级矛盾（明确触发）

两个标签之间存在**行为层面的直接冲突**——如果一个人真的符合标签 A 的典型行为模式，她就无法做到标签 B 所描述的事。

**判断公式**：将每个标签转化为"这个标签在现实中的典型行为模式"，然后检查两个行为模式是否互斥。

**正例（触发）**：
- "极度自卑" + "成绩年级前列" → 极度自卑的典型行为（自我否定、放弃努力、不敢竞争）与"成绩前列"需要的行为（持续努力、相信自己能行、主动学习）互斥
- "从不求人" + "最后向人借钱" → "从不求人"的典型行为（拒绝一切帮助）与"向人借钱"（主动求助）直接矛盾
- "社恐" + "当众演讲" → 社恐的典型行为（回避社交场合）与当众演讲（主动暴露在众人面前）互斥
- "完全不会拒绝别人" + "拒绝了所有人的帮助" → 行为直接矛盾

**反例（不触发）**：
- "温柔" + "有时候会发脾气" → 温柔的人也会发脾气，这不矛盾，这是正常人类
- "内向" + "在熟人面前话多" → 内向和选择性话多不矛盾
- "善良" + "会骂人" → 善良的人也可以骂人，骂人不等于不善良
- "安静" + "观察力强" → 安静和观察力强是互补而非矛盾

#### 规则 B：程度级矛盾（明确触发）

两个标签之间存在**程度上的不可调和**——标签 A 的极端程度与标签 B 的存在本身冲突。

**判断公式**：如果标签 A 前面有"极度""极致""完全""从来"等绝对化修饰词，而标签 B 描述的行为与 A 的极端版本不兼容 → 触发。

**正例（触发）**：
- "极度自卑" + "成绩年级前列" → "极度"让矛盾从"可能共存"变成"不可能共存"
- "从来不发火" + "把同学骂哭了" → "从来"和具体行为矛盾
- "完全不在乎别人看法" + "会因为别人一句话难过好几天" → "完全"和具体行为矛盾

**注意**：如果去掉"极度""从来"等修饰词后矛盾消失，则触发原因是"用户用了过度修饰词"，AI 追问方向应该是"这个程度词是否准确？"

#### 规则 C：正常人类矛盾（不触发）

两个标签描述的是**正常人类都会有的复杂性**，不构成需要追问的矛盾。

**判断公式**：如果两个标签在现实中可以同时存在于同一个人身上，且不需要特殊解释 → 不触发。

**正例（不触发）**：
- "温柔" + "有时候会发脾气" → 正常人类
- "很独立" + "每天都要打电话给男朋友" → 独立的人也可以有依赖需求，不矛盾
- "内向" + "在舞台上很疯" → 内向是社交能量来源方式，舞台是表演状态，不矛盾
- "善良" + "会骂人" → 骂人不等于不善良
- "坚强" + "会哭" → 坚强的人也会哭
- "理性" + "偶尔冲动消费" → 正常人类

#### 规则 D：灰色地带（弱触发 → 需要追问但语气温和）

两个标签在**某些文化/语境下可能矛盾，但在另一些语境下不矛盾**。AI 需要判断语境。

**判断公式**：如果两个标签的共存需要"一个合理的解释"但不需要"特殊解释" → 弱触发。

**处理方式**：标记为"弱矛盾"，AI 追问时用"这两面在她身上是怎么共存的？"而非"你写的矛盾了"。

**正例（弱触发）**：
- "很独立" + "每天都要打电话给男朋友" → 独立和依赖可以共存，但"每天都要打"暗示了依赖程度，需要了解这个依赖的"功能"是什么 → 弱触发
- "内向" + "在舞台上很疯" → 内向和舞台表现可以共存（很多演员内向），但需要了解"舞台"对她来说是什么（是表演状态还是真实自我？） → 弱触发
- "善良" + "会骂人" → 善良和骂人可以共存，但需要了解"骂人"的场景和对象 → 弱触发

**反例（不触发）**：
- "很独立" + "偶尔需要帮助" → 独立和偶尔求助完全不矛盾
- "内向" + "在朋友面前话多" → 典型的正常人类

### 3.3 判断流程图

```
用户输入
  │
  ├─ 是否包含"极度""从来""完全"等绝对化修饰词？
  │   │
  │   ├─ 是 → 检查修饰词后的标签与另一标签是否行为互斥
  │   │       │
  │   │       ├─ 是 → 触发矛盾（规则 B）
  │   │       │
  │   │       └─ 否 → 去掉修饰词后按规则 A/C 继续
  │   │
  │   └─ 否 → 继续
  │
  ├─ 两个标签的典型行为模式是否互斥？
  │   │
  │   ├─ 是 → 触发矛盾（规则 A）
  │   │
  │   └─ 否 → 继续
  │
  ├─ 两个标签是否需要"一个合理的解释"才能共存？
  │   │
  │   ├─ 是 → 弱触发（规则 D）
  │   │
  │   └─ 否 → 不触发（规则 C，正常人类矛盾）
  │
  └─ 关键区分：需要"特殊解释" vs 需要"合理解释"
      - 特殊解释 = "她不是正常人"级别的解释 → 触发
      - 合理解释 = "她在这个场景下这样" → 弱触发
      - 不需要解释 = 正常人类 → 不触发
```

### 3.4 正例与反例汇总

**应该触发（6个）**：
1. "极度自卑" + "成绩年级前列" → 行为级矛盾
2. "从不求人" + "向人借钱" → 行为级矛盾
3. "社恐" + "当众演讲" → 行为级矛盾
4. "完全不在乎别人看法" + "因别人一句话难过好几天" → 程度级矛盾
5. "从来不发火" + "把同学骂哭了" → 程度级矛盾
6. "完全不会拒绝" + "拒绝了所有人的帮助" → 行为级矛盾

**弱触发（3个）**：
1. "很独立" + "每天都要打电话给男朋友" → 需要合理解释
2. "内向" + "在舞台上很疯" → 需要合理解释
3. "善良" + "会骂人" → 需要合理解释

**不应该触发（6个）**：
1. "温柔" + "有时候会发脾气" → 正常人类矛盾
2. "内向" + "在熟人面前话多" → 正常人类
3. "坚强" + "会哭" → 正常人类
4. "理性" + "偶尔冲动" → 正常人类
5. "独立" + "偶尔需要帮助" → 正常人类
6. "善良" + "对坏人很凶" → 正常人类

## 四、结论检测（Conclusion Detection）

### 4.1 核心判断逻辑

**画面可拍摄性检验**：一段描写如果无法被摄像机拍到（没有物理动作、没有空间位置、没有可观察的感官事实），就是结论。

### 4.2 精确判断规则

#### 规则 A：纯心理/情感结论（明确触发）

用户给出的是角色的**内心状态、情感判断、心理分析**，而不是可观察的行为。

**判断公式**：如果一段描述回答的是"她感觉怎么样"或"她是什么样的人"，而不是"她做了什么" → 触发。

**正例（触发）**：
- "她对他充满恐惧" → 内心状态，不可拍摄
- "她内心很矛盾，既渴望被爱又害怕被伤害" → 心理分析，不可拍摄
- "这是她性格转变的起点" → 作者的总结/分析，不可拍摄
- "她对这个世界充满了不信任" → 内心状态
- "她本质上是一个善良的人" → 对角色本质的判断

**反例（不触发）**：
- "他把东西放她桌上，她用书本推到桌角" → 两个物理动作，可拍摄
- "她低着头，手指在校服口袋里攥了一下" → 身体动作，可拍摄
- "她的耳朵会发烫，低头小声说谢谢老师" → 身体反应+动作，可拍摄
- "她蹲在那里看流浪猫吃完，然后站起来继续走" → 完整动作序列，可拍摄

#### 规则 B：行为动词但无画面（灰色地带 → 弱触发）

用户使用了**行为动词**，但该行为没有具体的场景、动作细节或可观察的物理表现。

**判断公式**：如果一段描述包含行为动词，但该行为无法被"看到"（没有时间、地点、身体动作、空间关系中的至少 2 个） → 弱触发。

**处理方式**：标记为"弱结论"，AI 追问时用"那个时刻具体发生了什么？"而非"这是结论不是画面"。

**正例（弱触发）**：
- "她会回避和他的接触" → "回避"是行为动词，但没有具体画面（怎么回避？什么场景？身体做了什么？）
- "她不喜欢被人关注" → "不喜欢"是内心状态，"被关注"没有具体场景
- "她害怕失去妈妈所以很努力赚钱" → 前半句是结论（害怕），后半句是行为（努力赚钱），混合状态

**反例（不触发）**：
- "陆昂把零食放她桌上时，她会等，等到他不注意了才用课本把东西推到桌角" → 完整画面：时间（陆昂放零食时）、动作（等→推）、空间关系（桌角）
- "她进门第一件事是看妈妈的脸色，然后换衣服，做饭" → 完整动作序列

#### 规则 C：混合段落（分段处理）

用户在一个段落里同时包含结论和画面。

**判断公式**：将段落拆分为"结论部分"和"画面部分"。如果结论部分占主导 → 触发。如果画面部分占主导 → 不触发。如果各占一半 → 弱触发，AI 追问画面部分。

**示例分析**：
> "她害怕失去妈妈，所以每天放学后都会尽快回家，帮妈妈做饭、照顾起居。"

- 结论："害怕失去妈妈"（内心状态，不可拍摄）
- 画面："每天放学后尽快回家""帮妈妈做饭""照顾起居"（可拍摄的行为）
- 画面占主导 → 不触发，但 AI 可以追问"害怕"的具体表现

> "她对他充满恐惧。每次他靠近的时候，她都会把目光移开，手指不自觉地攥紧。"

- 结论："充满恐惧"（内心状态）
- 画面："目光移开""手指攥紧"（可拍摄的身体动作）
- 各占一半 → 弱触发，AI 可以追问"恐惧"时刻的更多画面细节

#### 规则 D：AI 总结/分析（明确触发）

用户替 AI 做了因果分析或性格总结。

**判断公式**：如果一段描述包含"因为…所以…""这说明…""本质上…""这意味着…"等因果/总结性表达 → 触发。

**正例（触发）**：
- "这是她性格转变的起点" → 替 AI 总结因果
- "这说明她的安静不是天生的，而是后天形成的" → 替 AI 分析
- "她本质上是一个缺乏安全感的人" → 对角色本质下结论

**反例（不触发）**：
- "10岁时父亲因意外去世，母亲独自带她来大城市打工" → 只摆事实，不总结
- "她不说'我家很穷'，她说'周三去东边那个市场，白菜比西边便宜两毛'" → 只摆行为，不分析

### 4.3 判断流程图

```
用户输入
  │
  ├─ 是否包含"因为这说明""本质上""这意味着"等总结性表达？
  │   │
  │   ├─ 是 → 触发结论（规则 D）
  │   │
  │   └─ 否 → 继续
  │
  ├─ 描述是否可以被摄像机拍到？
  │   （有物理动作/空间位置/身体反应/感官事实中的至少 2 个）
  │   │
  │   ├─ 完全不可拍摄 → 触发结论（规则 A）
  │   │
  │   ├─ 部分可拍摄 → 继续
  │   │
  │   └─ 完全可拍摄 → 不触发
  │
  ├─ 行为动词是否有具体画面？
  │   （时间/地点/身体动作/空间关系中的至少 2 个）
  │   │
  │   ├─ 有行为动词但无画面 → 弱触发（规则 B）
  │   │
  │   └─ 有行为动词且有画面 → 不触发
  │
  └─ 混合段落：结论 vs 画面的信息量比例
      │
      ├─ 结论占 > 50% → 触发
      │
      ├─ 结论占 ≈ 50% → 弱触发
      │
      └─ 结论占 < 50% → 不触发
```

### 4.4 正例与反例汇总

**应该触发（6个）**：
1. "她对他充满恐惧" → 纯内心状态
2. "这是她性格转变的起点" → 替AI总结因果
3. "她内心很矛盾，既渴望被爱又害怕被伤害" → 心理分析
4. "她本质上是一个缺乏安全感的人" → 对本质下结论
5. "她对这个世界充满了不信任" → 内心状态
6. "这说明她的安静不是天生的" → 总结性分析

**弱触发（3个）**：
1. "她会回避和他的接触" → 有行为动词但无画面
2. "她不喜欢被人关注" → 内心状态+无场景
3. "她害怕失去妈妈所以很努力赚钱" → 结论+行为混合

**不应该触发（6个）**：
1. "他把东西放她桌上，她用书本推到桌角" → 完整画面
2. "她低着头，手指在校服口袋里攥了一下" → 身体动作
3. "她蹲在那里看流浪猫吃完，然后站起来继续走" → 动作序列
4. "她进门第一件事是看妈妈的脸色，然后换衣服，做饭" → 动作序列
5. "老师表扬她时，她的耳朵会发烫，低头小声说谢谢" → 身体反应+动作
6. "10岁时父亲因意外去世，母亲独自带她来大城市打工" → 事实陈述

## 五、扁平检测（Flatness Detection）

### 5.1 核心判断逻辑

**正负平衡检验**：角色的特质是否全部集中在正面/单一维度，缺乏反面、矛盾或反差。

### 5.2 精确判断规则

#### 规则 A：正负比例检测（明确触发）

用户给出的特质中，正面特质数量远超负面特质数量。

**判断公式**：
1. 统计用户给出的所有**明确特质**（形容词、标签、行为描述都可以算）
2. 将每个特质标记为"正面"或"负面"或"中性"
3. 如果正面特质数 ≥ 负面特质数 + 3 → 触发
4. 如果正面特质数 ≥ 4 且负面特质数为 0 → 触发
5. 如果正面特质数 ≥ 5 且负面特质数 ≤ 1 → 触发

**特质分类标准**：
- **正面特质**：社会普遍认为好的品质（温柔、善良、坚强、聪明、独立、勇敢、懂事、体贴、大方、乐观、勤奋、有才华、漂亮、优雅）
- **负面特质**：社会普遍认为不好的品质（自私、冷漠、暴躁、懦弱、虚荣、刻薄、懒惰、嫉妒、虚伪、固执、冲动、粗心、小气）
- **中性特质**：本身不带有明显正负评价（安静、内向、话多、爱笑、喜欢独处、喜欢热闹、理性、感性、慢热、直接）

**正例（触发）**：
- "温柔、善良、坚强、独立、懂事"（5正0负）→ 触发
- "她很完美，唯一的缺点是太努力了"（名义上有1负，但"太努力"是变相优点）→ 按"0负"处理 → 触发
- "她善良、温柔、体贴、大方、聪明、勤奋、漂亮"（7正0负）→ 触发
- "她什么都好，就是太善良了容易被人欺负"（"什么都好"=全正，"太善良"是变相优点）→ 触发

**反例（不触发）**：
- "温柔、善良、坚强，但有点倔"（3正1负）→ 不触发
- "温柔、善良、坚强、独立，但有点倔"（4正1负）→ 不触发（4正1负，差距为3，但负面是真实负面）
- "安静、善良、有点小脾气"（1正1负1中性）→ 不触发
- "聪明但懒惰"（1正1负）→ 不触发
- "温柔、善良、坚强、独立、敏感、倔强"（4正2中性）→ 不触发

#### 规则 B：虚假负面检测（明确触发）

用户名义上给了负面特质，但该负面特质实际上是变相的优点。

**判断公式**：如果用户给出的"负面特质"满足以下任一条件 → 视为虚假负面，按 0 负处理：
1. 该特质在语境中明显是褒义（"太努力了""太善良了""太为别人着想了"）
2. 该特质是"优点过头了一点点"而非真正的缺点
3. 该特质是"可爱的小毛病"而非真正的性格缺陷（"太爱吃甜食""有点迷糊"）

**正例（触发）**：
- "她很完美，唯一的缺点是太努力了" → "太努力"是虚假负面 → 按0负 → 触发
- "她什么都好，就是太善良了" → "太善良"是虚假负面 → 按0负 → 触发
- "她唯一的缺点是太为别人着想了" → "太为别人着想"是虚假负面 → 按0负 → 触发

**反例（不触发）**：
- "她善良但有点自私" → "自私"是真实负面 → 不触发
- "她坚强但很固执" → "固执"是真实负面 → 不触发
- "她温柔但很敏感" → "敏感"是中性偏负面 → 不触发

#### 规则 C：信息不足（不触发，转完整性检查）

用户只写了极少数特质（≤2个），无法判断正负比例。

**判断公式**：如果用户给出的明确特质总数 ≤ 2 → 不做扁平检测，转完整性检查（信息不足，需要更多信息）。

**正例（不触发扁平，转完整性）**：
- "安静、善良"（2个特质）→ 信息不足，不是扁平
- "她很温柔"（1个特质）→ 信息不足
- "她是一个好人"（1个特质）→ 信息不足

**反例（触发扁平）**：
- "温柔、善良、坚强、独立、懂事"（5个特质）→ 信息足够，正负比例失衡 → 触发

#### 规则 D：灰色地带（弱触发）

正负比例在边界附近，或者特质数量足够但正负差距不够大。

**判断公式**：
1. 4正0负 → 弱触发（信息量够但差距在边界）
2. 5正1负，且那1负是"轻度负面"（如"有点小脾气""偶尔懒"）→ 弱触发
3. 3正0负 + 用户只写了3个特质 → 弱触发（信息量刚好在边界）

**处理方式**：标记为"弱扁平"，AI 追问时用"她有没有什么让别人受不了的地方？"而非"你的角色太完美了"。

**正例（弱触发）**：
- "温柔、善良、坚强、独立"（4正0负）→ 弱触发
- "温柔、善良、坚强、独立、偶尔有点小脾气"（4正1轻度负）→ 弱触发
- "温柔、善良、坚强"（3正0负，但只有3个特质）→ 弱触发

**反例（不触发）**：
- "温柔、善良、坚强，但有点倔"（3正1真实负）→ 不触发
- "温柔、善良、坚强、独立、敏感"（4正1中性）→ 不触发

### 5.3 判断流程图

```
用户输入
  │
  ├─ 统计明确特质数量
  │   │
  │   ├─ ≤ 2 个特质 → 不触发扁平，转完整性检查（规则 C）
  │   │
  │   └─ ≥ 3 个特质 → 继续
  │
  ├─ 检查是否有"虚假负面"（规则 B）
  │   │
  │   ├─ 有虚假负面 → 将其从负面中剔除，按0负处理
  │   │
  │   └─ 无虚假负面 → 继续
  │
  ├─ 计算正负比例
  │   │
  │   ├─ 正面 ≥ 负面 + 3 → 触发（规则 A-3）
  │   │
  │   ├─ 正面 ≥ 4 且 负面 = 0 → 触发（规则 A-4）
  │   │
  │   ├─ 正面 ≥ 5 且 负面 ≤ 1 → 触发（规则 A-5）
  │   │
  │   ├─ 4正0负 → 弱触发（规则 D-1）
  │   │
  │   ├─ 3正0负 → 弱触发（规则 D-3）
  │   │
  │   └─ 其他情况 → 不触发
  │
  └─ 注意：中性特质不计入正或负，但计入特质总数
```

### 5.4 正例与反例汇总

**应该触发（6个）**：
1. "温柔、善良、坚强、独立、懂事"（5正0负）→ 正负失衡
2. "她很完美，唯一的缺点是太努力了"（虚假负面）→ 实际0负
3. "她善良、温柔、体贴、大方、聪明、勤奋、漂亮"（7正0负）→ 全正面
4. "她什么都好，就是太善良了容易被欺负"（虚假负面）→ 实际0负
5. "她是一个完美的女孩，没有任何缺点"（明确说没缺点）→ 触发
6. "温柔、善良、坚强、独立、乐观、勤奋"（6正0负）→ 全正面

**弱触发（3个）**：
1. "温柔、善良、坚强、独立"（4正0负）→ 边界
2. "温柔、善良、坚强"（3正0负）→ 边界
3. "温柔、善良、坚强、独立、偶尔有点小脾气"（4正1轻度负）→ 边界

**不应该触发（6个）**：
1. "温柔、善良、坚强，但有点倔"（3正1真实负）→ 平衡
2. "安静、善良"（2个特质）→ 信息不足，转完整性
3. "聪明但懒惰"（1正1负）→ 平衡
4. "温柔、善良、坚强、独立、敏感、倔强"（4正2中性）→ 有中性特质
5. "她很温柔"（1个特质）→ 信息不足
6. "温柔、善良、坚强、独立，但有点倔"（4正1真实负）→ 平衡

## 六、诊断优先级与组合处理

### 6.1 多诊断同时触发时的优先级

同一段用户输入可能同时触发多个诊断。优先级如下：

```
1. 矛盾检测（最高优先级）→ 矛盾是最值得追问的入口
2. 结论检测 → 如果用户给的是结论，先还原成画面
3. 泛化检测 → 画面有了但太泛，需要具体化
4. 扁平检测（最低优先级）→ 其他问题都处理了再检查扁平
```

**原因**：
- 矛盾是通往深层真相的入口，应该最先处理
- 结论需要先还原为画面，才能判断画面是否泛化
- 泛化的画面需要先具体化，才能判断正负是否平衡
- 扁平是"锦上添花"的诊断，优先级最低

### 6.2 组合处理规则

| 同时触发 | 处理方式 |
|---|---|
| 矛盾 + 结论 | 先处理矛盾（矛盾点本身就是追问入口），结论问题在追问中自然解决 |
| 矛盾 + 泛化 | 只处理矛盾，泛化在矛盾追问中自然解决 |
| 结论 + 泛化 | 先处理结论（还原画面），再判断还原后的画面是否泛化 |
| 泛化 + 扁平 | 先处理泛化，再检查扁平。如果泛化追问后用户补充了负面特质，扁平可能自动解决 |
| 三个以上同时触发 | 只处理优先级最高的 1-2 个，其他标记为"待观察" |

### 6.3 同一诊断连续触发的降级处理

如果同一诊断连续 3 轮以上触发（用户始终给不出合格的回答）：

- **泛化连续触发**：降低标准，接受"弱触发"级别的回答，推进到下一阶段
- **矛盾连续触发**：检查 AI 是否理解错了用户的意图，考虑用户可能故意设计矛盾
- **结论连续触发**：降低标准，接受"有行为动词但无画面"的回答
- **扁平连续触发**：降低标准，接受"轻度负面"的回答

## 七、与 SKILL.md 的集成方式

### 7.1 诊断输出格式

每轮诊断后，AI 内部生成以下结构：

```json
{
  "diagnosis": {
    "generalization": {
      "triggered": true,
      "level": "strong",       // "strong" | "weak" | false
      "evidence": ["纯形容词：温柔", "无具体行为"],
      "matched_rule": "规则A"
    },
    "contradiction": {
      "triggered": false,
      "level": false,
      "evidence": [],
      "matched_rule": null
    },
    "conclusion": {
      "triggered": true,
      "level": "weak",
      "evidence": ["行为动词'回避'但无画面"],
      "matched_rule": "规则B"
    },
    "flatness": {
      "triggered": false,
      "level": false,
      "evidence": [],
      "matched_rule": null
    }
  },
  "action": "先处理结论（弱），追问具体画面"
}
```

### 7.2 追问语气映射

| 诊断级别 | AI 内部标记 | 对外追问语气 |
|---|---|---|
| strong | "明确问题" | 直接追问，用"给我一个具体的画面" |
| weak | "可能有问题" | 温和追问，用"能多说一点吗？" |
| false | "没问题" | 不追问 |

### 7.3 质量门

一段用户输入被认为是"合格的"（不需要追问），当且仅当：

1. 所有 4 个诊断的触发级别都不是 "strong"
2. 最多只有一个诊断是 "weak" 级别
3. 如果某个诊断连续 3 轮 "strong"，降级处理（见 6.3）
