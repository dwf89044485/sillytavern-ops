# 诊断设计决策记录：4 个基础诊断的精确判断标准

> 本文件记录 4 个基础诊断的设计决策。接手的 AI 读完这份文件，应该能直接把诊断写进 SKILL.md。

---

## 总体设计原则

### 三级判定（非二元）

所有诊断统一用三档判定，不是简单的"触发/不触发"：

| 级别 | 含义 | AI 的追问方式 |
|---|---|---|
| **触发** | 明确有问题 | 直接追问，引导用户给出更具体的内容 |
| **观察** | 灰色地带，有倾向但不确定 | 温和试探，承认用户已有进步但还差一步 |
| **通过** | 没问题 | 不追问，继续推进 |

**为什么不用二元**：用户的回答经常在"太泛"和"够具体"之间——比如"她会照顾人"不是纯标签（有行为动词），但也不是具体画面（没有场景）。二元判定要么误触发（把还行的当成废的），要么漏判（把不够好的放过去了）。三级判定让 AI 在灰色地带时用更温和的方式追问。

### 跨诊断优先级

一条用户输入可能同时触发多个诊断。同时触发时的处理优先级：

**矛盾 > 结论 > 泛化 > 扁平**

理由：矛盾是最值得追问的入口（能揭示更深的真相），结论检测能帮用户从"分析"切换到"画面"，泛化是最常见但也最容易处理的。扁平最后，因为它通常在积累了足够多特质后才能判断。

同时触发多个时，**只处理优先级最高的 1-2 个**，不要一轮追问 3 个问题。

### 追问的核心纪律

- 触发后**只追问，不指责**。AI 不说"你写的太泛了""你的标签打架了"。
- 诊断标签（泛化/矛盾/结论/扁平）是 AI 内部用的，**永远不对用户说出这些词**。
- 灰色地带默认走"观察"——宁可多问一句，不要误判为"没问题"。

## 诊断一：泛化检测

### 一句话原则

**这段描写换一个角色名字还成立吗？成立 → 触发。**

### 判定树

```
Step 1: 遮名测试
  把角色名换成同类人群的任意角色，这段描述还成立吗？
  → 不成立（只属于她）→ 通过，结束
  → 成立 → 进入 Step 2

Step 2: 画面测试
  这段描述能让 AI "看到"一个具体画面吗？
  画面 = 至少包含一个：
    (a) 具体场景/时间（"上课时""回家后"）
    (b) 具体物理对象（"草稿纸""杯子""校服袖口"）
    (c) 具体身体动作（"推到桌角""蹲下来""攥了一下"）
  → (a)(b)(c) 至少有一个 → 通过，结束
  → 都没有，但有行为动词 → 观察
  → 都没有，也没行为动词 → 触发
```

### 内容分类（AI 内部参考）

| 类型 | 特征 | 判定 |
|---|---|---|
| A: 万能形容词 | 温柔、善良、坚强、精致、优雅、美丽、聪明 | 触发 |
| B: 文学比喻 | "像清泉一样的眼睛""像墙角的小草" | 触发 |
| C: 具体行为 | "用书本把东西推到桌角""草稿纸正反面写满" | 通过 |
| D: 有倾向无画面 | "会照顾人""记住别人说的话""不善言辞" | 观察 |

**放大器规则**："极度/极致/特别/非常"套在 A 类标签上，仍判为触发，并提示 AI 在追问时自然引导用户去掉放大器（因为 AI 会往极端拉，角色失去弹性）。

**AI 默认值规则**：描写了 AI 对该人群的默认认知（17岁中国女生写"黑发黑眼""皮肤白皙"），判为触发——只需要写偏离默认的部分。

### 灰色地带处理

| 用户输入 | 判定 | 理由 |
|---|---|---|
| "她温柔，会照顾人" | 触发 | "照顾人"是行为类别但无场景，遮名成立 |
| "她是那种会记住别人说过的话的人" | 触发 | 有行为倾向但无具体情境 |
| "她不善言辞但很细心" | 触发 | 两个标签，无画面 |
| "她话不多，但别人说话时她都在听" | 观察 | 有行为（在听），但缺场景细节 |
| "她遇到不会的题会在草稿纸上反复算" | 通过 | 有场景+对象+动作 |

### 正例（应该触发）

1. "她很温柔" → 纯形容词
2. "五官精致秀气，是古典画中走出来的美人胚子" → 万能形容+文学比喻
3. "她特别善良特别自卑" → A 类标签+放大器
4. "她温柔，会照顾人" → A 类+D 类
5. "她黑发黑眼，皮肤白皙" → AI 默认值重复

### 反例（不应该触发）

1. "她会默默把杯子续上水" → 具体动作+对象
2. "刘海自己剪的，有些参差" → 只属于她的物理特征
3. "他把零食放她桌上，她用书本推到桌角" → 完整画面
4. "递本子时会小心不让手指碰到对方" → 具体互动动作
5. "她知道哪个菜市场周三便宜两毛" → 具体行为+细节

### 教程锚点

晴空妈妈的三层判断法：
1. **遮名测试**："遮住名字放在别的角色身上成立吗？"成立=泛化
2. **默认值排除**："17 岁中国女生 AI 数据库默认什么样？"是默认值=不需要写
3. **画面检验**："我试着在脑海里画她，画得出具体样子吗？"画不出=泛化

## 诊断二：矛盾检测

### 一句话原则

**两个标签放在一起，AI 按刻板模板演标签 A 时，标签 B 的行为还可能发生吗？不可能 → 触发。**

### 核心发现：触发器是放大器，不是标签本身

"自卑"+"成绩好" → **不触发**。自卑的人也可以努力学习。
"**极度**自卑"+"成绩好" → **触发**。"极度"把自卑推到完全不能行动的极端，维持成绩前列的行为在这个极端下不可能。

**矛盾检测的触发器往往不是特质本身，而是修饰词的极端程度。**

### 判定树

```
Step 1: 放大器检测
  用户的标签/描述中是否含有绝对化语言？
  绝对化语言：极度、极致、从不、永远、完全、绝对、一点也不
  → 有 → 进入 Step 2
  → 没有 → 进入 Step 3

Step 2: 逻辑共存测试（有放大器时）
  假设被放大的标签字面为真，另一个标签/行为还逻辑上可能吗？
  测试问法："一个[被放大的标签]的人，能做到[另一个标签/行为]吗？"
  → 不可能 → 触发
  → 困难但可能 → 观察
  → 完全可能 → 通过

Step 3: 同领域互斥检测（无放大器时）
  两个标签是否在同一行为领域且定义互斥？
  → 是（如"哑巴"+"辩论队队长"）→ 触发
  → 否 → 通过
```

### 关键区分：逻辑打架 vs 正常人性矛盾

| 类型 | 特征 | 判定 |
|---|---|---|
| **逻辑打架** | 同一维度上互斥，绝对词制造不可能 | 触发 |
| **正常人性矛盾** | 不同情境/不同对象的共存 | 不触发 |
| **场景分化** | 不同压力场景下不同表现 | 不触发（这是三面性信号，不是矛盾） |

### 灰色地带处理

| 用户输入 | 判定 | 理由 |
|---|---|---|
| "很独立"+"每天打电话给男朋友" | 通过 | 无绝对词，独立≠情感孤立，跨领域 |
| "内向"+"在舞台上很疯" | 通过 | 不同情境的场景分化，内向表演者是已知模式 |
| "善良"+"会骂人" | 通过 | 善良的人被惹急也会骂人，正常范围 |
| "很独立"+"完全离不开妈妈" | 观察 | "完全"是绝对词，但特定关系依赖可以解释 |

### 正例（应该触发）

1. "极度自卑"+"成绩年级前列" → "极度"使自卑=完全不能行动，与持续行动互斥
2. "从不求人"+"最后向人借钱" → "从不"是绝对禁止，借钱直接打破
3. "永远冷静"+"经常发脾气" → "永远"与"经常"互斥
4. "极致善良，从不拒绝任何人"+"她有时候会拒绝帮助" → "从不"被打破

### 反例（不应该触发）

1. "温柔"+"有时候会发脾气" → 无放大器，正常人性
2. "内向"+"在舞台上很疯" → 场景分化，非矛盾
3. "善良"+"会骂人" → 善良≠永远不发火
4. "坚强"+"偶尔偷偷哭" → 坚强的人私下也会哭

### 教程锚点

晴空妈妈的判断法：
1. **放大器识别**："先去掉'极度'。AI 会把所有行为往最极端方向拉。"
2. **逻辑共存追问**："一个极度自卑的人，能做到年级成绩前列吗？"
3. **矛盾是入口不是错误**：追问目的是修正标签或补全共存逻辑（"极度自卑"→"不甘心"），不是指责用户写错了

晴空还有一个重要判断：不只看标签之间的矛盾，还看**标签和用户描述的行为之间的矛盾**——标签说"极度自卑"，但行为里有"主动求助""维持成绩"，行为和标签也打架。

## 诊断三：结论检测

### 一句话原则

**这段描写摄影机拍得到吗？拍不到 → 触发。**

### 判定树

```
Step 1: 摄影机测试
  如果架一台摄影机拍这个角色，摄影机能拍到用户描写的东西吗？
  → 能拍到（物理动作/表情/对话/生理反应）→ 通过
  → 拍不到（内心状态/心理分析/作者判断）→ 进入 Step 2

Step 2: 动词类型检查
  描写中的动词是"瞬间动词"还是"模式动词"？
  瞬间动词（某一刻的物理动作）：转头、推、缩、攥、松、哼、弯、愣
  模式动词（一系列行为的归纳）：回避、依赖、追求、排斥、逃避、迎合
  → 瞬间动词 → 观察（有动作但缺场景）
  → 模式动词 → 触发
  → 无动词（纯内心/纯判断）→ 触发
```

### 结论词清单（出现即高度疑似结论）

充满、恐惧、排斥、喜欢、讨厌、觉得、认为、意味着、说明、其实是、本质上、内心、矛盾、转变、起点、因为……所以……（因果总结）

**例外**：结论词后面紧跟可观测行为时，降级为"观察"而非"触发"。如"她害怕失去妈妈所以很努力赚钱"——"害怕"是结论，但"努力赚钱"是行为。对结论部分追问，保留行为部分。

### 灰色地带处理

| 用户输入 | 判定 | 理由 |
|---|---|---|
| "她会回避和他的接触" | 触发 | "回避"是模式动词，无具体瞬间 |
| "她不喜欢被人关注" | 触发 | "不喜欢"是内心状态，摄影机拍不到 |
| "她害怕失去妈妈所以很努力赚钱" | 触发（前半） | 前半是结论，后半是行为。追问前半保留后半 |
| "她看到他会把目光移开" | 观察 | "移开目光"是瞬间动词，但缺场景 |
| "她回家后肩膀会松下来" | 通过 | "肩膀松"是可拍摄的身体变化 |

### 正例（应该触发）

1. "她对他充满恐惧" → 内心状态，拍不到
2. "这是她性格转变的起点" → 作者因果判断
3. "她内心很矛盾，既渴望被爱又害怕被伤害" → 心理分析
4. "她会回避和他的接触" → 模式归纳，无具体瞬间
5. "她本质上是缺乏安全感的人" → "本质上"+结论词

### 反例（不应该触发）

1. "他把零食放她桌上，她用书本推到桌角" → 可拍摄动作链
2. "老师表扬她时耳朵发烫，小声说谢谢" → 可观测生理+动作+对话
3. "递本子时小心不让手指碰到对方" → 具体互动画面
4. "她回家后肩膀松下来一点" → 可拍摄身体变化
5. "做饭时会哼一点什么，很轻，调子不全" → 可拍摄动作

### 教程锚点

晴空妈妈的判断法：
1. **旁观者测试**："如果我站在旁边看，我看得到什么？"——看不见的内心状态=结论
2. **事实 vs 解释分离**："10 岁时父亲因意外去世"是事实（留），"这是性格转变的起点"是解释（删）
3. **画面替代原则**："你让 AI 自己看见'她用书本推走零食'，AI 就能自己感受到回避。你不需要替 AI 下结论。"

## 诊断四：扁平检测

### 一句话原则

**角色有真正的缺点/局限/反差吗？没有 → 触发。**

### 判定树

```
Step 1: 分类
  把用户给的所有特质分为三类：
  - 正面：让角色更好/更讨喜的（温柔、善良、坚强）
  - 真负面：造成真实困难/后果的（倔到得罪人、不信任人导致孤立）
  - 伪负面：名义缺点实际是变相优点（太努力、太善良、太完美）

Step 2: 伪负面识别
  识别规则：把"缺点"换成正面说法，读起来一样吗？
  "太努力了" → "很努力" → 一样 → 伪负面
  "倔" → 无法换成正面 → 真负面
  伪负面计入正面，不计入负面

Step 3: 计数与判定
  → 真负面 = 0 且总特质 ≥ 3 → 触发
  → 真负面 = 0 且总特质 < 3 → 不触发（信息不足，路由到完整性检查）
  → 真负面 ≥ 1 → 通过

Step 4（可选）: 方向多样性检查
  所有特质是否都指向同一个基调？
  如全是"惨/乖/善良"的变体 → 即使有"负面"也可能扁平
  → 有不同方向的特质共存 → 通过
  → 全部同方向 → 观察
```

### 伪负面识别规则（重要）

| "缺点" | 换成正面说法 | 判定 |
|---|---|---|
| "太努力了" | "很努力" → 一样 | 伪负面 |
| "太善良了" | "很善良" → 一样 | 伪负面 |
| "太认真了" | "很认真" → 一样 | 伪负面 |
| "倔" | 无法换 | 真负面 |
| "容易发火" | 无法换 | 真负面 |
| "不信任人" | 无法换 | 真负面 |

### 方向多样性（Agent 5 的独特贡献）

扁平不只是"全是优点"，还包括"全是同一个方向"。

例：柚子原来的 7 个标签——"极度自卑、沉默寡言、敏感胆怯、极致善良、坚韧执拗、高度专注、被动顺从"——有些可以算"负面"（自卑、胆怯、被动），但**全部指向同一个基调："惨、乖、弱"**。没有反差方向。

晴空引导柚子找到"藏着的温度"作为点缀色——这是一个**不同方向**的特质，打破了单向度的扁平。

### 灰色地带处理

| 用户输入 | 判定 | 理由 |
|---|---|---|
| "温柔、善良、坚强、独立，但有点倔" | 通过 | 4正+1真负面（倔是真负面） |
| "她很完美，唯一缺点是太努力了" | 触发 | 伪负面，真负面=0 |
| "安静、善良"（只有2个） | 不触发 | 信息不足，路由到完整性检查 |
| "温柔、善良、勇敢、聪明、独立" | 触发 | 5正0真负面 |
| "她对外人冷漠，对妈妈温柔" | 通过 | 有反差方向（冷漠 vs 温柔），不扁平 |

### 正例（应该触发）

1. "温柔、善良、坚强、独立、聪明" → 5正0负
2. "她很完美，唯一缺点是太努力了" → 伪负面
3. "她善良到极致，缺点是太善良" → 自指伪负面
4. "她是世界上最好的人，从来不生气" → 无阴影

### 反例（不应该触发）

1. "温柔但有点倔，倔起来会跟人吵到断交" → 真负面+具体后果
2. "她独立，但不信任任何人导致没什么朋友" → 真负面+后果
3. "对外人冷漠，对妈妈温柔" → 有反差方向
4. "坚强，但有时候偷偷哭" → 主色调+私下释放，有张力

### 教程锚点

晴空妈妈的方法：
1. **点缀色追问**："什么时候她跟平时完全不一样？"——寻找反差
2. **不直接说"你缺缺点"**：用自然问法（"她朋友会怎么吐槽她？""她有什么改不掉的毛病？"）
3. **接受"优点有副作用"也算打破扁平**：如"她太操心了有时候让人压力很大"——温柔的副作用是过度

## 决策过程

### 怎么得出这些标准的

1. 派出 5 个独立 AI agent（deepseek-v4-flash / hy3 / glm-5.2 ×3），各自读教程原文和我们的架构设计，独立设计判断标准
2. 5 个 agent 不约而同提出了三级判定（触发/观察/通过）——采纳为统一框架
3. 5 个 agent 在核心测试方法上高度一致（遮名测试/放大器检测/摄影机测试/伪负面识别）
4. 各 agent 有独特贡献被整合进来（见下表）
5. 所有判断标准都回溯到教程中晴空妈妈的实际判断方式，确保和源材料一致

### 各 agent 的独特贡献

| 来源 | 贡献 | 用在哪 |
|---|---|---|
| Agent 2 (hy3) | 结论词清单 | 诊断三的快速判定参考 |
| Agent 2 (hy3) | 跨诊断优先级（矛盾>结论>泛化>扁平） | 总体设计原则 |
| Agent 3 (glm) | 扮演测试（能用肢体演出来吗） | 泛化检测的直觉判断辅助 |
| Agent 4 (glm) | AI 刻板模板冲突测试 | 矛盾检测的核心判断法 |

## 接手 AI 的行动指南

写 SKILL.md 中 4 个基础诊断时：

1. **每个诊断写判定树**（Step 1→2→3），不写"看情况"
2. **每个诊断附 2-3 个正例+反例**，让 AI 校准判断尺度
3. **灰色地带统一走"观察"级**：温和追问而非直接指出问题
4. **跨诊断优先级写在诊断部分的开头**
5. **结论词清单和放大器清单作为查表工具内联**
6. **不要把教程锚点写进 SKILL.md**——那是教学内容。只写判定规则和追问方式
