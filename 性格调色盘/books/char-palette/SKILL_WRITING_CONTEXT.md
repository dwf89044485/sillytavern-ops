## 1. 任务定位（一句话）

做一个 skill：**在 Claude Code 里通过追问引导用户创建角色**。用户提供想法（标签/画面/经历/模糊感觉/什么都没有），AI 追问帮用户自己"看见"角色；产出 = 可直接导出为角色卡内容的人物文档。**用户不需要学习任何方法论；好坏的唯一标准是用户说出的话越来越具体、越来越像"只有她的角色才会这样"。**

**关键结构原则**：
- 4 个诊断放 SKILL.md 的理由：全程运行每轮都要用；放 reference = 永远要加载的 reference，文件边界无信息量。

## 3. 教程方法论精要（已内化；写 probe 的内部诊断/质量门时直接使用）

> 来源：融合简报 SKILL_WRITING_BRIEF §二（其作者通读过教程）。本包作者未读教程，此节按其简报并入。**写作时以此节为纲，不需回读教程**；需要完整案例时按 §7 的定点提取指针定向取。

### 3.1 角色卡七层结构与写作规则（= 人物文档构建区框架）

写卡顺序：**基础信息 → 调色盘 → 多面性 → 混色画面 → 核心人格层 → 二次解释 → 意象**。多面性/混色/核心人格层是进阶可选，按角色需要触发。

1. **基础信息**（"她是谁"）：基本信息 / 外貌特征 / 背景设定 / 关系设定。**性格不写在这里。**
   - 外貌只写特征不写形容：遮名测试；只写偏离 AI 默认值的部分（17 岁中国女生不需要写"黑发黑眼"）；不写比喻、美感判断、行为习惯。
   - 背景只写改变这个人的事，只摆事实不写解释（"这是性格转变的起点"这类总结是二次解释的事）。
   - 关系写具体互动画面（"他用书本把零食推到桌角"），不写抽象形容。
2. **调色盘**（"她是什么质地"）：底色（无论场景怎么变都隐隐存在）/ 主色调（日常最常驱动行为）/ 点缀色（平时看不到、负责反差和隐藏层）。每色下写**衍生**——该颜色在具体生活场景里的行为画面。
   - 衍生是"压缩包"：3-5 条具体画面让 AI 解压。
   - 一条衍生可同时含两种颜色（颜色互相渗透，不为每种特质单独开标签）。
   - **禁放大器词**（极度/极致会把角色拉向极端）。
   - 衍生只写"她做什么"，不写"为什么"。
3. **多面性**（"同一盘颜料在不同场景怎么调"，可选）：判断标准 = 存在 ≥2 个**压力性质截然不同**的场景导致**整套行为逻辑切换**（"语气柔和了一点"不算）。
   - 每面**五部件**：触发条件 / 能量状态 / 语料 / 身体行为模式 / 功能，五个都写。
   - 面间**过渡**（至少最常见的和最剧烈的切换路径）与**渗透**（一张面运行时其他面元素的泄漏，角色最真实的时刻）。
   - 有三面性的角色，**语料从调色盘移入每一面**（规律留调色盘，实例放多面性）。
   - 不要硬拆面。
4. **混色画面**（"同一瞬间颜色怎么撞"，可选）：同一画面/动作/句子里两种以上情绪同时出现。
   - 核心技巧**物理事实反差**：两个客观事实摆一起让反差自动产生（"她说'我没事'。她的手在抖。"）。
   - **只写动作，不解释情绪**（一解释 AI 就照搬结论变八股）。
   - 点睛之笔不是底色，不要每个瞬间都混色；**禁"但/然而"转折句式**。
   - 适合有内部矛盾的角色。
5. **核心人格层**（"她为什么做这种选择"，可选）：七部件 = **表层欲望 / 深层缺失 / 核心恐惧 / 防御机制 / 核心矛盾 / 道德底线 / 自我认知可能性**。
   - 防御机制必须写成行为（"让自己不存在"+"让自己有用"，不是"逃避"）。
   - 核心矛盾一句话说清；道德底线是"跨过去她就不再是她自己"的定义；自我认知写"可能性"不写固定结局。
   - 日常**不频繁触发**核心恐惧（底层逻辑，大部分时间只泄漏一点点）。
   - 适合有剧情驱动/内部矛盾/成长空间的角色。
6. **二次解释**（防误读护栏，放所有人设内容最后）：格式"关于她的X："，每条做两件事——说清这个特质在她身上是什么样的 + 拦住 AI 最容易犯的错。
   - **直接叙述想要的样子，不先列举错误再否定**。
   - 调色盘给材料，二次解释给使用注意事项。
7. **意象**（总比喻收束，放最后）：从核心矛盾/存在状态长出（"她存在的方式像什么"），不外部搜比喻；能承载与 {{user}} 的关系动态（风铃和风、一小格阳光和开窗的人）；短；不解释自己。

### 3.2 三个构建路径（多入口的证据）

- **陈乖乖**：7 个标签 → 逐层下钻 → 调色盘三层（不甘心/把乖当盔甲/藏着的温度）。
- **姜糖**：一个画面 → 反推颜色。
- **三明月**：不用调色盘体系 → 小传+采访（教程 11 的"另一种写法"= 快速路径源材料）。

结论：构建路径由用户初始状态决定，不预设固定流程。

### 3.3 晴空妈妈标志性追问（写 SKILL.md body"措辞内化样本"用）

- "这七个标签里，哪个是无论如何都在那里的？"（底色提取）
- "一个极度自卑的人，能做到成绩年级前列吗？"（矛盾追问）
- "她为什么安静？"→"不出声就不会出错"→"把乖当盔甲"（机制下钻）
- "哪个菜市场周三便宜两毛"（把"穷"变成画面）
- "她最怕什么？不是怕黑怕疼——是'如果这件事发生了，我就不是我了'的那种怕。"
- 标签下钻五连问："她具体做什么？她什么时候这么做？她为什么不直接说？她这么做会伤到谁？她什么时候会停下？"

### 3.4 24-80-200 问工作流（question-bank 的原料）

- **24 问急救模式**：不知道怎么下手的用户先抓轮廓（6 组：角色核心/调色盘/来源/欲望恐惧/关系行为/AI 可演性）。
- **80 问正式模式**：推荐主线，10 组对应方法论结构（角色核心/调色盘/背景来源/欲望缺失恐惧/防御决策/关系/多面性/混色/台词行为/底线弧光二次解释）。
- **200 问抽题模式**：卡住时按卡点抽题（20 组）。
- 运行规则：一次只问一个问题；回答只有抽象标签必须追问一次具体行为；"不知道"记为暂未确定不替用户决定；支持修改/回看/切换/总结指令。
- 记录格式：`问题 / 用户原回答 / 整理后的思路 / 可落到行为的部分 / 仍待确认`。
- 最终总结（13 部分"创作思路整合"）：**必须区分用户已确定 / AI 高可能推论 / 待用户决定**；只能叫"创作思路整合"不能叫"最终人设"；禁止事项（不写成品卡/开场白/世界书，不替用户决定，不把可能改成确定）。
- 回答标准："不要只写'她害怕被抛弃'，要写'她害怕被抛弃时会怎么保护自己'。"

## 4. 决策日志（✅ 已确认结论，编写时直接遵守，不再重新论证）

> 格式：`编号。结论。［出处］`。编号按主题分组。全文细节去出处文件看，本表不重复。带 ⚠️ 的条目见 §6 待决。

### A. 定位与最高约束

- A1. 技能用途是构建角色卡，不是运行角色卡；人物成型后一次性写成实际用的卡。［handoff §1］
- A2. **教程 ≠ skill**：教程默认模式是教学（晴空妈妈教柚子），skill 默认模式是追问。追问动作融入，教学意图不融入；用户主动问"为什么"时才简答然后切回追问。［AGENTS.md 最高约束 + CHAR_BUILD_GUIDE 翻译层］
- A3. 教程顺序 = 教学逻辑，不是构建逻辑，不作为 skill 设计依据。［handoff §1］
- A4. 教程是写给人看的（大量篇幅说服人类作者），AI 执行者不需要被说服 → skill 剔除说服性内容，只保留操作指令和判断标准（执行语言，非教学语言）。［CHAR_BUILD_GUIDE §0.6］
- A5. **AI 不是 if-else 执行器**：原则驱动优于规则穷举。给顶层原则 + 清晰目标 + 判断好坏的标准，信任 AI 在具体场景判断。［CHAR_BUILD_GUIDE §1.2］
- A6. 三面性 → **多面性**命名（面数由角色决定，不限定三张）。［AGENTS.md + handoff §2.7］
- A7. skill 是追问引擎，不是知识手册；继承教程的追问能力，不继承术语表。［CHAR_BUILD_GUIDE §1.1］
- A8. 用户不需要学习教程；诊断地图（调色盘/多面性/混色/核心人格层）是 AI 内部工具，不对用户说术语。［§1.3 + char-palette 决策 #3/#8］
- A9. 顶层原则五条：从最具体的地方开始 / 只追问不填空（硬铁律）/ 推向独特性 / 节奏由用户决定 / 帮用户梳理不替用户总结。［CHAR_BUILD_GUIDE §2.1-2.5］
- A10. AI 主动性边界：追问帮用户自己想出来 ✓；用户说"不知道"时替她生成答案 ✗；从已有行为找模式推给用户确认 ✓；把术语抛给用户 ✗；确认前替用户总结 ✗。［§1.4］
- A11. 每句话必要性审查：skill 里每句话过"删掉它是否影响 AI 的理解和执行"测试，删掉不影响即废话。［handoff 大原则 3］
- A12. 文档顺序本身就是呈现顺序，不额外写"按呈现顺序排版"这类话术。［handoff 大原则 4］
- A13. 方向锚点 5 条（写 body 顶层原则用）：①越具体→AI 越难套模板，追问到"只有她才这样"就停；②AI 生成的内容=AI 数据库里最常见的东西，用户说不知道时不许替她生成；③角色区别不在颜色多，在于有没有 AI 数据库里不存在的颜色组合；④问"她做了什么"比问"她感受到了什么"有效 10 倍；⑤AI 会偷懒下结论锁死——永远只整理用户说了什么，不替用户总结。［融合简报 §3.2］

### B. 诊断系统（4 个基础诊断 → 写进 SKILL.md，来源 DIAGNOSTICS_DECISION.md）

- B1. 三级判定（非二元）：**触发**（明确有问题→直接追问）/ **观察**（灰色地带→温和试探）/ **通过**（不追问）。灰色地带默认走"观察"，宁可多问一句。
- B2. 跨诊断优先级：**矛盾 > 结论 > 泛化 > 扁平**。同时触发多个时只处理优先级最高的 1-2 个，不一轮问 3 个问题。
- B3. 追问纪律：只追问不指责；诊断标签（泛化/矛盾/结论/扁平）是 AI 内部用的，**永远不对用户说出**。
- B4. **泛化检测**：遮名测试（换名字还成立→触发）→ 画面测试（场景/对象/动作至少其一）；内容分类 ABCD（万能形容词/文学比喻→触发，具体行为→通过，有倾向无画面→观察）；放大器规则（"极度"套 A 类标签仍触发，追问时引导去掉放大器）；AI 默认值规则（描写 AI 对人群的默认认知→触发，只写偏离默认的部分）。
- B5. **矛盾检测**：核心发现——触发器是放大器不是标签本身（"自卑"+"成绩好"不触发；"极度自卑"+"成绩好"触发）。判定树：放大器检测 → 逻辑共存测试 / 同领域互斥检测。区分逻辑打架（触发）vs 正常人性矛盾（不触发）vs 场景分化（不触发——那是多面性信号）。矛盾是入口不是错误，追问目的是修正标签或补全共存逻辑，不指责。
- B6. **结论检测**：摄影机测试（拍得到→通过；内心状态/心理分析/作者判断→触发）。瞬间动词（转头/攥/缩）→观察；模式动词（回避/依赖/逃避）→触发。结论词清单内联（充满/恐惧/排斥/意味着/其实是/本质上/因为所以…）。例外：结论词后跟可观测行为→降级观察（追问前半保留后半）。
- B7. **扁平检测**：真负面/伪负面/正面分类；伪负面识别规则（换成正面说法读起来一样=伪，如"太努力了"）；真负面=0 且特质≥3→触发，特质<3→路由完整性检查；方向多样性检查（全是同一基调=观察）。
- B8. SKILL.md 写诊断的方式：每个诊断写判定树（Step 1→2→3，不写"看情况"）+ 2-3 个正例反例 + 结论词清单/放大器清单内联查表 + 优先级写在诊断部分开头；**教程锚点不写进 SKILL.md**（那是教学内容）。⚠️ 诊断全量位置（SKILL.md 内联 vs references/diagnostics.md）属架构冲突 → 待办 Q0。

### C. 追问动作体系（13 个动作 = 4 诊断 + 9 追问，来源 verified.md + questioning-moves.md）

- E5. 质量信号表（A 行为级密度 / B 独有性 / C 新增性 / D 模式可见性 / E 修正精度 / F 自发延伸 / G 自然收束意愿；最强的信号是 E 和 F——它们证明用户脑中有一个比 AI 追问更详细的角色模型）；明确排除的假信号（回答变长/用术语/说"我知道了"/情绪激动 ≠ 能看见角色）。［§4.3.2］
- E6. 行为测试只用修改版（用户自发生成场景），禁止原始版（AI 构造场景——方向反了+场景嵌入角色假设+交互姿态变考官+答不出是挫败）。可选增强层，非必经。［§4.3.3］
- E7. 入口引导：第零步接管道具（有现成卡→解析映射到素材区，从标签化点追问，不要求重走流程）；永远不先问"她是什么性格"（问性格=诱导贴标签，改问事件类/具象类问题）。［handoff §2.9 + char-palette 决策 #1 标签不是敌人］

- E7c. 轻量锚定（各入口都走，1-2 轮）：世界观锚定（"她活在什么样的世界里？"+"有什么 AI 自己想不到的规则？"——只锚定到够让角色站住，不构建完整世界）+ 用户角色定位（"你在这个世界里是什么身份？和角色什么关系？还是旁观者？"——确定行为参照系）。［probe-world + handoff §2.9 第一步/第二步 + 融合简报 C11；用户定位的保留见 §6 Q7］
- E7d. 情景引导（用户确实没有构思时才用，收窄边界再激发）：①身份/处境——"她在这个世界里大概是个什么身份？学生？社畜？剑修？"框住人物边界；②情景引导——"想象一个场景：<契合题材和身份的具体场景>。在这个场景里，她的第一反应是什么？"；③生成的初始素材回到追问循环。**现成情景引导**（现代都市题材，按可答性排序）：日常生活类（"她下班回家，进门做的第一件事是什么？"）/ 关系类（"她最好的朋友失恋了半夜打电话给她，她第一反应是什么？"）/ 反差类（"她在什么情况下会和平时完全不一样？"）/ 压力类（素材足够后用："她接到一个坏消息，第一反应是什么？"）/ 决策类（最难，最后用："她只有一次机会，只能救一个人，她会救谁？"）。［handoff §2.9 第五步］
- E8. 基础身份轻量处理：用户带完整信息来就提取确认，不强制重走。［决策 #10］
- E9. 意象总是尝试：AI 主动提炼并提议（2-3 个候选），用户觉得对就留，不对就不要；2-3 个方向都不贴可跳过（不贴的意象比没有更糟）。［决策 #11 + handoff §2.23 + 融合简报 C9］
- E10. 收束：整理为结构化记录，不做解读式总结；最后问"还有什么地方没被写到的？"留空白入口。［CHAR_BUILD_GUIDE §4.4］
- E11. 步骤分级（handoff §2.6，写 SKILL.md 流程段用）：**必须**——入口引导（世界设定+用户定位，缺则角色缺坐标系）/ 素材收集（无素材无推演）/ 调色盘（核心产出）/ 二次解释（防 AI 误读）/ MVC 决策点（暂停，用户选择继续或收工）；**必须尝试**——意象（2-3 个方向都不贴可跳过）；**条件**——多面性（不同场景行为模式根本性切换→拆面，否则跳过）/ 混色（两种以上内心矛盾撞一起→写画面，否则跳过）/ 核心人格层（剧情驱动/内部矛盾/成长空间→挖七层，否则跳过）。MVC 后的条件步骤按构建顺序依次检查触发条件，不是一次性全推。

### F. 快速路径（同一引擎的轻语言分支，来源 CHAR_BUILD_GUIDE §十三 G1-G9）

- F1. 快速路径本质：**能力问题不是意愿问题**。用这个 skill 的人都有意愿，只有能力高低。快速路径 = 同一套追问引擎换更轻的追问语言（"看"代替"拆"，"变成她"代替"分析她"），是内部路径，不是独立 skill，不存在"抗拒检测"。［G1］
- F2. 切换条件只有一种：深入模式中连续卡住（换了 ≥2 个切面 + 脚手架推演 ≥2 次被否）→ 不追问原因直接切。切换语："我们换个方式——闭上眼，你第一个想到的关于她的画面是什么？"［G2］
- F3. 五步流程：基础信息 → 小传 → 采访 → 情绪阈值 → 意象（每步的追问动作与完成标准表见 §十三 G3；要点见 §3.1 对应层的规则 + 融合简报 §4.5 表格）。［G3］
- F4. 快速路径 MVC 锚点在情绪阈值完成之后、意象之前；可自选入口（三个入口信号）；双向切换（快速路径产出是深入模式反向拆解的素材）。［G4］
- F5. 标签优先：对能力最弱的用户先收标签不纠正，然后三步深化——标签阶段扫矛盾 → 每个标签四问转化（做什么/什么时候/为什么/伤到谁）→ 标签退场（产出文档没有标签只有画面）。标签是脚手架，盖完楼拆掉。**注意：标签优先 ≠ 主动诱导贴标签，"永远不先问性格"仍然成立。**［G5 + 融合简报 §6.5］
- F6. 引导机制升级阶梯四级：钻探链（最轻）→ 回链+行为锚定 → 多选行为引导 → 假设场景/闭上眼（最重）。先诊断卡住类型（标签卡/表面卡/八股卡/空白卡/碎片卡/深度卡/拆分卡）再匹配机制。越往上越接近替用户想，所以越轻越好。［G6］
- F7. 示范边界三条：不写用户的角色（用通用例子或教程案例库）/ 只示范一条（示范后交还："现在你来写你的角色的"）/ "找到"型任务不示范（意象、底色只给排除引导+方向暗示）。［G7］
- F8. 肯定+追问成对出现（"接受→推深"螺旋）；引导强度动态调整（素材少→重引导；素材积累→轻引导）。［G8］
- F9. 情绪串不主动追问，只做防御性纠偏（用户写出"她同时感到快乐和焦虑"这种解释句时才说"别解释，写一个看起来矛盾的动作"）。［G9］

### G. 交互协议（来源 handoff，均用户逐条确认）

- G1. **先问后推演**（协作模式核心基石）：AI 永远先问作者，禁止先给候选——作者的解释永远比 AI 的推演独特；AI 先给候选就把作者框住了。四层：问（具体化问法，不问抽象"为什么"，问"什么时候/对谁/什么情境"）→ 作者答上→验证不替换（查矛盾/补盲区标"补充不是替换"/指隐含结构）→ 作者无解→多路径推演 → 人裁决→循环。［handoff §2.10］
- G2. **确认 vs 同步**：纯过滤（不记）→ 必须同步一句（"这个没有推演价值，我先不记"），不需确认；价值判断推进 → 同步即可；产生新内容（推演候选、转写模糊表述）→ 必须确认才能写入。红线"AI 永远提案，用户永远裁决"不等于所有动作都要确认。［handoff §2.1b/§2.15b］
- G3. **三层交互模型：镜子 → 脚手架 → 推演**。镜子（=旧追问）：追问具体场景，3 轮无新产出→进脚手架；脚手架：给一个试探方向让用户反应（"这个方向对吗？"），2 次被否→进推演；推演：2-3 条候选标注行为场景+机制+依据，用户裁决。每次否决→轻量溯源（"哪里偏了？一个词就行"）→说不出→暴露理解（整理理解摘要问"哪里理解偏了"），禁止跳过溯源。［handoff §2.22/§2.19d］
- G4. 阶段声明只在交互模式改变时触发（追问→推演 / 槽位切换 / 推演完→组装展示），连续追问期间不声明。［handoff §2.18］
- G5. **问题目标层**：每个问题都要能回答"我在探什么"——探明什么（十组方向：角色核心/调色盘/背景来源/欲望缺失恐惧/防御决策/关系/三面性/混色/台词行为/底线弧光二次解释）、终点（核心人格层"最低限度要知道"清单——所有提问最终要到达"角色怎么做选择"）、够不够（标签下钻五连问 + 闭环判据：能落成一句行为描述且用户认可）。堵死"为问而问"。［handoff §2.16 + §3.4 下钻五连问］
- G6. 推演质量保障：输入端软判断（对照十组方向判断素材覆盖，不需全满，维度够就推该维度，显式过渡确认"素材我觉得够推[槽位]了，还有补充吗？"）；解析端内部理解（推演前不输出地列已知事实/已确认特征/未言明模式/不确定留空，一句话摘要，三句写不清=素材不够退回去问）；质量端自检（差异性检查/标签检查/素材追溯检查，找不到源头标注"此为推测"）；失败端处理（"不是 X 是 Y"=校准非失败；"不知道"=素材不够回收集；"都不是"=理解偏差→溯源）。［handoff §2.19a-d］
- G7. 推演硬规则：禁止出形容词，只许出行为场景；每条推演标注三要素（行为场景/心理学机制/从哪段经历推出来）。［handoff §2.11］
- G8. 红线五条：禁止先给推演 / 禁止形容词 / 禁止一次性砸完整档案（先轮廓确认后补全）/ 禁止标签化（不写"极度自卑""傲娇"裸标签）/ AI 永远提案用户永远裁决。［handoff §2.14］
- G9. 边界：不生成开场白、不写正文、不做 NSFW 内容、不替代作者决策、不一次输出全部性格。［handoff §2.15］
- G10. 引导而非说教 + 用户分层：用户跟引导走→可展开讲原理；用户说"直接来"→立即闭嘴快速推进；默认一两句引导不展开。［handoff §2.15c + AGENTS.md］
- G11. ⚠️ 二次解释触发时机：handoff §2.13 说"组装阶段统一生成所有二次解释条目，不在构建过程中分散触发"；但第二份 §5.1.3 触发条件写"每个深度层完成后追加"，且 §4.3 MVC 结构判读依赖"第一轮二次解释已生成"。两处冲突 → **待决 Q12**。与 probe-misread 的阶段定位（AI 可执行性阶段）一致的部分不受影响。
- G12. "帮我生成/帮我扩写"→ 不路由排除，拦截并转为追问。［CHAR_BUILD_GUIDE §6.2 重要］
- G13. **用户确认信号表**（投影确认/收束时检查）：正面认可（"对""就是这种感觉"）✓有效；补充确认（"对，而且她还会……"）✓有效（最强）；修正确认（"不对，她会沉默几秒然后岔开话题"）✓有效（精确修正=脑中模型清晰的证据）；敷衍（"嗯""哦"）✗无效不推进；AI 引导式（"是不是有点 XX？"+"嗯"）✗无效不锁死。裁决权威：**用户裁决不可上诉**——"你推演，用户裁决。不服裁决不要争论，换方向重推。用户说'就是这种感觉'，它就是对的。"［handoff §2.15b + E_SECTION 决策 4 + 融合简报 §6.7］

核心四框架（任何角色都能推出东西的普适生成轴）：

| 框架 | 生成轴 | 推演方向 | 卡片映射 |
|---|---|---|---|
| 依恋理论 | 关系轴 | 怎么靠近/推开、怎么表达需求、对分离什么反应 | 调色盘衍生、深层缺失 |

- 筛选标准（五个）：生成性（必须能"经历→行为"推演）/ 行为落地（推演出来必须能演）/ 结构性差异（框架视角互不重叠）/ 领域覆盖 / 卡片映射（推演结果能流进调色盘结构）。排除：特质论大五（描述性，且整套方法论要消解的就是特质标签）、进化心理学（人类共性，个体独特性贡献低）、沟通分析 TA（与认知图式高度重叠）。
