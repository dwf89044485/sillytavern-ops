## 一、这个 skill 是什么

**通过一问一答，引导用户创造出一个角色。**

用户提供想法（一个标签 / 一个画面 / 一段经历 / 一张现成的卡 / 什么都没有），AI 持续追问，帮用户把脑子里模糊的感觉变成具体、独特、AI 演得出来的角色描述。产出一份角色文档。

核心洞察：告诉 AI "她温柔"，AI 只会演模板；告诉 AI "她把削好的铅笔放在没笔的同桌桌角，做完就收回目光"，AI 才知道这个温柔长什么样。**skill 的全部任务，是把标签翻译成行为画面。**

用户是创作者不是工程师，没读过教程，不懂任何术语，全程也不需要懂。

## 二、跑起来的样子

### 开始

- ✓ **用户带什么来都行**——标签、画面、经历、现成的卡、或者什么都没有。AI 从中挑最具体的一点切入。
- ✓ **带着现成角色卡来的不重走流程**——AI 解析已有内容，找出其中最标签化的地方，从那里开始追问。
- ✓ **轻轻锚一下世界设定**——现代都市？古风？末世？只为了知道用哪个场景库来提问，不构建完整世界观。
- ✓ **AI 不上课**——不解释原理，不抛术语（不说"底色""调色盘""三面性"），不做教学检验。用户主动问"为什么要这么写"时才简短回答，然后切回追问。

### 主循环

- ✓ **每轮诊断，挑最要紧的追**——AI 内部判断用户的回答缺什么：太笼统（换个角色也成立）、前后打架、说的是结论不是画面、这人太单薄没有反面。诊断是 AI 内心的，用户只看到一句自然的追问。
- ✓ **绝不要求用户做方法论判断**——不问"你觉得遮住名字还成立吗"，而是直接问一个更具体的问题。
- ✓ **一次问几个不硬性规定**——有关联的、一起回答更完整的问题，可以一次抛出。
- ✓ **用户一次说一大段时，其余信息点登记在册**——AI 只深挖其中一个，但把其他有价值的点记下来。当前这个挖到底、或用户不想再挖时，AI 拿出登记的清单问用户还想挖哪个。**说过的东西不会丢。**
- ✓ **露出苗头才往深里挖**——"她在家和在外面完全是两个人"→ 多面性；"她那时候又开心又难过"→ 混色；"她明明可以接受帮助但就是不要"→ 核心人格层。没露出苗头就不挖，**深度不设关卡，用户对此无感知。**
- ✓ **亲密 / NSFW 只在用户主动提及时进入**，AI 不主动引导。
- ✓ **用户中途推翻方向**（"不对，她不是这样的人"）——已构建的部分作废回到追问，但用户说过的原始材料保留，不清空。
- ✓ **确认过的立刻写进文档**——不是聊完才整理，是每轮就落盘，用户随时能看到攒了多少。
- ✓ **文档里三档标清楚**——哪些是用户说的、哪些是 AI 推的、哪些还没定。
- ✓ **AI 整理的东西用大白话讲给用户确认**，不是甩一份格式化文档让用户自己读。
- 🔲 **用户卡住时怎么救**——讨论中，见 `handoff/卡住救援-handoff.md`。核心待解：红线"只追问不填空"和救援手段（给选项/AI 推演/假设场景）的边界划在哪。

### 收口

- ✓ **攒够了停下来给用户看全貌**——用户决定收工还是继续挖。
- ✓ **用户说够了立刻停**——优先级最高，压过所有其他判断。
- ✓ **收工前检查一遍会不会被演歪**——"这么写，AI 扮演时会不会理解偏？"歪的地方补一句说明。
- ✓ **最后提一个意象**——AI 主动提炼并提议，用户觉得对就留，不对就扔。总是尝试，不跳过。
- ✓ **产出是角色文档，不是能直接用的角色卡**——转成卡、配世界书、写开场白是后面另外的 skill 的事。
- ✓ **跨会话可续**——今天聊一半明天接着聊，AI 读文档就能接上。

### 贯穿全程

- ✓ **必须聊到的清单按教程七层**：基础信息（外貌/背景/关系）→ 调色盘（底色/主色调/点缀色，每色配具体行为画面）→ 多面性 → 混色 → 核心人格层 → 二次解释 → 意象。其中多面性、混色、核心人格层按苗头触发，不是必经。
- 🔲 **要不要有个简化模式**——讨论中，见 `handoff/简化模式-handoff.md`。
