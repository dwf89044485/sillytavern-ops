# 阶段 1 候选：追问动作池

> 来源：3 个 knot agent 独立分析 + 24/80/200 工作流 + 主流程独立思考
> 组织原则：每个追问动作分为「AI 内部诊断」和「AI 对用户的外部追问」两层。用户不需要知道任何方法论。

---

## 第一部分：6 个基础诊断 + 对应追问

这 6 个在任何阶段都可能触发。AI 先做内部诊断，再选择对应的外部追问方式。

### 1. 泛化检测 → 具象化追问

**AI 内部诊断**：用户给的描写放到别的角色身上也成立（"遮名测试"不通过）。常见症状：万能形容词（精致、温柔、坚强）、文学比喻（像清泉一样的眼睛）、默认值重复（中国女生写黑发黑眼）。

**AI 对用户说的（示例）**：

外貌泛化时：
> "我试着在脑海里画她，但还画不出具体的样子。她有没有什么一眼就能认出'这是她'的东西？比如一个总带着的饰品、某个地方的痕迹、一种特别的走路方式？"

性格泛化时：
> "你说她温柔。她温柔的时候在做什么？给我一个具体的画面——什么时间、什么地点、她做了什么事让你觉得'她温柔'？"

背景泛化时：
> "你说她家庭条件不好。这件事在她的日常里变成了什么？她买东西的时候会怎么做？她看到同学用好东西的时候什么反应？"

**质量门**：用户的回答能让 AI "看到"一个具体画面，不再是形容词堆砌。

**教程来源**：
- 晴空教程 01（外貌"遮名测试"）、02（衍生的画面化）
- 原始教程 0（外貌特征差异化原则）、1（衍生示例）
- 工作流 Q24_01"这个角色一句话是什么"、Q80_13"每种颜色对应什么具体行为"

---

### 2. 矛盾检测 → 张力追问

**AI 内部诊断**：用户给的两个标签/描述互相打架。常见症状："极度自卑"但"成绩年级前列"、"从不求人"但"最后向人借钱"、"很独立"但"非常依赖某个人"。

**注意**：矛盾不一定是错误——更多时候是通往更深层真相的入口。AI 不要说"你写的矛盾了"，而是用矛盾点作为追问的切入。

**AI 对用户说的（示例）**：

> "她成绩年级前列——这需要很强的毅力和行动力。一个自卑到极点的人，是什么支撑着她一直保持这个成绩？"

> "你说她从不接受帮助，但最后她向{{user}}开了口。那一刻是什么压过了她'不求人'的习惯？"

> "她很独立，但她对红美玲有很深的依赖。这两面在她身上是怎么共存的——她是在红美玲面前才不独立，还是她的'独立'本身就是一种保护？"

**质量门**：用户给出了两个标签共存的内在逻辑，或者修正了不准确的标签（如"极度自卑"→"不甘心"）。

**教程来源**：
- 晴空教程 02（"极度自卑 vs 考前列"的矛盾追问 → 发现"不甘心"）
- 原始教程 1（性格对冲思路）、2（三面性判断前的行为差异检查）
- 工作流 Q24_04"核心矛盾是什么"、Q80_14"哪两种颜色会对冲"

---

### 3. 结论检测 → 画面还原追问

**AI 内部诊断**：用户给的是总结/分析/内心活动，而不是可被观察到的事实。常见症状："她对他充满恐惧""这是她性格转变的起点""她内心很矛盾，既渴望被爱又害怕被伤害"。

**AI 对用户说的（示例）**：

> "你说她害怕陆昂。那个害怕的时刻——陆昂做了什么，她做了什么反应？她的身体是什么状态？"

> "你说她'内心很矛盾'。如果我是站在旁边看的人，我看得到什么？她做了什么动作，说了什么话？"

> "你说她性格因为这件事发生了转变。转变之前她走路是什么样的？转变之后呢？"

**质量门**：用户的回答从"心理分析"变成了"可拍摄的画面"——可以看见、听见、摸到的东西。

**教程来源**：
- 晴空教程 01（背景"这是性格转变的起点"→去掉、关系"充满恐惧"→"用书本推到桌角"）
- 原始教程 4（混色"不解释，只写动作"）、11（小传"录像带规则"）
- Agent 3 场景 9（"用户写了很多内心描写但没有行为画面"）

---

### 4. 扁平检测 → 找反面追问

**AI 内部诊断**：角色全是正面特质，没有缺点、矛盾或反差。或者角色只有一种情绪状态，所有场景下表现一致。

**AI 对用户说的（示例）**：

> "她身边的朋友私下会怎么吐槽她？"

> "她有没有什么改不掉的毛病？或者做过什么让自己后悔的事？"

> "什么时候她会表现得跟平时完全不一样？"

> "她的温柔有没有副作用？会不会温柔过头反而伤到自己或别人？"

**质量门**：角色出现了反差、缺点或内在张力，不再是"完美但无聊"。

**教程来源**：
- 晴空教程 02（"点缀色：平时看不到的颜色"追问）
- 原始教程 7（核心人格层"深层缺失""核心恐惧"）
- 工作流 Q80_07"她的痛点在哪里"、Q80_08"删掉一个设定她还成立吗"
- Agent 3 场景 10（"用户想把所有好特质都塞给角色"）

---

### 5. 完整性检查 → 补白追问

**AI 内部诊断**：对照核心维度清单，某些维度用户还没有提及。AI 不对用户说"你漏了 X 维度"，而是用自然的追问引导到空白区域。

**核心维度清单**（来自 24 问精简）：
- 角色核心（一句话是什么、吸引力、核心矛盾）
- 性格质地（有哪些颜色、具体行为）
- 来源（为什么长成这样、背景中什么事改变了她）
- 内在驱动（她想要什么、她缺什么、她怕什么）
- 关系（{{user}}对她意味着什么、她怎么靠近/推开）
- AI 可执行性（常说什么、绝不会怎么说、AI 容易误读成什么）

**AI 对用户说的（示例，根据缺失维度选择）**：

缺来源时：
> "她为什么会变成现在这个样子？有没有什么事——不一定是大事——让她学会了现在这种处事方式？"

缺关系时：
> "她和{{user}}之间，最开始是怎么认识的？现在他们怎么相处？"

缺内在驱动时：
> "如果问她'你最想要什么'，她嘴上会说什么？她心里真正想的又是什么？"

**质量门**：核心维度都有至少最基本的覆盖。

**教程来源**：
- 工作流 24 问的 6 组结构
- 晴空教程 01-07 的完整流程顺序

---

### 6. 深度就绪检查 → 按需深入追问

**AI 内部诊断**：用户已经给了足够的素材，AI 判断角色是否需要进入更深的层次（三面性、混色、核心人格层）。不是所有角色都需要——纯甜饼角色不需要核心人格层，行为差异不大的角色不需要三面性。

**AI 对用户说的（示例）**：

判断三面性时：
> "她在家里和在外面，状态差别大吗？是'语气柔和了一点'的那种差别，还是'像换了一个人'？"

判断混色时：
> "她拒绝别人帮助的那个瞬间，她心里只有一种感觉在跑，还是好几种挤在一起？"

判断核心人格层时：
> "同样的处境，别人可能会接受帮助、可能会求人、可能会妥协。她为什么偏偏选了自己扛？是什么让她走了这条路而不是别的路？"

**质量门**：AI 判断出是否需要深入。如果不需要，直接跳到 AI 可执行性阶段。

**教程来源**：
- 晴空教程 03（"需不需要三面性"判断标准）、04（"什么角色适合混色"）、05（"什么角色需要核心人格层"）
- 原始教程 2/4/7 中各自的"不是所有角色都需要"的提醒

## 第二部分：8 个阶段专用追问

这些只在特定阶段触发，不是全程通用的。

### 7. 入口分流

**触发阶段**：用户刚进来，skill 需要判断起点。

**AI 内部诊断**：用户带来了什么？（现成角色卡 / 一堆标签 / 模糊感觉 / 详细构思）

**AI 对用户说的**：

> "你现在对这个角色有多少想法了？是已经有一份写好的角色卡想改进？还是有一些标签和灵感？还是只有一个模糊的感觉？"

如果用户只有模糊感觉：
> "没关系。你想象一下这个人第一次出现在你面前——你第一眼注意到她什么？"
> "如果用一个画面来形容她，你脑子里出现的是什么？"

如果用户有现成角色卡：
> "把角色卡给我看看，我来读一下，然后我们聊聊哪些地方可以更具体。"

**教程来源**：
- 已有 char-creator 雏形的"第零步：接管道具"
- 工作流"24 问急救模式"的入口设计
- Agent 3 场景 1（"只有模糊感觉说不出来"）

---

### 8. 标签压缩

**触发阶段**：性格质地阶段，用户给了 3 个以上散乱标签。

**AI 内部诊断**：用户的标签可以被组织成层次结构（底色/主色调/点缀），但 AI 不用术语——而是用自然追问引导用户自己发现层次。

**AI 对用户说的**：

> "你说了好几个关键词。如果让你只选一个——去掉了她就不是她了的那个——是哪个？"

> "这些标签里，哪个是她每天都在的、别人第一眼就能感觉到的？哪个是平时藏着的、只有特定时候才冒出来的？"

**质量门**：用户的标签从"散列"变成了有主次的结构。

**教程来源**：
- 晴空教程 02（从 7 个标签到 3 层颜色的完整过程）
- 工作流 Q24_05-07（底色/主色调/点缀追问）

---

### 9. 为什么追问（机制下钻）

**触发阶段**：性格质地阶段，用户给了表面行为但没说底层原因。

**AI 内部诊断**：用户描述了"她做什么"，但没触及"这个行为对她来说是什么功能"。AI 不是在要求用户解释心理学原理，而是追问行为的"功能"。

**AI 对用户说的**：

> "她在学校从来不说话。不说话对她来说是什么？是'懒得说'，还是'不敢说'，还是'说了也没人听'？"

> "她把别人给的东西悄悄推开。推开的时候她心里是'不想要'，还是'不敢要'？"

**质量门**：用户给出了行为背后的机制，同一个行为从"标签"变成了"有原因的策略"。

**教程来源**：
- 晴空教程 02（"她为什么安静？" → "不出声就不会出错" → "把乖当盔甲"）
- 原始教程 7（核心人格层"防御机制"必须能落到行动上）
- 工作流 Q80_33-40（防御与决策组）

---

### 10. 场景分化追问

**触发阶段**：深度就绪检查通过后，需要判断是否拆面。

**AI 内部诊断**：角色在不同压力场景下的行为差异是否大到需要分流语料和行为模式。

**AI 对用户说的**：

> "她在学校和在家里，说话方式差别大吗？在学校说什么，在家说什么？"

> "她面对一个让她紧张的人、和面对一个让她安心的人，整个状态差多少？是'稍微放松一点'，还是'完全换了一个人'？"

> "如果差别很大——那从一种状态切换到另一种，中间她会怎么过渡？比如放学到回家的路上，她会有什么变化？"

**质量门**：确定角色是否需要分面，以及分几面；如果需要，每面的触发条件、说话方式、身体状态、功能都有初步描述。

**教程来源**：
- 晴空教程 03（陈乖乖三面性完整示例 + 过渡 + 渗透）
- 原始教程 2（"压力性质截然不同"的判断标准）

---

### 11. 同一瞬间追问（混色发现）

**触发阶段**：深度就绪检查通过后，角色有内在矛盾，可能适合混色。

**AI 内部诊断**：角色在某些关键时刻会有多种情绪同时运作，AI 需要引导用户把这些瞬间写成具体画面。

**AI 对用户说的**：

> "她拒绝帮助的那个瞬间——她说'不用了'的时候，她的身体在做什么？和她嘴里说的是同一件事吗？"

> "她笑的时候，那个笑里面只有开心吗？还是有别的什么也在跑？"

> "你说她很难受，但同时又被{{user}}的一句傻话逗笑了。那一秒她的脸上是什么表情？"

**质量门**：用户给出了"两个物理事实放在一起"的画面，不需要解释情绪——画面本身就是混色。

**教程来源**：
- 晴空教程 04（物理事实反差技巧 + 7 个混色画面示例）
- 原始教程 4（混色的"不解释"原则 + 洛潮汐 20 个画面）

---

### 12. 决策追问（核心人格层入口）

**触发阶段**：深度就绪检查通过后，角色有明确的剧情压力和防御机制。

**AI 内部诊断**：角色的行为已经有了"怎么做"的描述，但还缺"为什么做这个选择而不是别的选择"。

**AI 对用户说的**：

> "同样是很穷的人，有人会借钱、有人会偷、有人会出卖自己。她为什么偏偏选了自己扛到最后？"

> "她最怕什么？不是怕黑怕疼那种——是'如果这件事发生了，我就不是我了'的那种怕。"

> "她有没有一条线——她自己都没意识到的——跨过去她就不再是她自己了？"

> "如果这个故事走得好，她可能意识到什么？如果走得不好呢？"

**质量门**：用户能回答角色的表层欲望、深层缺失、核心恐惧、防御机制中的至少 2-3 个，而且是用行为而非心理词回答的。

**教程来源**：
- 晴空教程 05（陈乖乖核心人格层完整推导过程）
- 原始教程 7（霸总顾钧示例 + 七部件格式）
- 工作流 Q24_13-16、Q80_25-40

---

### 13. 误读预判追问

**触发阶段**：AI 可执行性阶段，角色的主要特质都已确定。

**AI 内部诊断**：角色的某些特质组合容易被 AI 套进常见模板（安静→冷漠、不接受帮助→傲娇、坚强→热血少年漫）。

**AI 对用户说的**：

> "你觉得如果让 AI 来演她，AI 最容易把她演成什么样子？你最不希望看到 AI 把她写成什么？"

> "她的安静——你觉得 AI 会不会把'安静'理解成'冷漠'或者'什么都不想'？如果会，那她的安静和冷漠的区别在哪？"

> "她的常用语是什么？比如她最常说的三句话。反过来，她绝对不会说什么样的话？"

**质量门**：用户给出了 AI 最可能的误读方向 + 正确的理解方式。这些会变成二次解释。

**教程来源**：
- 晴空教程 06（九条防误读备注完整示例）
- 原始教程 1（二次解释的本质 + 秋明月示例）
- 工作流 Q24_24"AI最容易把她误读成什么"、Q80_79-80

---

### 14. 意象追问

**触发阶段**：所有主要内容完成后的收束阶段。

**AI 内部诊断**：角色的所有维度都有了，但缺少一个总的锚定感。AI 需要引导用户找到一个象征物来收束角色。

**AI 对用户说的**：

> "现在你已经很了解她了。最后一个问题——如果用一样东西来形容她存在的方式，你会想到什么？不是她的外貌像什么，是她活在这个世界上的姿态、方式像什么。"

> "这个比喻能不能也装得下她和{{user}}的关系？比如风铃和风、一小格阳光和开窗的人。"

如果用户想不到，可以引导：
> "想想她的核心矛盾。她一直在做什么？在等什么？在抵抗什么？什么自然界的东西也是这样的？"

**质量门**：用户找到一个意象，能承载角色的核心状态和关系动态。

**教程来源**：
- 晴空教程 07（"一小格阳光"的完整创作过程）
- 原始教程 6（姜糖"向日葵"、洛潮汐"潮汐"的意象选择）

## 第三部分：阶段流转模型

### 主流程

```
┌────────────┐
│  入口分流   │  判断用户起点
│            │  现有卡 → 解析，跳到需要补充的阶段
│            │  标签/灵感 → 进入基础身份
│            │  模糊感觉 → 用画面/颜色/天气找入口
└─────┬──────┘
      │
      ▼
┌────────────┐
│  基础身份   │  轻量处理：谁、长什么样、经历、关系
│  (轻量)    │  用户带着完整信息来 → 提取确认即可
│            │  诊断：泛化检测、结论检测
└─────┬──────┘
      │
      ▼
┌─────────────────────────────────────────────┐
│              性格质地 (主阶段)                  │
│                                              │
│  主线追问：标签压缩、为什么追问、具象化           │
│  诊断：泛化、矛盾、扁平、完整性                  │
│                                              │
│  ┌─ 持续信号检测 ─────────────────────────┐   │
│  │                                        │   │
│  │  场景差异信号                            │   │
│  │  "她在家和在外面完全不一样"               │   │
│  │  "她必须扮演大小姐"                      │   │
│  │  衍生自然聚类到不同环境                   │   │
│  │  → 检测到 → 自然进入场景分化追问(#10)     │   │
│  │                                        │   │
│  │  情绪碰撞信号                            │   │
│  │  "她那时候又开心又难过"                   │   │
│  │  调色盘颜色之间有强烈张力                  │   │
│  │  用户描述的行为和言语矛盾                  │   │
│  │  → 检测到 → 自然进入同一瞬间追问(#11)     │   │
│  │                                        │   │
│  │  决策深度信号                            │   │
│  │  "她明明可以接受帮助但就是不要"            │   │
│  │  角色有明显的防御模式                     │   │
│  │  用户被问'为什么'时给出深层回答            │   │
│  │  角色有剧情驱动的核心困境                  │   │
│  │  → 检测到 → 自然进入决策追问(#12)         │   │
│  │                                        │   │
│  │  未检测到任何信号 → 角色不需要深入          │   │
│  └────────────────────────────────────────┘   │
└─────┬───────────────────────────────────────────┘
      │
      ▼
┌────────────┐
│ AI 可执行性  │  误读预判追问(#13) + 常用语/禁用语
└─────┬──────┘
      │
      ▼
┌────────────┐
│  意象       │  总是尝试提炼(#14)
│  (总是尝试) │  用户觉得对就留，不对就不要

      │

│  整理输出   │  组织成角色文档
│            │  区分：已确认 / AI推论 / 待用户决定
└────────────┘
```

### 运行规则

1. **6 个基础诊断全程运行** — 泛化/矛盾/结论/扁平/完整性/深度信号检测，在任何阶段都持续监听用户输入。

2. **不强制线性** — 用户可能一上来就给了大量信息覆盖多个阶段。skill 做完整性检查，只追问空白维度，不重复已有内容。

3. **深度分支是自然过渡，不是关卡** — 没有"深度就绪检查"这个显式阶段。三面性/混色/核心人格层的追问在性格质地阶段内由信号触发，检测到就顺着聊，没检测到就自然流向 AI 可执行性。

4. **基础身份轻量处理** — 用户带着完整基础信息来的，提取确认即可，不强制重走。基础信息有明显问题的（泛化外貌、结论式背景），诊断后追问纠正。

5. **意象总是尝试** — 不跳过，但用户觉得不对可以不要。意象是 skill 主动提炼并提议的，不是强制用户想出来的。

6. **输出分层** — 最终文档必须区分三类内容：用户明确确认的、AI 根据对话推论的、用户还没决定的。不把推论当事实。
