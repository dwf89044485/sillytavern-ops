# ⚠️ 如果你是 AI，先读这里

本目录是 `char-build-guide` skill 的源材料。但 **这些教程不是 skill 的操作手册。**

---

## 教程和 skill 有本质区别

**教程的目标**：教会读者理解调色盘方法论，让读者成为一个能独立写角色的人。
教程作者通过"晴空妈妈与柚子妹妹"的母女对话演绎，在追问角色的过程中顺带教学：
- 解释"为什么外貌只写特征不写美感"
- 展示正确 vs 错误对比来教读者识别问题
- 让柚子写"课后笔记"来检验学会没有
- 故意让柚子先写错的再纠正（教学冲击力更强）

**skill 的目标**：用教程中的追问方法引导用户创建角色。用户不需要学会任何理论。
skill 默认只做一件事：通过追问让用户把脑子里的角色说出来。
教学/解释不是禁止——但只在用户主动问"为什么要这样写"时才简短给出，然后切回追问。

## 读本教程时，每看到一个晴空妈妈的行为，先区分

| 晴空妈妈在做什么 | 意图 | skill 是否用 |
|---|---|---|
| 追问"遮住名字放在别人身上也成立吗？" | 追问角色 + 顺便教识别废话 | ✅ 追问动作吸收。教学部分不吸收 |
| 追问"有没有哪个时刻她表现得完全相反？" | 追问角色 + 展示矛盾追问法 | ✅ 追问动作吸收。教学部分不吸收 |
| 解释"为什么只写特征不写美感" | 教原理 | ❌ 不融入默认行为。用户问时才简答 |
| 正确 vs 错误并列对比 | 教识别 | ❌ 不融入默认行为 |
| 让柚子写课后笔记 | 检验学习 | ❌ 不融入默认行为 |
| 先让柚子写错再纠正 | 教学手段 | ❌ 不融入默认行为 |
| 说"这就是调色盘，底色、主色调、点缀" | 教术语 | ❌ 不融入默认行为 |
